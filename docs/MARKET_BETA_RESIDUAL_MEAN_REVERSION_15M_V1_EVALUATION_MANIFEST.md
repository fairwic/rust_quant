## 3. 冻结因子与候选

每个 UTC `00:00 / 08:00 / 16:00`，对应 15m K 线完成后：

1. 使用币种与 BTC 此前连续 `7d = 672` 个同步 15m 对数收益；
2. `beta = cov(symbol, btc) / var(btc)`，`alpha = mean(symbol) - beta * mean(btc)`；
3. `residual = symbol_return - alpha - beta * btc_return`；
4. `residual_24h`、`residual_6h` 分别为最近 96、24 个 residual 之和；
5. `daily_residual_vol = sample_std(672 residual) * sqrt(96)`；
6. `score = residual_24h / daily_residual_vol`，要求 `abs(score) >= 1.5`；
7. 必须已经出现回归：`residual_24h` 与 `residual_6h` 严格异号；
8. 当时币池至少 80% 成员具备完整因子，否则整个时点阻塞；
9. 每个决策时点按 `abs(score)` 降序、symbol 字典序打破并列，只选一个；
10. `score > 0` 做空，`score < 0` 做多，不使用 K 线颜色、BOS、CHoCH、FVG、影线、OI、funding
    或 taker 阈值。

所有因子只读取决策时点及以前的已完成 K 线；symbol 输入顺序不得影响结果。

## 4. 冻结交易与成本合同

- 下一根 15m 开盘入场；
- 初始止损距离为决策时点 `ATR(14) * 2.0`，且必须位于入场价的 `0.75%～5.0%`；
- 固定止盈 `2R`，最长持有 `24h = 96` 根；
- 同棒同时触及止损和止盈时按止损；
- 同币最多一笔，组合最多 4 笔并发、同方向最多 3 笔；容量不足单独记录；
- 每边手续费与滑点合计 `8bps`，每跨一个 UTC 8h 时点再计 `1bp` 不利资金成本；
- 双倍成本为上述成本的两倍；
- `1R` 固定为入场时初始止损对应的风险，退出不得回写。

## 5. 预注册停止与晋级规则

必须报告因子覆盖、候选/风险/容量漏斗、交易数、有效事件、方向、月份、币种集中度、退出原因、
零/标准/双倍成本 EV、PF、胜率、trade Sharpe、最大回撤 R 与 Recovery。

以下任一成立即永久淘汰，不扫描阈值或退出参数：

- 零成本 EV `<=0R` 或 PF `<=1`；
- 标准成本 EV `<=0R` 或 PF `<=1`；
- 少于 300 笔或 180 个有效事件；
- 少于 8/12 个正收益月；

职业晋级要求标准成本同时满足净 EV `>=0.6R`、PF `>=2.2`、组合频率 `50～120` 笔/月、
Sharpe `>=1.5`，双倍成本仍为正，并且跨月、方向、币种不集中。交易级全部通过后，才以 0.5%
单笔风险、2% 最大并发初始风险计算逐时组合权益，要求最大回撤 `<=10%`、Recovery `>=4`、
日收益 Sharpe `>=1.5`。
