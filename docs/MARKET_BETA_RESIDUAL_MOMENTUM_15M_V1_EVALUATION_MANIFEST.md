## 3. 冻结因子计算

每个 UTC `00:00 / 08:00 / 16:00`，只在对应 15m K 线已经完成后决策：

1. 每个币种与 BTC 必须连续覆盖此前 `7d = 672` 个 15m 收益；
2. 用这 672 个同步对数收益计算带截距 OLS：`beta = cov(symbol, btc) / var(btc)`，
   `alpha = mean(symbol) - beta * mean(btc)`；
3. 特质收益：`symbol_return - alpha - beta * btc_return`；
4. `residual_24h` 为最近 96 个特质收益之和，`residual_6h` 为最近 24 个之和；
5. `daily_residual_vol = sample_std(672 个特质收益) * sqrt(96)`；
6. `score = residual_24h / daily_residual_vol`；
7. 只保留 `residual_24h` 与 `residual_6h` 同号且 `abs(score) >= 1.5` 的成员；
8. 当时有效币池至少 80% 成员有完整因子，少于该覆盖率则整个决策时点阻塞；
9. 按 `abs(score)` 降序、symbol 字典序打破并列，每个决策时点只选择一个币种；
10. `score > 0` 做多，`score < 0` 做空。不得看当前 K 线颜色或局部结构。

Beta、波动率和残差只读取决策时点及以前的已完成 K 线；symbol 输入顺序不得改变选择结果。

## 4. 冻结入场、风控与退出

- 下一根 15m 开盘入场；缺失下一根或时间不连续则阻塞；
- 初始止损距离为决策时点 `ATR(14) * 2.0`；
- 初始风险距离必须位于入场价的 `0.75%～5.0%`，否则阻塞；
- 固定止盈 `3R`，最长持有 `48h = 192` 根；
- 同一根同时触及止损和止盈时，保守按止损；
- 每个币种同一时间最多一笔；组合最多 6 笔并发、同方向最多 4 笔；容量不足记 blocker；
- 一个决策时点只有一个候选，不允许用候选遍历顺序抢占容量；
- 每边手续费与滑点合计 `8bps`；另按每跨过一个 UTC 8h 时点计入 `1bp` 不利资金成本；
- 双倍成本为每边 `16bps` 加每个 8h 时点 `2bps` 不利资金成本；
- `1R` 永远是入场时初始止损对应风险，后续退出不回写。

## 5. 预注册报告与停止规则

必须报告：候选漏斗、覆盖阻塞、容量阻塞、原始交易数、30 分钟有效事件数、Long/Short、月份、
Discovery/Validation、零成本、标准成本、双倍成本、币种贡献、移除前三盈利币种、止损/止盈/超时，
以及净 EV、PF、胜率、trade Sharpe、最大回撤 R 和 Recovery。

Discovery 任一条件成立即永久淘汰 V1，不打开 Validation，也不扫描阈值：

- 零成本 EV `<= 0R` 或 PF `<= 1`；
- 标准成本 EV `<= 0R` 或 PF `<= 1`；
- 少于 300 笔或少于 180 个有效事件；
- 少于 8/12 个正收益月；
- 移除前三盈利币种后净 R `<= 0`；
- Long 或 Short 任一方向超过 80% 且另一方向不足 60 笔。

只有 Discovery 通过上述早停，才允许原样运行 Validation。职业晋级仍要求标准成本 OOS 同时满足：

- 净 EV `>= 0.6R`、PF `>= 2.2`、Sharpe `>= 1.5`；
- 组合频率 `50～120` 笔/月；
- Validation 净 EV/PF 均为正，跨月、方向和币种不集中；
- 双倍成本仍保持净 EV `> 0R`、PF `> 1`；
- 交易级通过后，再以统一 0.5% 单笔风险、3% 最大并发初始风险计算逐时盯市组合权益，要求最大回撤
  `<= 10%`、Recovery `>= 4`、日收益 Sharpe `>= 1.5`。

## 6. 现实边界

- 这是全市场相对强弱策略，不是原动量 15m 中的“极端下跌后做多”小版本；若成立必须使用独立
  `strategy_key`，不能覆盖旧策略；
- 当前 live-only 币种池按用户要求排除退市币，因此不是无幸存者偏差的历史全市场结论；
- ResearchBar 只能证明 K 线级经济行为，不能证明实盘滑点、部分成交、lease 或保护恢复；
- 本清单不授权 Paper、Live、真实下单、撤单、平仓、部署或生产数据写入。

## 9. 决策

**V1 永久淘汰，不打开原计划 Validation，不进入组合权益精算、邻域扫描、Paper 或 Live。**

它不是频率不足：交易频率正好位于 15m 组合目标带，且有效事件远超早停下限。失败来自假设本身：
剔除 BTC Beta 后的 24h 特质强弱，在冻结的 8h 决策节奏上没有继续延伸，Long 与 Short 均为负，
零成本下也已失败。不得在该窗口反向交易、修改 1.5 分数、7 日 Beta、6h 持续、ATR 止损或 3R
目标。若研究残差回归，必须使用独立策略身份、不同的先验条件和尚未打开的历史窗口。
