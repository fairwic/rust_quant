# 市场去杠杆主动流翻转后回踩接受 15m V3 评估清单

## 1. 独立假设与版本边界

- 策略身份：`market-deleveraging-flow-acceptance-reversal-15m-v3`；
- V2 已证明去杠杆与主动流翻多后立即追入短结构突破没有优势。V3 不调整 V2 的 OI、taker、
  横截面或止盈止损阈值，只验证新的入场语义：突破后必须首次回踩原阻力并收盘重新接受；
- BOS/CHoCH/FVG 不作为投票指标。V3 的“接受”是可执行顺序：setup 成立、等待、首次回踩、
  已完成 K 线收回、下一根开盘入场；
- 本清单在读取 2025-07～2026-05 的 V3 结果之前冻结。该窗口不用于参数扫描。

## 2. 新未见窗口与数据

- 评估期：2025-07-01 至 2026-05-31，共 11 个完整 UTC 月；Discovery 为 2025-07～12，
  Validation 为 2026-01～05；
- 月度币池仍按前一个完整 OKX UTC+8 月中位日成交额 Top60，只保留当前 live、
  `instCategory=1` 的加密 USDT 永续，按用户要求排除退市币并承认幸存者偏差；
- OKX 官方分钟归档只用于严格聚合 15m；Binance 官方 5m metrics 使用与 V2 相同的 checksum、
  日界线、重复 `00:00` 归并、缺失阻塞和 5 分钟可见性合同；
- 当前 Binance 映射只保留 `TRADING + PERPETUAL + USDT + underlyingType=COIN`；未映射、404、
  无效 OI/taker 日均只阻塞对应 setup，不补值。

## 3. 冻结 setup

1. 最近 96 根已完成 15m 的净收益为负，且处于同一时点当月币池最低 20%；
2. 最近 8 根中至少一根最低价跌破它之前 96 根最低价；
3. setup K 线收阳并收盘突破前 4 根已完成 15m 的最高价，冻结该最高价为回踩接受位；
4. Binance 最新可见 `sum_open_interest_value` 必须低于精确 4 小时前；最近 12 个 5m
   `sum_taker_long_short_vol_ratio` 中位数 `>1`，再前 12 个中位数 `<1`；
5. top-trader 多空比只记录诊断，不参与门禁。

## 4. 冻结回踩接受、入场与退出

1. setup 完成后只观察第 1～8 根已完成 15m；若任一根收盘不高于最近 8 根扫低锚点，setup 失效；
2. 第一根最低价触及或跌破接受位、收盘重新高于接受位且收阳的 K 线定义为首次有效接受；
3. 首次有效接受完成后的下一根 OKX 15m 开盘入场；8 根内没有接受则过期，不追更晚回踩；
4. 初始止损仍为 setup 最近 8 根最低价减 `0.25 ATR(14)`；风险距离必须为 `0.5%～3%`；
5. 固定目标 `3R`、最长持有 48 小时；同根止盈止损按止损；每边成本 `8 bps`，双倍成本
   `16 bps/side`；同币 setup、等待与持仓期间不叠加新交易；
6. setup 后的 K 线只能按顺序决定接受、失效、过期和入场，入场后的 K 线才用于结算。

## 5. 预注册门槛

- 标准成本净 EV `>=0.6R`、PF `>=2.2`、trade Sharpe `>=1.5`；
- 原始组合频率 `50～120` 笔/月，30 分钟聚类有效事件至少 `20` 个/月；
- Discovery 与 Validation 均为正，至少 `8/11` 月为正；
- 双倍成本下 EV 与 PF 仍为正；移除前三大盈利币后净 R 仍为正；
- 交易级门槛全部通过后才进入统一资金、容量、相关簇、最大回撤 `<=10%` 与 Recovery `>=4`
  审计；任一核心门槛失败即淘汰 V3，不在本窗口改等待根数、接受条件、止损或目标。

## 6. 待填写结果

## 8. 决策

**V3 永久淘汰。** 回踩接受没有改善 V2；零成本已为负，Discovery 与 Validation 同时为负，
`74.1%` 的交易最终触发结构止损。不能再在已见窗口修改等待 8 根、收阳、接受位、风险或目标，
也不能把 BOS、CHoCH、FVG 继续叠加成投票项。下一实验改为独立的“反转尝试失败后顺势做空”
机制，并使用更早的未见历史窗口；它若成立也属于新策略，不代表 V3 多头反转被救活。
