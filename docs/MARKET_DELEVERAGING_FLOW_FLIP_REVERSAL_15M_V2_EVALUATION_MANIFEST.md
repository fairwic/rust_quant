# 市场去杠杆主动流翻转 15m V2 评估清单

## 1. 独立假设

- 策略身份：`market-deleveraging-flow-flip-reversal-15m-v2`；
- V1 已证明“主动卖出仍处于横截面高位时接扫低”没有优势。V2 不放宽 V1 阈值，而是验证另一种
  状态转换：持仓量先下降，主动成交从卖方占优翻转为买方占优，15m 再突破短期结构；
- BOS、CHoCH、FVG 只保留为其他策略的结构诊断，不参与 V2 开仓；
- 本清单建立在读取 V2 交易结果之前。参数冻结后只运行一次，不做网格或阈值扫描。

## 2. 未见窗口与币种池

- 评估期：2023-10-01 至 2024-04-30，共 7 个完整 UTC 月；
- manifest：`okx_current_live_usdt_swap_prior_month_median_quote_volume_top60_202310_202404`；
- 每个生效月使用前一个完整 OKX UTC+8 月的中位日成交额选 Top60；
- 只保留当前仍为 live 且 `instCategory=1` 的 OKX 加密 USDT 永续，排除股票永续和退市合约；
- 当前 live 过滤存在幸存者偏差，结果只评价当前幸存币；
- 价格仍来自 OKX 官方 1m 月包严格聚合的 UTC 15m：91 个并集币、623 个归档月包、
  1,820,832 根 15m；信号不使用 1m；
- 外部去杠杆证据来自 Binance 官方 public-data 日度 `metrics` 档案。只接受当前 Binance
  `TRADING + PERPETUAL + USDT + underlyingType=COIN` 合约；明确映射
  `PEPE/SHIB/BONK/FLOKI/SATS -> 1000*USDT`、`LUNA -> LUNA2USDT`，无当前对应物则阻塞；
- Binance metrics 只提供辅助证据，开仓价格、止损、止盈和持仓路径全部按 OKX 15m 回放。

## 3. 价格候选

1. 当前已完成 15m 的最近 96 根（24 小时）净收益为负，且处于当月成员同一时点最低 20%；
2. 最近 8 根已完成 15m 中，至少一根最低价跌破它之前 96 根的最低价；
3. 当前确认 K 线必须收阳，且收盘高于前 4 根已完成 15m 的最高价；
4. 上述条件只生成候选和需要下载的 Binance `symbol x UTC day`，不读取候选之后的价格结果。

## 4. Binance 去杠杆与主动流翻转

- metrics 原始粒度为 5m；每个点延迟完整 5 分钟才允许使用；
- 每个官方 ZIP 必须通过同路径 `.CHECKSUM` 的 SHA-256；404 表示当日无该合约历史，只阻塞对应
  候选，不伪造 0；通过校验但存在空数值、非法数值、非完整 288 点或 5m 不连续时，把整个币种日
  标为无效并阻塞依赖它的候选，不前填、不后填；下载、校验和、ZIP 或表头契约异常仍直接失败；
- Binance metrics 日文件现实中可能覆盖当日 `00:05` 至次日 `00:00`；按文件内连续时间戳读取，
  不强行改写成当日 `00:00` 至 `23:55`；top-trader 两列仅诊断，空值不阻塞 OI+taker 主信号；
- 相邻日文件若在 `00:00` 给出不同快照，优先采用时间戳所属自然日文件中的点；当天文件没有该点时，
  才保留前一日文件尾点。归并只按来源日和时间戳，不比较数值或交易结果；
- OI 使用 `sum_open_interest_value`。最新可见点相对至少 4 小时前的可见点必须下降；不设置
  结果驱动的绝对下降百分比；
- 主动流使用 `sum_taker_long_short_vol_ratio`。最近 12 个完整 5m 点的中位数必须 `>1`，
  再前 12 个完整 5m 点的中位数必须 `<1`；两段各要求 12 个连续点；
- `count_toptrader_long_short_ratio` 与 `sum_toptrader_long_short_ratio` 只记录诊断，不作为门禁，
  避免再次把三项相关条件交集压成极低频样本。

## 5. 入场、风控与成本

- 在 15m 确认 K 线完成后的下一根 OKX 15m 开盘成交；
- 初始止损为最近 8 根最低价减 `0.25 ATR(14)`；入场到止损必须为 `0.5%~3%`；
- 固定目标 `3R`，最长持有 48 小时；同根同时触及止盈止损时按止损；
- 单边手续费与滑点合计 `8 bps`，双倍成本压力为 `16 bps/side`；
- 同币未平仓期间不重复开仓；30 分钟内同方向触发聚为一个有效市场事件。

## 6. 预注册判定

- 净 EV `>=0.6R`、PF `>=2.2`、Sharpe `>=1.5`；
- 原始组合频率目标 `50~120` 笔/月，同时报告有效市场事件；
- 发现集 2023-10～2024-01 与验证集 2024-02～04 均须 EV 为正，至少 5/7 月为正；
- 双倍成本下 EV 为正且 PF `>1`；移除前三大盈利币后净 R 仍为正；
- 交易级门槛、频率、时间稳定性和集中度全部通过后，才进入统一资金、并发、相关簇、组合
  最大回撤与 Recovery 审计；任一失败即淘汰 V2，不在本窗口调参数。

## 7. 现实边界

- Binance OI 和主动流用于判断全市场状态转换，OKX 用于实际价格回放；跨交易所状态并不保证
  每个时点完全一致，因此必须把“跨交易所证据”作为策略适用边界；
- 当前币种池和当前 Binance 映射都会带来幸存者偏差；
- 若官方 metrics 某日缺档，候选只能阻塞，不能用相邻未来日补造；
- 7 个月足以淘汰明显失败家族，但即使通过，也仍需在完全隔离的新时间窗口做最终 OOS。

## 9. 决策

**V2 永久淘汰，不进入统一资金、邻域扫描、Paper 或 Live。** 它不是频率不足，而是信号本身
在零成本下几乎没有优势，标准成本后 discovery 与 validation 同时为负。OI 下降能证明去杠杆，
taker 翻多能证明短时主动买方占优，但“当前根突破前 4 根高点后立即追入”没有证明突破被市场接受；
`71.8%` 的交易随后触发结构止损。后续不在这 7 个月调整 OI、taker、低点、风险或止盈阈值。
