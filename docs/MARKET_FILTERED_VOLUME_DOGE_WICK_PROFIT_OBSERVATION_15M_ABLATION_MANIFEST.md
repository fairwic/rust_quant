# 15 分钟过滤放量策略：长下影与盈利观察消融清单

## 研究目的

本轮只回答两个相互独立的问题，不覆盖已经落库的 v3：

1. 在原双重成交量门槛成立时，允许 `30 < RSI14 < 70` 的长下影 K 线做多，是否改善跨币种结果。
2. 不改变 v3 入场时，使用“0.5R 观察、1R 前回落确认、1R 后按真实 ATR 目标完成比例保护”的状态机，是否减少盈利回吐。

## 冻结对照组

- 基线：`kline15m_filtered_volume3_weekly_base_volume_p90_rsi_ema_macd_structure_stop_fixed_atr_tp_v3`
- 已落库回测：`back_test_log.id = 17172`
- 数据源：只使用当时已完成的 15 分钟 K 线。
- 样本：Top60，`sample_seed = top60_v36_direct_kline_20260721`。
- 时间范围：`1751328000000..1784470500000`。
- 成本：单边手续费 5 bps，单边滑点 3 bps。
- 仓位：单币种隔离 100U，单笔账户风险 1%。
- 入场、止损、量比分档 ATR 目标、冲突合并均沿用 v3。

## 预注册版本

### v6：只增加中性 RSI 长下影做多

- 原过滤后量比必须 `>= 3`。
- 当前 `vol_ccy` 必须 `>=` 同币种前 672 根的 P90。
- 当前 K 线下影占完整振幅 `>= 60%`，下影严格大于上影，实体占振幅 `> 10%`。
- `30 < RSI14 <= 70`；“未触发 RSI > 70”按字面包含 70 边界。
- 不要求阳线，不增加镜像长上影做空，不改变其他分支。
- 仅当 v3 的 RSI、EMA、MACD 原分支均没有候选方向时补充该信号；已有 v3 交易的方向、触发标签和止损保持不变。
- 触发标签：`neutral_rsi_lower_wick_long`。
- 结构止损：当前 K 线最低价。

### v7：只增加盈利观察状态机

- 入场完全等同 v3。
- 从入场后的下一根完整 K 线开始观察，入场 K 不用于事后武装保护。
- `peak_r >= 0.5` 只进入观察状态，不移动止损。
- 尚未达到 1R 时，仅后续完整 K 线收盘严格低于 `0.25R` 才按收盘退出。
- 达到 1R 后，使用真实逐笔 ATR 目标 `target_r`：
  - `completion = clamp(peak_r / target_r, 0, 1)`
  - `candidate_lock_r = max(0.25, peak_r * max(0, completion - 0.25))`
  - 实际保护位只允许上移，不允许下移。
- 新保护位在计算它的 K 线完成后生成，只从下一根 K 线生效。
- 若计算时收盘已经穿过新保护位，则按该根收盘退出，不虚构盘中保护价成交。
- 同根优先级：已有止损、已有止盈、状态退出、生成下一根有效保护位。

### v8：组合版本

- 入场使用 v6。
- 出场使用 v7。
- 用于检查两项变化是否存在交互，不作为单项效果归因依据。

## DOGE 两个 RSI 底背离未入场的根因

### 2026-07-05

- UI `15:30` 这根自身不是严格低点枢轴，RSI14 为 `41.305361`，过滤量比仅 `1.016612`，`vol_ccy` 也低于周 P90。
- 截图中真正满足代码背离公式的是 `q=12:00` 与 `p=13:30`：低点 `0.07582 -> 0.07558`，RSI14 `27.839200 -> 29.209391`，改善 `1.370191`。
- `p` 要等右侧 `13:45/14:00/14:15` 三根全部完成，确认事件时间为 `14:30`。
- `p` 的过滤量比为 `0.819988`，确认 K 的过滤量比为 `0.455619`；两者的 `vol_ccy` 也都低于周 P90。因此背离成立，但成交量门禁失败。

### 2026-06-25 01:45

- `q=2026-06-24 23:30`、`p=2026-06-25 01:45`：低点 `0.07451 -> 0.07271`，RSI14 `14.498217 -> 16.109119`，改善 `1.610902`，背离公式完整成立。
- 右侧三根完成后的确认事件时间为 `02:45`。`p` 的过滤量比为 `1.324384`，虽通过周 P90，但仍低于 3；确认 K 的过滤量比为 `0.210058`，且周 P90 也失败。
- 策略在确认 K 的成交量前置门禁就返回，尚未执行 RSI 背离候选合并。

这两个案例不能证明 RSI 改善 1 点或左右各 3 根过严。真正冲突是：背离属于枢轴 `p`，策略却要求延迟确认 K `t` 同时极端放量；而仅把成交量检查移回 `p` 也覆盖不了这两个样本。若继续，应另建版本比较“背离分支取消双重成交量门禁”或“已完成 setup window 内量能 OR”，不能后验修改当前版本。

## v7/v8 盈利观察状态机结论

v7 相对 v3：

- 胜率提高 `13.2766` 个百分点，最大单币隔离回撤下降 `11.9386` 个百分点；净 EV 仅改善约 `0.000873R`。
- 净和反而多亏 `1.9279R`，PF 从 `0.800122` 降至 `0.694167`，Sharpe 从 `-4.8145` 降至 `-6.9591`。
- 2,204 个相同入场事件中，状态机带来 `+5.6148R`：382 笔由亏转盈、89 笔由盈转亏。但提前退出释放出的 24 笔额外交易合计 `-7.5427R`，抵消了匹配事件改善。
- 对原 V3 亏损交易，三类保护合计改善约 `+788.0132R`；对原 V3 盈利交易，却合计削减约 `-782.3984R`。这说明状态机确实解决了部分利润回吐，同时几乎等量误杀了最终可恢复或可达目标的赢家。

v8 相对 v6：匹配事件改善 `+55.6162R`，但新增释放出的 62 笔交易亏 `-10.1288R`；最终仍为负 EV/PF。DOGE `2026-07-01 21:30` 在 v8 中由 v6 的 `+1.007642R` 被提前保护为 `+0.494847R`。
