# 过滤量比 + RSI/EMA/MACD 15m V2 评估清单

- 策略家族：`market_filtered_volume_rsi_ema_macd_15m_v1`
- 规则版本：`kline15m_filtered_volume3_rsi_ema_macd_pivot_atr15_v2`

- 对照回测：`back_test_log.id=17171`，规则版本 `kline15m_filtered_volume3_rsi_ema_macd_atr15_v1`

## 固定数据与成本口径

- 数据源：本地 `quant_core` 已完成 15m K 线，不读取 `market_rank_events` 或 episode。
- 币种池：与 `17171` 相同的 current-live Top60，`sample_limit=60`，`sample_seed=top60_v36_direct_kline_20260721`。
- 方向：双向。
- 完整窗口：`1751328000000..=1784470500000`，即 2025-07-01 00:00 UTC 至 2026-07-19 14:15 UTC。
- 开发段：`1751328000000..=1772322300000`，即 2025-07-01 00:00 UTC 至 2026-02-28 23:45 UTC。
- 未见段：`1772323200000..=1784470500000`，即 2026-03-01 00:00 UTC 至 2026-07-19 14:15 UTC。
- 单边手续费：5 bps；单边滑点：3 bps。
- 最长持仓：48 小时。
- 入场：信号完成 K 线收盘价；初始止损：反方向 `1.5 * ATR14`，无固定 3% 截断。
- 目标：过滤量比 `[3,4) / [4,6) / [6,+∞)` 对应 `1.8R / 2.4R / 3.0R`。
- RSI、EMA、成交量、冲突合并及退出规则保持 v1 不变，只评估 MACD v2。

该币种池为了与 `17171` 严格对照而沿用 current-live 口径，存在幸存者偏差；本轮结果只能比较 MACD 修复的增量，不能作为全市场晋级证据。

## 预注册参数网格

先跑一个 MACD 关闭基线，再跑以下九个组合：

| 参数 | 冻结值 |
| --- | --- |
| DIF 零轴缓冲系数 `Z` | `0.10, 0.20, 0.30` |
| 最小归一化 DIF 改善 `D_min` | `0.0005, 0.0010, 0.0020` |

禁止在看到结果后补扫中间值、扩大网格或删除亏损币种。若九个组合全部不具备正增量，结论为 MACD v2 在本轮网格内被证伪。

## 开发段选择规则

1. MACD-only 实际交易至少 100 笔；不足只作低样本诊断。
2. 先按完整策略开发段净 EV 从高到低排序。
3. 净 EV 相同则依次比较完整策略净 PF、MACD-only 净 EV、MACD-only净 PF。
4. 若最佳点周围参数轻微变化即明显崩溃，则标记为边界不稳健，不因单点最优晋级。
5. 即使全部配置为负，仍把开发段排名第一的配置送入一次未见段验证，但只能作为证伪诊断。

## 未见段与完整窗口规则

- 选择完成后不再调整参数，只运行一次 MACD 关闭基线和一次选中配置的未见段。
- 再用选中配置运行完整窗口，报告整体、时间四分位、方向、币种集中度和 RSI/EMA/MACD 分支。
- 有效市场事件预注册代理口径：按开仓时间排序；相邻交易方向相同且时间差不超过 30 分钟时归为同一事件，否则开启新事件。该口径没有板块/相关性数据，只能作为保守的时间方向聚类，不能替代完整相关簇审计。
- 若完整回放未落实统一资金、最大并发、同方向/相关簇风险，则组合回撤仅按当前 legacy symbol-isolated 100U 口径报告，不宣称生产组合权益。

## 判定门槛

- 净 EV `>= 0.6R`
- 净 PF `>= 2.2`
- 最大组合回撤 `<= 15%`；当前 symbol-isolated legacy 口径需单独标明
- Recovery Factor `>= 4`
- Sharpe `>= 1.5`
- 15m 组合频率参考 `50～120` 笔/月

任一职业门槛不满足，不进入 Paper/Live。本轮默认不使用 `--save-backtest-detail`，不写回业务回测表。

### 事件、集中度与结论

- 按预注册的 30 分钟同向邻接规则，3,176 笔交易归并为 1,914 个事件，其中多头事件 877 个、空头事件 1,037 个，平均每事件 1.659 笔，最大簇 19 笔；约 `151.9` 个事件/月。该结果仍未使用板块或相关系数。
- 移除盈利最高的 1/3/5 个币后，symbol-isolated 总利润分别下降到 `-489.908264U/-573.877145U/-609.856314U`；策略不是由少数盈利币掩盖成正收益，而是整体亏损。
- 当前 legacy `symbol_isolated_100u` 没有统一资金、容量与并发风险，无法给出合格的组合 Recovery Factor；55.24% 只能标注为最大单币隔离回撤。
- 最终状态：`research_rejected_no_edge`。不进入 Paper/Live，不落库，不生成新回测 ID，不使用 `back_test_detail`，也不执行任何交易 mutation。
