## 冻结增量规则

- 只在 V3 已经形成 EMA 延续候选后计算距离：`abs(signal_close - EMA144) / ATR14`。
- 距离 `<= 1.0 ATR14` 时保留 EMA 候选；严格大于 1.0 时删除，等于边界可以入场。
- 门禁只作用于 EMA 延续分支，不否决同根已独立成立的 RSI 或 MACD 候选。
- 多头与空头使用完全镜像的绝对距离公式。
- 不叠加 V4 的 BB(12,2.6) 冲突缓冲，保证 V4/V5 是相对 V3 的单变量 A/B。
- 其余过滤量比、周 `vol_ccy` P90、RSI/MACD、下一根开盘成交、结构或 `1.5*ATR14` 止损、固定 ATR 距离止盈和单币隔离权益风险 1% 均保持 V3 口径。
