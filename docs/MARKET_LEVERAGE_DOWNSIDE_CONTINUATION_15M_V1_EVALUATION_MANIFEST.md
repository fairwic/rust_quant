# 杠杆下跌冲量延续 15m V1 评估清单

## 1. 新策略身份与假设来源

- `strategy_key=market_leverage_downside_continuation`
- `version=15m_v1_20260721`
- `entry_rule_version=negative_impulse_6h_24h_oi4h_taker1h_alignment_4h_v1`
- 状态：`research_only`，`promotion_eligible=false`
- 冻结时间：`2026-07-21`，在打开本策略窗口的 Binance metrics 与对应 outcome 前完成；
- 基线 Git HEAD：`438b67af52e64ad4babdc310ddef36c5dddbcc09`

假设来源：双向杠杆资金流延续 V1 在 2025-07～2026-06 被整体淘汰，但预注册方向诊断显示
Long 420 笔标准成本 EV `-0.0903R`，Short 70 笔 EV `0.2867R`、PF `1.5137`、Sharpe `1.6417`。
这不足以晋级，却形成了可证伪的新假设：加密市场中 OI 扩张的上行冲量容易被获利抛压反转，
而 OI 扩张、主动卖出确认的下跌冲量更可能发生杠杆多头踩踏并延续。

本策略是显式 short-only 新身份，不回写或过滤 V1 结果；固定 4h 决策是为了让预期组合频率有机会
落入 15m 策略的 `50～120` 笔/月目标，而不是在验证窗口看到结果后调整。

## 2. 独立验证窗口与数据边界

- OKX 执行价格：已确认 15m；Binance 只提供信号时点可见的 5m metrics；
- 窗口：`2022-07-01T00:00:00Z` 至 `2023-07-01T00:00:00Z`，12 个完整月；
- 币池：`okx_current_live_usdt_swap_prior_month_median_quote_volume_top60_202207_202306`；
- 币池 SHA-256：`b610840ca9272e6db3bd3b9363bd5b6e84fac1e5b02e09a74ffd03db3c3fbdfd`；
- 每月 60 个、合计 81 个当前仍为 live 且 `instCategory=1` 的加密货币 USDT 永续；按用户要求
  排除退市币，并明确接受幸存者偏差；
- 该窗口曾用于其他价格策略，但从未用于“负冲量 + OI 扩张 + 主动卖出”规则；本轮对新因子与
  对应交易 outcome 只打开一次；
- Binance 当前合约映射只接受 `TRADING + PERPETUAL + USDT + underlyingType=COIN`；未映射、404、
  checksum 或 288 行完整性失败只阻塞对应候选，不补值；
- 1m 不参与；Binance 5m 只产生外部因子，最终信号与交易仍为 15m。

## 3. 冻结信号规则

每个 UTC `00:00 / 04:00 / 08:00 / 12:00 / 16:00 / 20:00`，对应 OKX 15m 完成后：

1. 对当月成员计算截至该已完成 K 线的 6h 与 24h 收益；两段必须连续、有限且严格小于零；
2. 数据覆盖先于方向过滤计算；当时币池至少 80% 成员具备完整价格因子，否则整个时点阻塞；
3. 按 6h 收益升序、symbol 字典序打破并列，只保留跌幅最大的前三个价格候选；
4. Binance metrics 只使用至少延迟 5m、最多陈旧 10m 的最新点；最近 1h 必须有连续 12 个 5m 点，
   OI 必须存在精确 4h 对照点；
5. 名义 `sum_open_interest_value` 的 4h 变化必须严格为正；最近 1h
   `sum_taker_long_short_vol_ratio` 中位数必须严格 `<1`；
6. 对通过外部因子的候选仍按第 3 条顺序，每个决策时点最多选择一个；不因风险或容量阻塞递补；
7. 只做空；不使用 K 线颜色、BOS、CHoCH、FVG、影线、funding、残差、回踩或主观形态。

所有输入只读取决策时点以前已经完成和发布的数据；symbol 输入顺序不得改变选择。

## 4. 冻结交易、容量与成本

- 下一根 OKX 15m 开盘入场；
- 初始止损距离为决策时点 `ATR(14) * 2.0`，必须位于入场价的 `0.75%～5.0%`；
- 固定止盈 `2R`，最长持有 `24h = 96` 根；同棒双触按止损；
- 同币不得重叠；组合最多 4 笔并发、同方向最多 3 笔；容量不足不递补；
- 每边手续费与滑点合计 `8bps`，每跨 UTC 8h 时点再计 `1bp` 不利资金成本；双倍成本全部翻倍；
- `1R` 固定为入场时初始止损对应风险，退出不得回写。

## 5. 预注册停止与晋级规则

必须报告价格覆盖、前三下跌冲量、metrics 映射/文件/行、OI+主动卖出通过、风险/容量/不完整漏斗、
交易数、有效事件、月份、币种集中度、退出原因，以及零/标准/双倍成本指标。

以下任一成立即永久淘汰，不扫描决策频率、收益窗口、候选数、OI、taker、ATR、止盈或持仓参数：

- 零成本 EV `<=0R` 或 PF `<=1`；
- 标准成本 EV `<=0R` 或 PF `<=1`；
- 少于 300 笔或 180 个有效事件；
- 少于 8/12 个正收益月；
- 移除前三盈利币后净 R `<=0`。

职业晋级要求标准成本同时满足净 EV `>=0.6R`、PF `>=2.2`、组合频率 `50～120` 笔/月、
Sharpe `>=1.5`，双倍成本仍为正且跨月、币种不集中。交易级全部通过后，才以 0.5% 单笔风险、
2% 最大并发初始风险计算逐时组合权益，要求最大回撤 `<=10%`、Recovery `>=4`、日收益
Sharpe `>=1.5`。
