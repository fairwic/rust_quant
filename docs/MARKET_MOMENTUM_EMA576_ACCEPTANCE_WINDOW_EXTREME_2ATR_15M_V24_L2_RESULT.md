# EMA576 八根接受窗口极值 2ATR：V24 L2 成本后结果

## 结论

V24 在 L2 停止，不进入 L3。冻结的 715 个 L1 候选全部完成文件、集合、逐字段候选和行情身份
复核；715 个都能解析下一根连续 15m 开盘，应用首笔成交规则后形成 397 笔完整交易。成本前仅有
微弱正边际，加入冻结的每边 8bps 成本后转为显著负收益：

- 成本前：`+29.0685R / EV +0.07322R / PF 1.10846`；
- 成本：`123.3525R`，平均 `0.31071R/笔`；
- 成本后：`-94.2840R / EV -0.23749R / PF 0.73236`；
- L2 决策：`stop`。

本轮没有证据支持优先修改止盈或止损。冻结的结构止损使固定价格成本折算为较高 R，但更根本的
问题是信号命中率不足，尤其多头在成本前已经为负。按预注册停止纪律，不得在看到本结果后继续
搜索 ATR 阈值、八根长度、止损缓冲或目标倍数。

## 成本为何会翻转结果

- 总成本为 `123.3525R`，平均 `0.31071R/笔`，中位数 `0.30820R`，P90 为 `0.45815R`；
- 止损交易最大实际成本为 `0.49873R`，仍满足冻结的止损成本 `<=0.50R` 门禁；
- 毛边际只有 `0.07322R/笔`，平均成本是毛边际的 `4.24 倍`；
- 129 笔目标交易平均为 `毛 +2.30286R / 成本 0.30286R / 净 +2R`；
- 268 笔止损交易平均为 `毛 -1R / 成本 0.31449R / 净 -1.31449R`。

在平均赢家 `+2R`、平均输家 `-1.31449R` 下，成本后盈亏平衡胜率约为 `39.6589%`，实际只有
`32.4937%`。因此不是“止损执行太慢”导致本轮失败，而是当前入场命中率无法覆盖结构风险与固定成本。

- 324 个有效事件中 113 个净正、211 个净负；
- BTC 仅 3 笔，净 `-0.7946R`；ETH 为 0 笔；其他币种 394 笔，净 `-93.4894R`；
- 最佳币种为 MERL `+9.6286R`、LAYER `+9.4022R`；最差为 EIGEN `-13.6420R`、
  ONE `-11.4927R`、ATOM `-11.2057R`。

单一币种占全部正 R 的最大比例为 `6.2016%`，单一事件为 `2.3256%`，均低于 35%。这说明失败
不是少数赢家造成的收益集中，而是负边际广泛分布。移除最佳两笔后为 `-98.2840R`，移除最佳事件后
为 `-100.2840R`；两项门禁失败的直接原因是总净 R 原本已经为负。

## 四象限审视

- **已知的已知**：715 个候选零漂移、397 笔交易合同一致；总体和两个方向的成本后结果均为负。
- **已知的未知**：未做统一资金曲线、point-in-time 全市场池、资金费、OOS/walk-forward 与参数邻域；
  因 L2 已失败，这些 L3 项目不应继续执行。
- **未知的已知**：715 个候选不等于 715 笔交易；318 个后续信号被首笔成交规则正确阻塞。成本
  以 R 计很高，是结构止损距离较近的必然换算结果，而不是报告重复扣费。
- **未知的未知**：哪些新的、仅使用信号时可见数据的结构特征能够提高命中率尚未建立可证伪假设；
  不能从本次赢家/输家结果反向挑选阈值。

## 冻结门禁与最终决策

通过：候选与合同身份、交易/方向/币种/月/事件覆盖、总体成本前 `EV>0/PF>1`、币种与事件正收益
集中度上限。

失败：

1. 总体成本后 `EV>0/PF>1`；
2. 多头与空头分别成本后为正；
3. 移除最佳两笔后总净 R 为正；
4. 移除最佳事件后总净 R 为正。

最终状态固定为 `stopped_at_l2_negative_cost_adjusted_edge`。V24 保持 Research-only，不进入 L3，
不创建 Pine，不接 Paper、ReadOnly、Live、worker、调度、compose 或生产，也不触发真实交易。

如果继续研究，应另建一张只改变一个“信号时可见入场质量变量”的 L1 假设卡；止盈、止损、成本、
持仓与候选池继续冻结。新变量必须先做无 outcome 覆盖，不能直接用本次 397 笔的胜负反向筛选。
