# EMA576 八根接受窗口极值 2ATR：V24 L1 结果

## 结论

V24 已按用户纠正完成，并通过 L1 无 outcome 覆盖门禁。V23 错把动量距离固定在第 2 根
确认 K 的收盘价；V24 改为第 1～8 根接受窗口内任一完成 K 的顺势极值达到 `2.00 ATR14`
即可。两根收盘确认、连续 8 根同侧收盘、EMA576 盘中反向穿越否决和 EMA144/576 原关系
保持到信号的规则均未改变。

冻结公式为：

- 多头：`max((High[i] - EMA576[i]) / ATR14[i]), i=1..8 >= 2.00`；
- 空头：`max((EMA576[i] - Low[i]) / ATR14[i]), i=1..8 >= 2.00`。

每根使用当根已完成 K 的 EMA576 和 ATR14。第 8 根完成后才确认；第 9 根及以后出现的极值
不能回填旧突破。
