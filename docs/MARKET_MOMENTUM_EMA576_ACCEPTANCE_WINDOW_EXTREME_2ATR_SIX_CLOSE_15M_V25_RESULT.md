# EMA576 六根接受窗口极值 2ATR：V25 L1 结果

## 结论

V25 已把 V24 的连续 8 根同侧收盘与 2ATR 顺势极值窗口同步缩短为 6 根，并通过 L1 无 outcome 覆盖门禁。V24 的八根版本保持原行为；第 7 根不能回填 V25，但仍属于 V24 的窗口。

冻结公式为：

- 多头：`max((High[i] - EMA576[i]) / ATR14[i]), i=1..6 >= 2.00`，且第 1～6 根收盘全部严格高于 EMA576；
- 空头：`max((EMA576[i] - Low[i]) / ATR14[i]), i=1..6 >= 2.00`，且第 1～6 根收盘全部严格低于 EMA576。

第 2 根确认完成后至第 6 根完成前继续执行 EMA576 盘中反向穿越否决。只有第 6 根完成后才能确认，第 7 根及以后不得补认旧突破。
