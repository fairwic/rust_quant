# EMA576 突破确认距离 2.5 ATR V18 结论

## 结论

2.5 ATR 突破距离能拒绝用户指出的 ADA 与 ONT 弱突破，但它删除了绝大多数原始机会，且保留子集的毛结果和成本后结果均为负。V18 固定为 `stop / Research-only`，不应采用或继续围绕该样本调节距离阈值。

## 因果定义

- 多头：第二根突破确认 K 的完成收盘满足 `(close - EMA576) / ATR14 >= 2.50`。
- 空头镜像：`(EMA576 - close) / ATR14 >= 2.50`。
- 只使用确认 K 的收盘、同棒 EMA576 与当时可见 ATR14；影线不算突破距离。
- 入场、结构止损、净 2R 目标、0.50R 成本门禁及资金路径全部沿用 V16。

## L1 无标签覆盖

- 冻结 V16 可入场机会：8,732 个。
- 拒绝：8,178 个，占 `93.6555%`；只保留 554 个。
- 保留方向：多头 398、空头 156；覆盖 44 币、13 月、342 个事件。
- 距离分布：P50 `0.7617 ATR`、P75 `1.3314 ATR`、P90 `2.0827 ATR`、最大 `6.8829 ATR`。
- ONT 目标样本只有 `1.1054 ATR`；ADA 目标样本只有 `0.8867 ATR`，均按预期拒绝。

## 冻结 L2

- 完成交易：179 笔，覆盖 162 个有效事件。
- 毛结果：`-10.272R / EV -0.057388R / PF 0.919747`。
- 成本后结果：`-63.206R / EV -0.353104R / PF 0.617412`。
- 条件过滤率很高，但保留下来的强距离突破并没有更高胜率或更好盈亏结构；它不是有效的质量分离变量。

## 决策

- 拒绝 2.5 ATR 作为当前策略的突破有效性门槛。
- 不基于当前 outcome 搜索 2.0、1.5 或其他距离；若未来重启，必须使用新样本和新的独立预注册。
