# EMA576 资格周期 + 2.0 ATR + 8 根接受 V21 结论

## 结论

把 V20 的突破距离从 2.50 ATR 单独放宽到 2.00 ATR 后，保留机会由 325 个增加到 623 个，
多空最低覆盖已经恢复。但实际影响率 `92.8653%` 低于事前冻结区间 `93.5%～96.3%`，因此 V21
按预注册固定为 `stopped_at_l1_impact_below_preregistered_range`，没有读取 outcome 或运行 L2。

这不是“2.00 ATR 没有增加信号”，而是它增加信号的幅度超过了事前预计；不能在看到结果后把覆盖
区间下限改成 92.8% 再补跑收益。

## 唯一变化与保持项

- 唯一变量：第二根突破确认收盘距离由 `>=2.50 ATR14` 改为 `>=2.00 ATR14`。
- V17 资格关系周期、第一根越线起连续 8 根同侧收盘、EMA144±0.30ATR 提前回踩否决不变。
- V16 下一根连续开盘、首笔真实成交、EMA144±0.30ATR 结构止损、净 2R 目标、每边 8 bps、
  0.50R 止损成本门禁与冲突顺序不变。

## L1 无标签结果

- V16 合格机会：8,732 个。
- V21 三项全过：623 个，保留率 `7.1347%`；拒绝 8,109 个，影响率 `92.8653%`。
- 相对 V20：净增加 298 个机会，保留数增加 `91.69%`。
- 方向覆盖：多头 398、空头 225；覆盖 44 个币、13 个北京时间月份、387 个一小时方向事件。
- ADA `2026-07-19 01:15` 空头仍在 `2026-07-08 18:15` 因旧资格周期结束首先失效。
- ONT `2026-07-19 09:45` 多头仍只通过资格周期；其突破距离与八根接受不通过。
- L1 禁止字段检查通过，没有用退出时间、MFE、MAE、最终 R、胜负或 PnL 决定候选。

## 决策

- 唯一失败门禁为 `affected_ratio_within_preregistered_range=false`；其余目标、方向、币种、月份与
  事件覆盖门禁全部通过。

- V22 的独立预注册已在 V21 结果产生前完成，因此可作为下一张单变量卡片继续，而不是对 V21
  事后修改覆盖区间。
