# EMA576 资格周期 + 2.0 ATR + EMA576 八根保持 V22 结论

## 结论

V22 已完整实现用户本轮指定规则：2.00 ATR 突破、连续 8 根 EMA576 同侧收盘，并在确认后到第八根
期间禁止价格盘中严格穿越 EMA576。它通过 L1 并完成一次冻结 L2，但成本前已经略为负期望，计入
每边 8 bps 后净 `-70.0868R / EV -0.3129R / PF 0.6566`，多空均负，固定为
`stopped_at_l2_negative_entry_edge`。

EMA576 盘中保持并不是一次有效放宽：相对 V21 最终组合纯删除 10 个多头机会、没有新增机会。
因此当前不应通过调整止盈止损掩盖入场本身在成本前都没有正边际的问题。

## 冻结规则

候选必须同时满足：

1. 从长期资格完成到突破确认，EMA144/576 原方向关系周期不能中断。
2. 第二根突破确认收盘方向性距离 EMA576 至少 `2.00 ATR14`。
3. 第一根越线收盘起连续完成 8 根 EMA576 同侧收盘；突破确认之后到第八根完成期间，多头最低价
   严格低于当棒 EMA576 即失效，空头最高价严格高于当棒 EMA576 即失效；等于均线允许。
4. 第八根与后续 EMA144 回踩信号不得复用；入场及风控仍沿用 V16 冻结合同。

## L1 无标签结果

- V16 合格机会：8,732 个。
- V22 三项全过：613 个，保留率 `7.0202%`；拒绝 8,119 个，影响率 `92.9798%`。
- 方向覆盖：多头 388、空头 225；覆盖 44 个币、13 个北京时间月份、381 个一小时方向事件。
- 所有预注册 L1 门禁通过，ADA 与 ONT 仍按因果规则被拒绝。
- 相对 V21 最终交集：删除 10 个、增加 0 个；10 个全部是多头，分布在 VIRTUAL、YFI、EIGEN、
  LTC、RSR、RENDER 六个币。

单看八根接受组件，V21 的 EMA144 回踩区规则通过 5,450 个 V16 合格机会；替换为 EMA576 盘中
保持后通过 4,413 个。新边界删除 1,109 个、释放 72 个，净减少 1,037 个，说明在本样本中它整体
更严格，而不是更宽松。

## L2 成本后诊断

- L1 可解析机会 613 个；按首笔真实成交与成本门禁后完成交易 224 笔，覆盖 44 个币、13 个月、
  196 个有效市场事件；多头 144、空头 80，月均 `17.23` 笔。
- 退出：67 笔目标、157 笔止损，胜率 `29.91%`。
- 成本前：`-2.7977R / EV -0.01249R / PF 0.98218`，已经没有正入场边际。
- 成本后：`-70.0868R / EV -0.31289R / PF 0.65658`，最大交易序列回撤 `81.5159R`。
- 多头：`-42.7242R / EV -0.29670R / PF 0.66810`。
- 空头：`-27.3626R / EV -0.34203R / PF 0.63692`。
- 13 个自然月仅 3 个月净正；移除头部事件或头部两笔后均为 `-74.0868R`，不存在靠单一赢家
  掩盖负边际的情况。

## 判断与下一步

- 这轮主要问题是入场质量，不是止盈止损过早：毛 PF 已小于 1，继续调目标或止损会混入第二变量。
- `2.00 ATR` 的确恢复了方向覆盖；真正与“适当放松”相冲突的是盘中不得穿越 EMA576，它在历史
  候选上净减少 1,037 个八根接受机会。
- 若继续，下一轮唯一值得验证的变量是：保留 `2.00 ATR + 8 根同侧收盘`，删除盘中高低价否决，
  只用完成收盘是否回到 EMA576 另一侧判定八根失败。该定义才是严格意义上的放宽。
- V22 停止在 Research-only，不进入 L3；未创建 Pine，未接 Paper、ReadOnly、Live、调度、
  compose 或生产，未写数据库或触发交易。
