# 15m 动量衰竭反转 V2 评估清单

## 本轮唯一假设

在 V1 的“96 根单向净移动 + 过滤后异常量 + 周成交额 P90”基础上，只检验两项变化：

1. 方向性长影线不再紧邻下一根开盘追价，而是在 `p` 的影线极值挂限价，最多等待 12 根；
2. 成交量越极端，止盈距离越大。

V1 保持冻结。本版本不读取 RSI、MACD、EMA、平台、布林带、BOS、FVG、CHoCH 或
`market_rank_events`。

## 冻结信号

1. 信号 K 记为 `p`，只使用当时已完成的 15m K 线。
2. `p` 的过滤后量比必须 `>=2.5`：
   - 逐根因果标记 `p` 前精确十根中的历史异常量；
   - 历史 K 达到其自身此前十根原始均量 `2.5` 倍即从当前基线剔除；
   - 剔除后至少保留五根，`p` 不进入自己的均量分母。
3. `p.vol_ccy` 必须不低于 `p` 前连续 672 根的 nearest-rank P90。
4. `p` 前精确 96 根（不含 `p`）从首根开盘到末根收盘：
   - 净下跌至少 8%：只创建做多 setup；
   - 净上涨至少 8%：只创建做空 setup。
5. 不要求 `p` 收阳或收阴。
6. 方向性长影线要求：
   - 实体占完整振幅严格大于 10%；
   - 对应方向影线占完整振幅至少 60%；
   - 对应方向影线严格长于反方向影线。

## 冻结成交

- 长下影做多：在 `p.low` 挂买入限价；长上影做空镜像在 `p.high` 挂卖出限价。
- 有效窗口为 `p+1` 至 `p+12`，两端均包含；盘中触及限价即按 `p` 极值成交。
- 跳空穿越仍按冻结限价成交，不使用更有利的跳空价格。
- 同币种出现更新的有效 `p` 时，旧的未成交 setup 作废，由最新 `p` 替换，不叠加挂单。
- 每根 K 先判断旧限价是否盘中成交，再用该 K 收盘后的完整信息判断是否出现新 `p`。
- 非方向性长影线仍沿用 V1：只允许 `p+1` 严格突破 `p.high` 做多或严格跌破 `p.low`
  做空；未触发立即失效。

## 冻结风险与成本

- ATR：冻结 `ATR14[p]`。
- 初始止损：实际成交价反方向 `1.5 * ATR14[p]`。
- 止盈：
  - `2.5 <= 过滤后量比 < 4`：`2.7 ATR`，毛目标 `1.8R`；
  - `4 <= 过滤后量比 < 6`：`3.6 ATR`，毛目标 `2.4R`；
  - `过滤后量比 >= 6`：`4.5 ATR`，毛目标 `3.0R`。
- 同一根 K 同时触及止损和止盈时按止损优先。
- 最长持仓 48 小时；单笔账户风险 1%；单边手续费 5 bps；单边滑点 3 bps。
- 不启用移动止损、盈利保护、持仓二次放量保护或趋势目标调整。
