# 15m 动量衰竭反转 V2 回测结果

## 结论

V2 已按预注册规则完成首轮回测并写入数据库，但整体仍为稳定负期望，结论为
`research_rejected_no_edge`。不得进入 Paper/Live，也不能用“长影线限价相对最好”这一事后切片
直接晋级新版本。

方向性长影线改为在 `p` 极值等待 12 根、并按量比放大止盈后，没有改善整体信号质量。相对 V1，
净 EV 从 `-0.142040R` 下降到 `-0.187622R`；净 PF 基本持平，但仍远低于 1。
