# 15m 动量衰竭反转 V3（55% 方向影线）评估清单

## 本轮唯一假设

V2 把方向性长影线定义为“对应影线占完整振幅至少 60%”。本轮只把该阈值调整为
`55%`，检验原本落在 `55%..60%` 区间的价格拒绝形态改为在 `p` 极值等待成交后，能否改善
整体入场质量。

V2 保持冻结。96 根净移动、过滤后量比、周成交额 P90、12 根限价有效期、ATR 止损与量比分档
止盈均不得随结果调整。

## 唯一行为差异

方向性长影线同时满足：

1. 实体占完整振幅严格大于 10%；
2. 做多时下影线、做空时上影线占完整振幅至少 55%；
3. 对应方向影线严格长于反方向影线。

满足时：

- 长下影做多在 `p.low` 挂限价；
- 长上影做空在 `p.high` 挂限价；
- 有效窗口仍为 `p+1` 至 `p+12`，两端均包含；
- 更新的有效 `p` 仍替换旧的未成交 setup。

未达到 55% 时，仍只允许紧邻 `p+1` 盘中严格突破 `p.high` 做多或严格跌破 `p.low` 做空。

## 其余冻结信号

1. 只使用当时已完成的 15m K 线，不读取 `market_rank_events`。
2. `p` 的过滤后量比必须 `>=2.5`，剔除历史异常量后至少保留五根。
3. `p.vol_ccy` 必须不低于 `p` 前连续 672 根的 nearest-rank P90。
4. `p` 前精确 96 根不含 `p`：
   - 首开到末收净下跌至少 8%：寻找反转做多；
   - 首开到末收净上涨至少 8%：寻找反转做空。
5. 不读取 RSI、MACD、EMA、平台、布林带、BOS、FVG 或 CHoCH。
6. 不要求 `p` 收阳或收阴。

## 冻结风险与成本

- ATR：冻结 `ATR14[p]`。
- 初始止损：实际成交价反方向 `1.5 * ATR14[p]`。
- 止盈：
  - `2.5 <= 过滤后量比 < 4`：`2.7 ATR`，毛目标 `1.8R`；
  - `4 <= 过滤后量比 < 6`：`3.6 ATR`，毛目标 `2.4R`；
  - `过滤后量比 >= 6`：`4.5 ATR`，毛目标 `3.0R`。
- 同根同时触及止损与止盈时止损优先。
- 最长持仓 48 小时；单笔账户风险 1%；单边手续费 5 bps；单边滑点 3 bps。
- 不启用移动止损、盈利保护、持仓二次放量保护或趋势目标调整。
