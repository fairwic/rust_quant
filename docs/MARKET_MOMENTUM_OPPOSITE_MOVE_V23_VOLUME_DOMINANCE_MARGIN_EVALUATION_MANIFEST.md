# Market Momentum Opposite Move v23 量能优势余量评估清单

## 1. 策略身份与本轮唯一变化

v23 仍是同一个 `market_momentum_opposite_move_reversal` 策略：

- 产品 slug：`market-momentum-opposite-move-reversal`
- 数据库策略类型：`market_velocity_kline_15m`
- 规则版本：`kline15m_market_momentum_opposite_reversal_top60_volume_margin_v23`

本轮从 v21 分叉，不保留已失败的 v22 反转阳线 3% 门槛。唯一变化是把当前三根反转
簇相对过去 96 根已确认低点极值簇的最大成交量门槛，从“不低于”提高为“至少高出
20%”，即 `entry_min_exhaustion_volume_dominance_ratio: 1.0 -> 1.2`。

这直接对应“之前低点的放量都没有触发大反转，当前缩量更不能开仓”：只有当前量能
不仅超过历史低点，而且具备明确余量时才接受。Top60 排名、自身滚动成交额增长、
long-only、BTC 震荡、历史整体下跌/长时间分支、当前收阳、反转/均线确认、3% 止损、
Volume-ATR 止盈和成本全部保持 v21 不变。

## 2. 开发池与停止规则

Top60 已全部查看，本轮仍是开发验证，`promotion_eligible=false`。查看结果前冻结：

- 原始成交至少 30 笔，30 分钟同方向最宽松归并的有效事件下界至少 20 个；
- 净 EV `<=0R`、PF `<=1`、后半段 EV `<=0R` 或半数及以上成交品种亏损则淘汰；
- 固定 1.2 候选通过后才运行预注册的 1.1/1.3 邻域，两个邻域都必须 EV `>0R`、
  PF `>1`，不从中改选最佳值；
- 候选和邻域均通过才允许冻结新的 Top100 未见池。正式晋级门槛仍为净 EV
  `>=0.6R`、PF `>=2.2`、组合最大回撤 `<=15%`、Recovery `>=4`、Sharpe
  `>=1.5` 及主项目的全部稳健性和实盘证据。

## 3. 预注册执行口径

使用 v21 Top60 完整开发池命令，不设 `min_price_change_pct`，不设 symbol blocklist；
唯一策略参数变化为：

```text
--entry-min-exhaustion-volume-dominance-ratio 1.2
```

仍不带 `--save-backtest-detail`。

## 4. 执行结果

- 1.2 量能余量产生 30,657 个原始排名事件，116 个通过完整信号层；BTC 震荡过滤后
  形成 79 笔实际成交，覆盖 46 个品种。30 分钟同方向最宽松归并后为 59 个有效事件
  下界，样本量合格。
- 79 笔均有固定初始 R；累计 `+6.1290R`、EV `+0.0776R`、PF `1.1059`、
  trade Sharpe `0.3971`、胜率 `30.38%`、最大回撤 `14.82%`。
- 前半段 EV `+0.4358R`、PF `1.6661`，后半段 EV `-0.2380R`、PF `0.7032`；
  Q1/Q3 为负，Q4 仅接近盈亏平衡，仍只有 Q2 明显盈利。
- 46 个成交品种中 28 个亏损，超过半数；最佳 BONK 贡献 89.07% 总利润，移除前三个
  盈利品种后整体转为 `-18.34U`。

v23 的量能余量改善了 v21 的整体 EV，但同时触发后半段 EV/PF、亏损品种比例与集中度
停止线，按预注册规则不运行 1.1/1.3 邻域、不保存正式回测。失败分段持续集中在较长
市场下行期，下一步只能研究可在信号当时计算的广义市场方向门禁，不能按日期删除。
