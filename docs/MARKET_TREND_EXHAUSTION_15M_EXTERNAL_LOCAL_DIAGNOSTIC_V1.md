# 15m 趋势耗竭外部证据与本地量价诊断 V1

## 1. 目的与边界

本轮不优化 V2 的 8 根重置长度，也不把 MACD、FVG、BOS 或网络文章直接拼成开仓
条件。目标是先验证 V1/V2 的核心假设是否错误：量比高且振幅扩张的趋势方向 K 线，
究竟更接近反转耗竭，还是趋势继续推进。

诊断只标注 V2 基线实际成交，不对子集重新回放，因此不会因为同币持仓锁变化而生成
基线中不存在的交易。setup 后三根 K 线只用于失败路径归因，明确标记为
`causal_at_entry=false`；它们不能回填或改写 V2 入场。

## 2. 外部可复核依据

- TradingView 官方 Volume 指南：价格方向与放量同时出现通常确认趋势；长趋势后高量但
  价格推进很小，才更接近潜在反转。
- TradingView 官方图表形态说明：反转形态需要价格向原趋势反方向突破，并由收盘确认，
  不能只凭极端量猜顶/底。
- TradingView Relative Volume：普通量比为当前量除以前期均量；CEX 横截面对比需要先
  转为 USD 成交额。V2 只做单币时间序列量比，不把合约张数直接跨币比较。
- OKX 官方 K 线合同：`confirm=1` 才是已完成 K 线；衍生品 `vol` 是合约张数，
  `volCcy` 是基础币数量，`volCcyQuote` 是计价币成交额。
- Wen 等人的加密市场研究表明日内 momentum 与 reversal 会同时存在，并受跳跃、流动性
  和市场状态影响，因此“历史趋势后统一反向”不能被当成稳定事实。
- Zaremba 等人的跨币研究显示流动性较差资产更偏短期反转，而最大、最可交易币更偏动量；
  当前 live 全市场不能默认使用同一反转语义。

## 3. 结果读取前冻结的诊断维度

全部维度只统计 V2 实际成交的固定初始净 R：

1. `direction`：long / short；
2. `setup_body_alignment`：setup 实体已经反向，或仍沿原趋势推进；
3. `setup_body_ratio`：`<20%`、`20%~50%`、`50%~80%`、`>=80%`；
4. `directional_close_rejection_ratio`：收盘从原趋势极值退回的相对位置，使用相同四档；
5. `directional_wick_ratio`：反转方向影线 `<10%`、`10%~25%`、`25%~40%`、`>=40%`；
6. `volume_ratio`：`<2x`、`2x~3x`、`3x~5x`、`>=5x`；
7. `range_expansion_ratio`：`<1.4x`、`1.4x~2x`、`2x~3x`、`>=3x`；
8. `setup_open_reclaim_3`：下一根收回、第二至三根收回、三根内未收回。该维度仅作
   future-path 诊断，不是 V2 的因果入场特征。

本轮不根据结果改变分桶边界。只有外部证据与本地实际交易归因方向一致时，才允许另立
V3 manifest；V3 必须在确认 K 线完成后按当时价格入场，未在三根内确认则过期。

## 4. 冻结运行参数

沿用 V2 全部币池、样本、趋势、量比、振幅、止损、Volume-ATR、成本和持仓参数，
唯一增加输出开关：

```text
--equity-price-volume-diagnostic-report
```

## 5. 冻结诊断结果

按 V2 原命令只增加诊断输出，状态扫描仍为 216 个交易对、97,037 次 armed、
96,930 次中性重置、66,902 个去重前有效 setup、17,566 个状态后 setup；实际成交
16,288 笔，缺失固定初始 R 和 setup 的交易均为 0。

本地结果否定了“量比越极端、振幅越大就越接近反转耗竭”的核心假设：

| 维度 | 分组 | 交易数 | 净 EV | PF |
|---|---|---:|---:|---:|
| 方向 | long | 9,159 | -0.117622R | 0.820937 |
| 方向 | short | 7,129 | -0.010403R | 0.983242 |
| 量比 | 2～3x | 7,533 | -0.033015R | 0.947100 |
| 量比 | 3～5x | 5,445 | -0.088248R | 0.864533 |
| 量比 | 5x 以上 | 3,310 | -0.127569R | 0.807507 |
| 振幅扩张 | 1.4～2x | 7,415 | -0.055306R | 0.912689 |
| 振幅扩张 | 2～3x | 6,008 | -0.075676R | 0.881546 |
| 振幅扩张 | 3x 以上 | 2,865 | -0.100072R | 0.849637 |

15,346 笔、占 94.22% 的 setup 实体仍沿历史趋势方向推进，其净 EV/PF 为
`-0.071135R/0.889046`；setup 实体已经反向的 942 笔也只有
`-0.063515R/0.900845`。实体占比四档全部为负，说明“高量但小实体”本身也不足以构成
反转条件。

future-path 诊断显示，V2 原入场后下一根收回 setup 开盘价的 2,295 笔按**旧入场价**
计算为 `+0.130377R/PF 1.226293`，第二至三根收回的 2,492 笔为
`+0.204056R/PF 1.371124`；三根内不收回的 11,501 笔为
`-0.170350R/PF 0.747188`。这只能证明后续路径与结果有关，不能证明生产可执行的延迟入场
有优势。基于该外部与本地一致方向，另立 V3，并按真实确认后下一根开盘成交；结果见
`MARKET_TREND_EXHAUSTION_SETUP_OPEN_RECLAIM_15M_V3_EVALUATION_MANIFEST.md`。
