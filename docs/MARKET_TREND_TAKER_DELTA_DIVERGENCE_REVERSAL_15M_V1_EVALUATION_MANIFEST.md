# 15m 历史趋势 Taker Delta 背离反转 V1 评估清单

## 1. 策略身份与唯一假设

- 产品 slug：`market-trend-taker-delta-divergence-reversal`
- 规则版本：`okx15m_binance15m_taker_delta_divergence_one_shot_v1`
- 状态：`research_only`，`promotion_eligible=false`

本版本不再把总成交量直接解释为买压或卖压。唯一新增信息是 Binance USD-M 官方
15m K 线中的 `quote asset volume` 与 `taker buy quote asset volume`：

```text
taker_buy_share = taker_buy_quote_volume / quote_volume
signed_imbalance = 2 * taker_buy_share - 1
```

V1 只检验价格与主动成交方向的背离：历史下跌背景中的放量阴线，如果主动买入份额
至少 60%，视为下跌仍在发生但买方正在主动承接，下一根开盘做多；历史上涨背景中的
放量阳线，如果主动买入份额至多 40%，视为上涨仍在发生但主动卖出占优，下一根开盘
做空。60%/40% 等价于 `abs(signed_imbalance) >= 0.20`，在读取结果前固定；本轮不扫描
55%/45%、65%/35% 或其他阈值。

该假设来自 Volume Delta/footprint 对“价格方向与 delta 方向不一致”的公开定义，但
仅把它当成待验证线索，不预设必然反转。

## 2. 数据边界与时序

- 开发窗口：`2025-07-01 00:00:00` 至 `2026-07-01 00:00:00`，UTC；
- 独立旧窗口：`2024-07-01 00:00:00` 至 `2025-07-01 00:00:00`，UTC；
- OKX 价格、总量、入场和持仓路径只读取本地 `quant_core` 中 `confirm='1'` 的原生
  15m K 线；不读取 1m、`market_rank_events`、episode、盘口或未来 K 线；
- 主动成交方向只读取 Binance USD-M 官方原生 15m 月包，不通过 1m K 线推断；每个
  ZIP 必须通过官方 `.CHECKSUM` SHA-256 校验，缺失或无效月份按不可用处理；
- Binance 方向棒与 OKX setup 必须具有相同 15m 开盘时间；信号只在两边该棒都完成后
  产生，入场固定为下一根 OKX 15m 开盘，不用信号后的高低点决定是否入场；
- 每月使用已冻结的 current-live OKX USDT 永续 top60 币池，并再次要求对应 Binance
  合约当前为 `TRADING + PERPETUAL + USDT + COIN`；当前退市币不参与，同时明确承认
  current-live 口径存在幸存者偏差；
- `1000PEPE`、`1000SHIB` 等仅按已登记合约乘数映射；买入份额使用同一 Binance
  合约内部的 quote volume 比值，不做跨交易所绝对量比较。

## 3. 冻结入场与一次性状态

- 历史趋势背景沿用前序 V2：当前 setup 之前 192 根净涨跌至少 8%，或前 96 根收盘价
  线性趋势同向且 R² 至少 0.60；多空同时成立时按中性；
- setup 必须延续历史趋势实体：下跌背景为阴线，上涨背景为阳线；实体占振幅至少
  20%，OKX 当前量 / 前 20 根均量至少 2.0，当前振幅 / 前 20 根均幅至少 1.4；
- 下跌背景 + 阴线 + Binance `taker_buy_share >= 0.60`，下一根 OKX 开盘做多；
- 上涨背景 + 阳线 + Binance `taker_buy_share <= 0.40`，下一根 OKX 开盘做空；
- 趋势首次成立后只允许交易第一个满足全部条件的 Taker Delta 背离 setup；消费后必须
  连续 8 根中性 15m K 线才重置。方向直接翻转不能绕过中性重置；
- 窗口开始前的历史用于状态热身，但只有窗口内完成的 setup 可产生交易；同一币种持仓
  期间不重叠开仓。

## 4. 冻结退出与成本

- 初始止损固定为入场价 3%，且任何一笔都必须先形成止损价格；
- ATR14 与 setup 量比只使用 setup 完成时可见数据：量比 2～3 使用 `2 * ATR14`，
  量比至少 3 使用 `3 * ATR14`；距离除以 3% 初始风险后乘 4，并限制在 1.8R～3R；
- 最长持有 48 小时；同一根同时触发止损和止盈时保守按止损先发生；
- 手续费 5 bps、滑点 3 bps，开平两边分别计入；另报告双倍成本压力；
- `R` 固定为入场时 3% 初始止损距离。本轮只报告交易级/单币隔离指标，不把它冒充
  已完成统一资金、并发容量和相关簇约束的组合权益。

## 5. 预注册门禁与停止规则

- 两个年度窗口分别报告：交易数、月频、有效市场事件、多空、前后半段、四分位、
  月度、成本压力和移除前三盈利币后的结果；
- 继续研究的最低条件：两个窗口的成本后净 EV 都 `> 0`、PF 都 `> 1`，且各自前后
  半段不能出现负 EV；任一失败即淘汰，不在已查看结果上修改 60%/40%、量比、趋势、
  重置、止损或止盈；
- 职业级候选仍要求净 EV `>= 0.6R`、PF `>= 2.2`、Sharpe `>= 1.5`，并在后续统一
  组合回放中满足最大回撤 `<= 15%`、Recovery `>= 4`；
- 全市场 15m 目标频率为 50～120 笔/月。频率不足不放宽信号，频率过高也不能替代
  正 EV；
- 失败则保持 `research_only`，不写回测业务表、不生成生产回测 ID、不进入 Paper/Live。

## 6. 公开定义来源

- [TradingView Volume Delta](https://www.tradingview.com/support/solutions/43000725057-volume-delta/)：
  说明 delta 用较低层级成交量估计或聚合买卖压力；
- [TradingView Volume Footprint](https://www.tradingview.com/support/solutions/43000726164-volume-footprint-charts-a-complete-guide/)：
  说明价格与 delta 的背离可能代表趋势减弱或反转，
  但需要进一步验证；
- [Binance Public Data](https://github.com/binance/binance-public-data)：说明 USD-M 原生 K 线月包包含总 quote volume 与 taker buy
  quote volume，并提供 `.CHECKSUM`；
- [OKX API](https://app.okx.com/docs-v5/en)：逐笔历史成交包含 side，但官方历史端点只覆盖最近三个月，因此不用于本轮
  双年度回放。

## 10. 最终判定

V1 状态为 `rejected_temporal_instability_concentration_and_low_frequency`，保持
`research_only`、`promotion_eligible=false`。

拒绝原因不是单一指标：独立旧窗口连零成本都为负；开发窗口 Q2/Q3 负向且移除前三
盈利币后转负；两窗方向、月份和集中度均不稳定；合并 EV/PF 接近零；频率只有目标下限
的约四分之一。按预注册停止规则，本轮不在已查看结果上扫描 55%/45%、65%/35%、
只做多、只做空、量比、趋势或退出参数。

本轮未写回测业务表，因此没有回测 ID；没有写入 Paper/Live，也没有触发交易 mutation。
后续若继续，方向量不应再直接升级为交易门禁。更合理的是先建立独立的多棒累计 delta
因子面板，预注册分桶与固定 1h/4h forward return，确认它相对单棒价格/总量是否有稳定
增量信息，再决定是否创建新策略版本。
