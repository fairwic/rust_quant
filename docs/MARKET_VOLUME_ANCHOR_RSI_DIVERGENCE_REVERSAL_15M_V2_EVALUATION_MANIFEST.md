# 15m 放量锚点 RSI 背离反转 V2 评估清单

## 单一研究假设

V1 把最近两个方向性异常放量锚点直接配对，但相邻锚点可能仍属于同一次噪声脉冲，锚点之间也可能
已经完成一次反方向 RSI 摆动。V2 只检验以下单变量假设：

> 最近合格锚点 `q` 与当前信号 K `p` 之间至少存在 4 根完整 K，且 RSI 没有越过反方向摆动重置线，
> 能否提高放量锚点 RSI 背离的信号质量。

V2 不新增或读取历史 96 根净移动、MACD、EMA、平台、布林带、BOS、FVG、CHoCH 或排名动量事件。

## 冻结锚点与背离规则

1. 只使用信号时点已经完成的 15m K 线。
2. 当前异常放量 K 为 `p`；在 `p` 前最多 48 根中，仍先选择最近的同方向合格异常放量 K 为 `q`：
   - 做多侧 `q/p.RSI14 <= 30`，做空侧 `q/p.RSI14 >= 70`；
   - `q/p` 在各自时点的因果过滤量比均 `>=2.5`；
   - `q/p.vol_ccy` 均不低于各自此前连续 672 根的 nearest-rank P90。
3. 最近 `q` 固定后才检查 V2 周期门禁，不允许因门禁失败回退到更早锚点：
   - `p_idx - q_idx - 1 >= 4`，即 `q` 与 `p` 之间至少有 4 根完整 K；
   - 做多时，`q` 与 `p` 之间任一 RSI14 `>60`，该 `q` 失效；
   - 做空时，`q` 与 `p` 之间任一 RSI14 `<40`，该 `q` 失效；
   - RSI 恰好等于 60/40 仍允许；
   - 任一中间 RSI 缺失或非有限数时失败关闭。
4. 周期门禁通过后才接受 V1 的价格/RSI背离：
   - 做多：`p.low < q.low` 且 `p.RSI14 >= q.RSI14`；
   - 做空：`p.high > q.high` 且 `p.RSI14 <= q.RSI14`；
   - RSI 相等允许。
5. 成交方式完全沿用 V1：
   - 方向性长下/上影线：紧邻下一根开盘成交；
   - 其他形态：只在紧邻下一根盘中严格越过 `p.high/p.low` 时成交；
   - 紧邻下一根未触发即过期。
