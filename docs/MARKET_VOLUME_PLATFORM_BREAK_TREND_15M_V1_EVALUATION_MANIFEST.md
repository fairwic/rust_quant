# 15m 放量平台破位趋势 V1 评估清单

## 最小假设

窄平台被强实体异常放量 K 线突破，随后连续两根收盘保持在平台外，同时长期均线组已经同向排列且
EMA696 斜率同向时，顺势延续可能具有独立交易优势。

本策略只检验“平台破位 + 两根接受确认 + 长期 EMA 趋势确认”。不读取 RSI、MACD、历史 96 根
涨跌、反转影线、布林带、BOS、FVG、CHoCH 或排名动量事件。

## 冻结身份

- 策略键：`market_volume_platform_break_trend_15m_v1`
- 产品 slug：`market-volume-platform-break-trend-15m-v1`
- 规则版本：`kline15m_filtered_vol2p5_platform20_confirm2_ema_trend_fixed1r_v1`
- 研究预设：`research_market_volume_platform_break_trend_both_15m_v1`
- 状态：`research_unvalidated`
- 边界：Research-only，不注册 Paper/Live，不覆盖 V9～V13。

## 冻结入场

1. 最新已完成 K 记为确认 K `c2`，其前两根依次为 `c1` 与破位 K `b`。
2. `b` 前精确 20 根定义平台；平台宽度不得超过 `4 * ATR14[b]`。
3. `b` 必须满足：
   - 过滤量比 `>=2.5`，且 `b.vol_ccy` 不低于此前连续 672 根 nearest-rank P90；
   - 实体占完整振幅至少 60%；
   - 实体相对开盘价至少 1%；
   - 看空为强阴线收盘严格低于平台下沿，看多完全镜像。
4. `c1` 与 `c2` 的收盘都必须严格保持在平台外；信号仅在 `c2` 完成时产生一次。
5. `c2` 时点还必须连续三根满足同向均线顺序：
   - 看空：`EMA12 < EMA144 < EMA169 < EMA696`；
   - 看多：完全镜像。
6. 同时最近四个 EMA696 必须逐根同向下降/上升，证明 EMA696 自身斜率已经转向。
7. 信号后紧邻下一根 15m 开盘成交；不等待回踩，不允许 RSI 或影线创建额外交易。

## 冻结风险、成本与样本

- 初始止损：实际成交价反方向 `1.5 * ATR14[c2]`。
- 止盈：实际成交价顺方向 `1.5 * ATR14[c2]`，毛目标固定 `+1R`。
- 最长持仓 48 小时；单笔账户风险 1%；单边手续费 5 bps；单边滑点 3 bps。
- 不启用量比目标档位、移动止损、盈利保护或持仓二次放量阶梯。
- 首轮使用 `sample_limit=60`、`sample_seed=top60_v36_direct_kline_20260721`、
  `1751328000000..=1784470500000`。
- current-live Top60 只作诊断，不得视为样本外。

## 查看结果前冻结的报告

1. 平台候选数、放量破位数、两根接受确认数、EMA 确认数和最终成交数。
2. 整体及多空分别报告交易数、币种、有效事件、胜率、净 EV、净 PF、净 R、Sharpe、最大回撤。
3. 报告入场后 1/2/4/8/16/32 根 K 的 MFE/MAE 与 `+1R/-1R` 先后次序。
4. 按平台宽度 ATR、破位实体、破位量比、周成交额分位、月份和币种报告贡献。
5. 改变 RSI、MACD、影线形态或历史 96 根净移动不得改变信号。

若严格组合导致样本很少或为零，也保留该结论；看完结果后不得放宽确认条件。任何放宽都必须成为
新的独立规则版本。
