# Vegas 压缩突破价格位移激活 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_breakout_price_displacement_activation_4h_research`。
- 入场规则版本：`compressed_breakout_price_displacement_activation_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v45_breakout_price_displacement_20260720`。
- 冻结来源：v42 `12682..12781`；保留其弱扩张门禁，不继承 v43 止损放宽或 v44 延迟入场。
- 仅运行本地 `ResearchBar`；100 个配置保持 `enabled=false`，不覆盖任何旧版本，不进入 Paper、Live 或生产默认消费路径。

## 2. 冻结假设

v44 证明低量突破等待一根确认会损失入场价格，却不能获得稳定选择力。另一方面，v41 压缩突破空头中，信号棒总振幅达到 `1.5ATR` 的交易在 discovery/validation 分别为 `0.860R/0.532R`，低于 `1.5ATR` 时为 `0.133R/-1.100R`。这说明价格自身的真实位移可能是比延迟确认更直接的冲击证据。

`1.5ATR` 复用项目既有 ATR 止损自然尺度，不来自本轮数值扫描。本候选不修改当前 `1.5x` 成交量门禁，而是验证一个 OR 激活：成交量不足 `1.5x` 时，若当根真实振幅已经达到 `1.5ATR`，允许价格位移替代成交量成为压缩突破冲击证据。

## 3. 冻结规则

1. 完整继承 v42：v27 原信号、v36 低 ATR 扫高确认空、v40 结构止损，以及 `relative_volume<2.5x && EMA=Normal` 弱扩张拦截均保持不变。
2. 仍要求此前 5 根区间宽度 `<=3%`、当前阴线实体占比 `>=60%`、收盘跌破区间下沿 `>=1%`、MACD 零轴下负柱继续下降、EMA 非多头、无 bullish BOS。
3. 原量能条件 `volume_ratio>=1.5x` 保持有效；只有不满足时，才允许 `current_candle_range / ATR(14) >= 1.5` 替代它。
4. 价格位移激活只作用于新增空头突破；不开放多头，不改变 v27 或扫高反转信号。
5. 入场仍在冲击棒收盘，结构止损仍为此前 5 根整理区下沿；止盈、风险、容量和成本全部不变。
6. ATR 未就绪、为零或非有限值时不得启用替代；不回退成裸价格阈值，不读取未来 K 线。

## 4. 统一回放与停止门禁

- 固定组合：`100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 目标：实际成交频率 `>=8/月`；净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、盘中回撤 `<=15%`。
- 必须单列价格位移新增交易的 discovery/validation EV/PF、实际成交与有效事件数。
- 标准成本任一联合门禁失败即拒绝，不扫描 ATR 倍数、不修改量能阈值、不叠加 v44。
- 标准成本全部通过后才运行双倍成本；即使通过，也只能标记为 `development_candidate_forward_shadow_required`。

## 5. 实测结果与决策

- 本地回测：`back_test_log.id=12984..13083`，100 个配置，全部保持 `enabled=false`。
- 标准成本组合：241 笔、约 `8.07` 笔/月，176 个有效事件、约 `5.89` 个/月；净收益 `+163.524%`、EV `0.612R`、PF `2.114`、Sharpe `1.625`、Recovery `4.986`、盘中最大回撤 `14.79%`。
- 价格位移替代量能只产生 2 笔实际成交：CRO `2025-06-18 16:00` 为 `-1.106R`，AGLD `2026-04-29 20:00` 为 `-1.075R`；discovery/validation 各 1 笔且方向一致为负。
- 固定参数 walk-forward test-2 仍为 `-0.526R`、PF `0.562`，时间弱窗没有修复。

固定决策：`rejected_standard_gate`。频率、EV、Sharpe、Recovery 和回撤通过，但 PF `2.114<2.2`，新增 setup 本身 0 胜 2 负；按停止门禁不运行双倍成本、不扫描 ATR 倍数或放宽 EMA 门禁。
