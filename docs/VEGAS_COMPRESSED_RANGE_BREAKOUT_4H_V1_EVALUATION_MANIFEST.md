# Vegas Compressed Range Breakout 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_compressed_range_breakout_4h_research`。
- 入场规则版本：`compressed_range_breakout_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v39_compressed_range_breakout_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，回测 `10976..11075`。
- 仅运行 `ResearchBar`；100 个候选配置保持 `enabled=false`，不覆盖 v27/v36，不进入 Paper、Live 或生产默认消费路径。

## 2. 亏损逆向分析后的边界

v27 的全部成交按信号时点特征做两两组合后，没有任何组合能在 discovery 与 validation 同时满足“各至少 2 笔且净 EV 都为负”。因此不再增加亏损过滤器：继续删单会放大样本内拟合，并进一步降低频率。

v38 证明宽泛的冲击后回踩虽然能把成交频率推近目标，但新增多头为负期望、新增空头跨时段不稳定。v39 改为验证另一个独立结构：窄幅整理完成后的同向放量实体突破，不等待后续 K 线，也不复用 Fib 回踩。

## 3. 冻结入场规则

所有判断只使用当前及此前已完成的 4H K 线：

1. 当前棒之前固定查看 5 根 K 线；其最高价到最低价的区间宽度相对当前收盘不超过 `3%`。
2. 当前棒实体占整根振幅至少 `60%`，成交量相对 v27 现有成交量基线至少 `1.5` 倍。
3. 多头必须收阳，且收盘高于前 5 根最高价至少当前收盘的 `1%`；MACD 快慢线均在零轴上方、柱体为正且继续增强；EMA 不能是明确空头趋势；不能同时出现 bearish BOS。
4. 空头完全对称：收阴、向下有效跌破至少 `1%`、MACD 快慢线均在零轴下方且负柱继续增强；EMA 不能是明确多头趋势；不能同时出现 bullish BOS。
5. 仅当原 v27 在当前棒没有方向时补充本 setup；信号在当前棒收盘生成，使用既有 ATR 初始止损、费用、滑点和退出规则。
6. 候选只新增 `is_open / enable_long / enable_short` 三个版本门禁；本轮不扫描回看根数、区间宽度、突破幅度、实体、量能或 MACD 条件。

## 4. 统一回测与停止门禁

- 100 币真实重放；组合固定初始资金 `100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- accepted trades 目标 `>=8` 笔/月，并同时报告按时间、方向、市场状态和相关簇归并后的 effective events/month。
- 净 EV `>=0.6R`、净 PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、保守盘中最大回撤 `<=15%`。
- 新增 setup 自身必须为正 EV、PF `>1`；long/short、`<2026-01-01` 与 `>=2026-01-01` 分段必须单独报告，不能由单币种或单事件主导。
- 标准成本门禁全部通过后，才运行双倍额外滑点与资金费压力；任一门禁失败即拒绝 v39，不调整冻结参数、不切方向救参、不与其他候选组合救参。

## 5. 冻结后结果

- 100 币回测：`back_test_log.id=12282..12381`。
- 原始成交 `256` 笔；组合全部 accepted，约 `8.56` 笔/月；effective events `187`，约 `6.26` 个/月。
- 标准成本组合：收益 `+139.099%`，PF `1.83229`，净 EV `0.50878R`，Sharpe `1.38951`，Recovery `4.62996`，保守盘中最大回撤 `15.27745%`。
- 时间分段：
  - discovery：`167` 笔，PF `1.45515`，EV `0.32815R`，Sharpe `0.88775`，盘中回撤 `15.14797%`；
  - validation：`89` 笔，PF `2.33427`，EV `0.84771R`，Sharpe `2.69131`，盘中回撤 `15.27745%`。
- 新增 setup 实际成交 `103` 笔：
  - 多头 discovery：`10` 笔 `0` 胜，合计 `-10.518R`；validation：`3` 笔 `1` 胜，合计 `+10.182R`，其中 JUP 单笔 `+12.292R`；
  - 空头 discovery：`43` 笔，EV `0.359R`、PF `1.584`；validation：`47` 笔，EV `0.322R`、PF `1.551`。
- 组合至少有一个负收益 walk-forward 窗口；2024 年仅盈利 `6.28U`，多个完整月份显著为负。

## 6. 亏损路径补充诊断

1. “下一根收盘没有继续跌破就退出”在 validation 能减少损失，但在 discovery 把同类交易合计从 `-3.509R` 恶化到约 `-6.808R`（未计退出成本），不具备跨时段稳定性。
2. 空头突破后若重新站回此前整理区下沿，7 个样本全部最终亏损；但等下一根收盘退出在 discovery 已经过晚。
3. 将整理区下沿直接作为空头结构失效止损的静态路径诊断，在 discovery 将新增空头 EV 从 `0.359R` 提到约 `0.452R`、PF 从 `1.584` 提到约 `1.988`；validation 提到约 `0.341R`、PF `1.745`。方向一致但仍低于职业级新增 setup 质量，需作为新的独立版本验证，不能回写 v39。
4. v27 的 695 个被过滤信号中，623 个为 LOSS、仅 discovery 有 16 个 WIN，validation 没有 WIN；现有硬过滤不存在可安全解除的跨时段盈利簇。

## 7. 决策

`v39` 拒绝，100 个配置继续保持 `enabled=false`：

- 只有成交频率与 Recovery 过线；PF、EV、Sharpe、盘中回撤和有效事件频率均失败；
- 多头突破在 discovery 明确负期望，validation 正收益由单笔极端尾部主导；
- 空头虽跨时段为正，但质量不足，不能靠事后切方向把 v39 伪装成通过；
- 不运行双倍成本压力，不 promote，不进入 Paper/Live。
