## 2. 预注册市场机制

V60/V69 的主入口由 `only_on_fib=true` 约束，现有独立分支覆盖扫流动性、冲击中点回踩和压缩突破，却没有验证 Vegas 原生 EMA144/169 隧道的完整顺势回踩序列。V70 冻结三个相邻已完成 4H K 线：

1. **干净趋势侧 K 线 `t-2`**：多头整根最低价在 EMA144 上方；空头整根最高价在 EMA144 下方。
2. **隧道回踩 K 线 `t-1`**：多头最低价进入 EMA144/169 隧道且收盘重新站上 EMA144；空头最高价进入隧道且收盘重新跌回 EMA144 下方。
3. **确认 K 线 `t`**：多头为阳线、收盘突破 `t-1` 高点且形成更高低点；空头为阴线、收盘跌破 `t-1` 低点且形成更低高点。

趋势排列在回踩棒与确认棒都必须为：多头 `EMA12 > EMA144 > EMA169 > EMA576`，空头完全反向。历史 EMA 值只能由当时已完成收盘和同一 EMA 递推公式恢复，不读取后续 K 线。

- 入场为确认棒收盘；只在所有既有 V69 信号为空时生效。
- 保护止损放在回踩棒与确认棒共同极值之外 `0.6%`；该缓冲复用现有 Fib/流动性扫单合同，不扫描。
- 不要求量能、MACD、FVG、BOS/CHoCH、RSI、影线比例或币种条件；动态退出、最大损失和组合容量保持 V69 口径。
- 该机制与此前失败的冲击棒实体中点回踩不同：它要求长期 EMA 排列、先离开隧道、再回到隧道并由下一棒突破确认。

## 3. 实现与验证合同

- 新配置默认关闭；只创建 100 条 `enabled=false` 研究配置，不进入 Paper/Live。
- 单元测试必须覆盖多空对称、缺少三棒、非干净首次回踩、回踩未收复、确认未突破、EMA 排列错误和同棒因果边界。
- 与 V69 做精确入场键差分：共同交易结果必须为 0 漂移；新增交易必须带 `EMA_TUNNEL_RETEST_CONFIRMATION_LONG/SHORT` 标签。
- 标准组合：`100U / risk-scale 0.375 / 最大并发12 / 单边额外5bps / 资金费1bps每8h`。
- 双倍压力：单边额外 `10bps`、资金费 `2bps/8h`；同样应用 `projected_double_execution_cost_r <=0.20R`。
- 时间切分固定在 `2026-01-01 00:00:00 UTC`；报告 IS/OOS、12/3 月 fixed-parameter walk-forward、年度、方向、币种、有效事件和收益集中度。

## 4. 晋级与停止规则

- V69 接受 215 笔、约 `7.12笔/月`；V70 至少需增加约 27 笔实际可执行交易才能达到 `8笔/月`，但不得为凑数量改变规则。
- 标准与双倍成本都必须满足净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、日频 Sharpe `>=1.5`、保守盘中回撤 `<=15%`。
- 新增家族的 IS/OOS 必须分别为正，所有有成交 walk-forward 窗口不得为负；新增收益不能由单币或单一相关事件主导。
- 频率、增量跨期质量或任一组合硬门禁失败即拒绝；不追加成交量、EMA 距离、MACD、FVG、BOS、影线、方向或目标参数补丁。
- 历史 point-in-time 币种池缺口继续阻止最终生产晋级，即使聚合数值通过也只能保留 disabled forward shadow。

- 最终状态：`rejected_incremental_negative_expectancy`。全部配置保持 disabled，未进入 Paper/Live、未部署，也未触发任何交易 mutation。
