# Vegas bearish FVG 完整收复 + MACD 修复多头 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_failed_bearish_fvg_reclaim_macd_long_4h_research`。
- 入场规则版本：`failed_bearish_fvg_reclaim_macd_long_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v49_fvg_reclaim_macd_long_20260720`。
- 冻结来源：v42 `12682..12781`；不携带已判退的 v46、v47、v48 规则。
- 仅运行本地 `ResearchBar`；配置保持 `enabled=false`，不覆盖 v27/v42，不进入 Paper、Live 或生产默认消费路径。

## 2. 预注册市场机理

v48 的 bearish BOS + bearish FVG 首次回补失败空头在标准成本下新增 `79` 笔，但净期望为负，且 validation 更差；同期审计显示，bearish BOS active 在验证段更像成熟趋势与拥挤度标签，而不是继续做空的正向确认。MACD 顺势转弱也没有修复追价问题。

本轮只验证相反但仍保持因果的机理：bearish FVG 先由已完成 K 线形成，随后价格在固定短窗口内以多头实体完整收复 FVG 上沿，同时 MACD 柱体较上一根改善。此时 bearish imbalance 已被市场否定，尝试把它作为新多头机会，而不是把 v48 的亏损单事后逐笔反向。

BOS 只保留为结果审计维度，不参与入场门禁，避免把已证伪的成熟趋势状态重新包装成正向条件。

## 3. 冻结规则

1. bearish FVG 沿用 v48 的三根已完成 K 线定义：形成棒最高价低于两根前锚点最低价，中间位移棒必须收阴。
2. 缺口宽度固定要求 `>=0.10 ATR`，中间位移棒实体固定要求 `>=0.80 ATR`；不扫描参数。
3. FVG 形成后最多等待 4 根已完成 K 线，只允许第一次收盘站上 FVG 上沿的完整收复棒入场。此前已有任一收盘站上上沿，则该 setup 过期，不能在后续补造机会。
4. 收复棒必须收阳且收盘严格高于 FVG 上沿；只触及上沿或收盘仍位于缺口内部不算完整否定。
5. MACD 配置必须启用，当前柱体必须较上一根增加；MACD 可位于零轴任一侧，不新增绝对阈值或交叉条件。
6. FVG 形成当根不得入场；超过 4 根、MACD 未改善、非首次完整收复时立即放弃，不能使用信号后的 K 线反向改写。
7. 保护止损位于 FVG 下沿与收复棒最低价二者较低值外 `0.6%`；原 ATR/最大损失风控继续保留。
8. 只新增多头 setup，且仅在原 Vegas、v36 与 v42 压缩突破均未产生方向时补充；v27/v42 的既有入场和退出语义不变。
9. 本轮不启用 v48 的 BOS + FVG 回补失败空头；市场结构指标不作为门禁，若快照中存在 BOS/CHoCH，仅用于事后分组审计。

## 4. 统一回放与停止门禁

- 固定组合：`100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 联合目标：实际成交频率 `>=8/月`；净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、盘中回撤 `<=15%`。
- 必须单列 v49 新增交易的 discovery/validation EV、PF、FVG 年龄、MACD 零轴/柱体状态、BOS 审计状态、有效事件数和退出类型，并复核 XRP 指定时点没有被未来 K 线重写。
- 标准成本任一联合门禁失败即拒绝，不扫描 FVG 宽度、位移实体、等待根数、收复定义、止损缓冲或 MACD 数值。
- 标准成本全部通过后才运行双倍成本；即使通过，也只能标记为 `development_candidate_forward_shadow_required`。

## 5. 冻结后结果与决策

- 本地禁用配置：100 个；回测 `13384..13483`，没有进入 Paper、Live 或生产消费路径。
- 标准成本组合候选 `2608` 笔、实际接受 `2424` 笔，约 `79.5` 笔/月；有效事件 `1242`，约 `40.71` 个/月，频率超过 4H 目标上限。
- 组合净收益 `-73.37%`、PF `0.761`、EV `-0.072R`、Sharpe `-1.296`、Recovery `-0.957`、保守盘中回撤 `75.93%`，全部质量门禁失败。
- v49 新增 setup 原始成交 `2368` 笔，胜率 `71.11%`，但平均盈利仅 `0.299R`、平均亏损 `-1.057R`，净 EV `-0.092R`、PF `0.698`。discovery/validation 分别为 `-0.109R / 0.662 PF` 与 `-0.054R / 0.797 PF`，两段均为负。
- FVG 年龄 1—4、MACD 零轴上下、EMA 状态、EMA 趋势和 Fib 腿方向所有已预先可见分组均未达到正 EV；不从这些亏损桶继续扫描阈值。
- XRP 路径出现有害换向：`2026-07-05 00:00` 的确认空单被 `2026-07-06 04:00` 的 v49 多头以反向信号提前平到约 `+0.398R`，该多头随后约 `-1.055R` 止损，并在 `2026-07-06 20:00` 长下影棒重新开空。它直接证明纯 FVG 收复 + MACD 改善会把短反弹误判成结构反转。
- 结论：`完整收复 bearish FVG + MACD 柱改善` 主要识别普通反弹，而不是可持续结构反转。v49 拒绝，不运行双倍成本；配置继续保持 `enabled=false`。
