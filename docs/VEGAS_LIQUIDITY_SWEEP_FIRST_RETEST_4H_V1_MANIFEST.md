# Vegas 扫流动性后首次回测 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_liquidity_sweep_first_retest_4h_research`。
- 入场规则版本：`liquidity_sweep_reversal_first_retest_v1_20260721`。
- 最终可审计候选配置版本：`xasset_4h_top100_v53b_sweep_first_retest_20260721`。
- 冻结来源：v42 `12682..12781`；不携带 v46—v52 已拒绝的 FVG、BOS、CHoCH 或 MACD 补充规则。
- 仅运行本地 `ResearchBar`；100 个配置必须保持 `enabled=false`，不覆盖 v27/v42，不进入 Paper、Live 或生产默认消费路径。
- 2024-01 至 2026-07 的现有历史已经被多轮查看，本轮只能提供开发证据；即使通过标准门禁，也必须等待未见未来数据的 forward shadow 才能晋级。

## 2. 预注册市场机理

既有两棒扫单反转要求冲击后立即以长影线再次扫过极值，容易把尚未完成的顶部或底部误当反转；单纯 MACD、BOS、CHoCH 与 FVG 也已证明无法稳定提高新增交易质量。

本轮验证不同机理：冲击棒先扫掉此前结构流动性，下一根反转棒收回冲击实体中点，第三根只能是紧邻的第一次回测；只有回测触及中点、没有再次突破冲击极值并重新收在反转方向一侧，才认为反转被接受。该序列使用三根已经完成的 K 线，不能跳棒、延迟补偿或读取信号后的数据。

## 3. 冻结规则

1. 冲击棒固定突破此前 `20` 根已完成 K 线的最高点或最低点。
2. 冲击棒实体占自身振幅至少 `0.65`，成交量相对其前 `4` 根均值至少 `2.5` 倍；这些常量复用已有流动性扫单规则，不扫描参数。
3. 空头：冲击棒收阳并扫过前高；紧邻确认棒收阴且收盘低于冲击实体中点；紧邻首次回测棒最高价触及该中点、最高价不超过冲击棒最高价，收阴且收盘仍低于中点。
4. 多头完全对称：冲击棒收阴并扫过前低；确认棒收阳且收盘高于冲击实体中点；首次回测棒最低价触及中点、最低价不低于冲击棒最低价，收阳且收盘仍高于中点。
5. EMA 只作为方向冲突门禁：空头不得处于明确多头趋势，多头不得处于明确空头趋势；不要求 MACD、BOS、CHoCH、FVG、RSI 或 Fib。
6. 保护止损置于三根形态极值之外 `0.6%`；既有最大亏损、统一仓位、组合容量与费用合同继续生效。
7. 仅在 v42 原有规则未产生方向时补充；v42 的信号、弱扩张门禁、退出和持仓管理保持不变。
8. 多头和空头分别报告交易数、EV、PF、退出分布和 discovery/validation；任一方向的负期望不得由另一方向掩盖。
9. 本轮只有这一组冻结常量，不扫描回看长度、量比、实体比例、中点、等待根数、方向或止损缓冲。

## 4. 统一回放与停止门禁

- 固定组合：`100U` 初始资金、单笔风险 `0.75%`、最大容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 联合目标：实际成交频率 `8—40/月`；净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、盘中回撤 `<=15%`。
- 同时报告原始成交、有效市场事件、月份/Tier/币种/相关簇贡献、walk-forward 与头部收益集中度。
- 必须精确单列 v53 相对 v42 的新增交易，并复核 XRP `2026-07-04 20:00`、`2026-07-05 00:00`、`2026-07-06 20:00`；不得使用信号后的 K 线反写入场。
- 标准成本任一门禁失败即拒绝，不运行双倍成本、不缩小亏损桶、不做阈值邻域搜索。

## 5. 冻结后结果与决策

原 v53 `14087..14186` 错把首次回测配置做成替换模式，关闭了 v42 已有的低 ATR 两棒扫高空头。精确差分出现 `236` 笔共同、`12` 笔新增、`2` 笔移除，其中被移除的是 LTC `+2.278R` 和 XRP `+4.124R`；该批次违反“原信号不变”合同，只保留为排障记录，不参与策略结论。

v53b 仅修正为 additive 组合：原两棒判断保持优先，未命中后才评估相同冻结条件的三棒首次回测。阈值、方向、止损、费用和停止门禁均未改变。

## 6. v54 退出几何预注册（查看结果前冻结）

v53b 的新增交易暴露出一个与入场方向无关的风险合同错配：三棒形态止损距离大部分超过有效最大止损，而多头目标仍由形态止损距离生成，空头目标仍由 ATR 止损距离生成。这使目标相对入场时有效 `R` 在币种与方向间不可比。

v54 只验证一个与信号时点因果无关的出场假设：

1. 入场、三棒形态、方向、止损、仓位、费用与组合容量与 v53b 完全一致。
2. 只对 `first_retest_confirmation=true` 的新增机会，在入场时有效止损冻结后，生成相对该止损的固定 `2R` 止盈。
3. 实际止盈价取原有可执行目标与 `2R` 中更近入场价者；不影响 v42 原有交易。
4. `2R` 来自既定盈亏比目标带，不根据 AVNT 事后最高浮盈选取。
5. 主候选固定为 `2R`；`1.5R` 和 `2.5R` 只做参数邻域稳定性检查，不允许在看到结果后改选最好者。
6. 主候选仍必须同时通过标准组合门禁、新增交易 discovery/validation 与多窗口检查；若只靠 AVNT 一笔事后翻转才达标，则降级为研究候选，不得晋级。
7. v54 的研究配置必须 `enabled=false`；盈利目标尚未纳入 live 风险计划 contract，因此即使回测通过也仍禁止 Paper/Live。
