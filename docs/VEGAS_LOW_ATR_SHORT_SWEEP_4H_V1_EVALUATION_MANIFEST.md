# Vegas Low-ATR Short Sweep 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_low_atr_short_sweep_4h_research`。
- 入场规则版本：`low_atr_short_sweep_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v36_low_atr_short_sweep_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，回测 `10976..11075`。
- 候选只运行 `ResearchBar`，100 个配置全部保持 `enabled=false`；不覆盖 v27，不进入 Paper、Live 或生产默认消费路径。

## 2. 候选来源与证据等级

v28 两棒扫流动性反转新增 15 笔交易，其中新增空头 6 笔：

- LTC `2024-06-30 04:00`：ATR `1.551%`，`+2.278R`。
- XRP `2026-07-05 00:00`：ATR `1.675%`，`+4.124R`。
- AAVE、EGLD、CRO、NEAR 四笔亏损的 ATR 为 `2.297%~3.636%`，每笔约 `-1.05R`。

两笔赢家都低于 v27 已存在的震荡波动带下界 `1.8%`，四笔亏损都高于该边界。该分组是在查看 v28 结果后发现，因此属于开发样本假设，不是密封 OOS；即使完整重放通过，也必须等待冻结后的 forward 数据确认。

## 3. 冻结规则

保留 v28 上方扫流动性后的两棒确认空头，关闭对称多头，并额外要求：

```text
current_atr_ratio < choppy_volatility_filter.min_atr_ratio
```

- 每个币种直接复用其 v27 配置中的现有下界，当前档位均为 `0.018`；不新增、不扫描 ATR 数值。
- 确认条件、20 根结构回看、冲击棒实体/量比、确认棒上影、Fib 中位、0.6% 结构止损缓冲全部保持 v28 原值。
- 信号只在第二根确认 K 线完成后生成；不用信号后的 K 线决定是否入场。
- v27 原始信号不受影响；本候选只在原始方向为空时补充独立 short-sweep setup。

## 4. 统一回测与停止门禁

- 100 币使用与 v27 相同的 K 线范围、初始资金、风险和交易成本真实重放。
- 组合口径固定为初始资金 `100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- accepted trades、trades/month 和 effective events/month 必须高于 v27。
- 净 EV `>=0.6R`、净 PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、保守盘中回撤 `<=15%`，并且不得相对 v27恶化。
- `< 2026-01-01` 与 `>= 2026-01-01` 两段的 EV/PF 都不得相对 v27 恶化；新增 setup 两段都必须有实际样本。
- 不调整 1.8% 边界，不按币种、方向子类或年份二次筛选；任一门禁失败即拒绝 v36。
- 即使所有开发样本门禁通过，只能记为 disabled 候选；新增 setup 只有两笔命中，未见 forward 数据前不得晋级。

## 5. 完整回放结果与决策

100 币真实重放生成 `back_test_log.id=11982..12081`。候选产生 LTC、XRP 两个低 ATR 扫高空头，但 XRP 更早的扫高确认仓位替代了 v27 在 `2026-07-06 20:00` 的原始空头，因此净成交只增加 1 笔。

| 指标 | v27 | v36 |
|---|---:|---:|
| accepted trades | 154 | 155 |
| effective events | 121 | 122 |
| effective events/month | 4.051 | 4.084 |
| 净 PF | 2.254 | 2.290 |
| 净 EV | 0.693R | 0.713R |
| 日频 Sharpe | 1.647 | 1.688 |
| Recovery | 4.214 | 4.320 |
| 保守盘中回撤 | 13.12% | 13.12% |

- 发现段 PF/EV 改善到 `1.683 / 0.465R`，验证段改善到 `3.918 / 1.423R`。
- 双倍额外成本压力下仍为正，PF `2.103`、EV `0.646R`、Sharpe `1.535`，但 Recovery 降至 `3.934`，低于职业级目标 `4`。
- 规则改善了 XRP 的入场语义：从长下影冲突棒立即做空，改为前一日扫高后等待确认棒收盘入场；但样本只有 LTC/XRP 两笔，且来自已查看数据。

**决策：保留为 disabled 开发候选，不晋级。** 标准成本质量优于 v27，但频率仍约 `5.2` 笔/月，远低于 `8` 笔/月目标；双倍成本 Recovery 也未过线，必须等待 forward 数据。
