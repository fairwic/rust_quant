# Vegas Low-Vol Delayed Fib 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_low_vol_delayed_fib_4h_research`。
- 入场规则版本：`low_vol_delayed_fib_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v37_low_vol_delayed_fib_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，回测 `10976..11075`。
- 仅运行 `ResearchBar`；100 个配置保持 `enabled=false`，不覆盖 v27/v36，不进入 Paper、Live 或生产默认消费路径。

## 2. 结构性缺口

v27 已启用延迟 Fib 量能确认：量价冲击发生后至少等待 1 根完整 4H K 线，只在随后 2 根已完成 K 线内重新评估 Fib 入场。当前波动门禁允许：

- 中波动带 `[1.8%, 3.2%)` 的多头与空头；
- 高波动 `>=3.2%` 的空头；
- 不允许低波动 `<1.8%` 的任何延迟确认。

低波动缺口会丢失“先有放量冲击、随后低波动回踩确认”的 setup。候选只验证是否开放这个现有边界下的区域能提高信号密度，不新增外部数据，也不改已有冲击、等待和有效期参数。

## 3. 冻结规则

在 v27 上只开启：

```text
candle_momentum_activation.allow_low_volatility_delayed = true
```

- 当 `atr_ratio < choppy_volatility_filter.min_atr_ratio` 时，允许 long/short 对称使用已有延迟 Fib 量能确认。
- 复用每个币种已有的 `1.8%` 下界，不扫描阈值。
- 冲击事件仍要求相对量能 `>=3.0`、相对振幅 `>=2.0`、同向、至少等待 1 根、最多有效 2 根。
- 入场棒仍必须独立满足当时 Vegas/Fib/过滤条件；不保存未来承诺，不使用入场后的 K 线补造信号。
- 不同时开启 v35 new-leg 拦截或 v36 sweep，先隔离验证本 setup。

## 4. 统一回测与停止门禁

- 100 币真实重放，组合固定初始资金 `100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 本候选承担频率目标：accepted trades 应达到完整样本约 `8` 笔/月，且 effective events/month 必须同步增加；原始信号增加但被容量大量跳过不算通过。
- 净 EV `>=0.6R`、净 PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、保守盘中回撤 `<=15%`。
- `< 2026-01-01` 与 `>= 2026-01-01` 两段都必须为正，且不能靠单一币种或单一事件贡献。
- 双倍额外成本压力继续报告；若标准成本硬门禁失败，立即拒绝。
- 不调整 ATR 边界、方向、等待根数、有效期、量比或振幅阈值；任一门禁失败即拒绝 v37，不做二次救参。

## 5. 完整回放结果与决策

|---|---:|---:|
| accepted trades | 154 | 161 |
| effective events/month | 4.051 | 4.209 |
| 净 PF | 2.254 | 2.100 |
| 净 EV | 0.693R | 0.616R |
| 日频 Sharpe | 1.647 | 1.514 |

- 相对 v27 新增 7 笔：3 笔多头全亏，4 笔空头仅 1 胜；新增交易合计约 `-6.281R`。
- 发现段 PF/EV 降到 `1.539 / 0.376R`；验证段仍为正，但不能弥补开发段的明确退化。
- 161 笔约 `5.4` 笔/月，仍远低于 `8` 笔/月目标。

**决策：拒绝 v37。** 同时触发频率、PF、Recovery 与回撤非劣停止门禁；不扫描 ATR 阈值、方向或等待窗口，不与 v35/v36 组合救参。
