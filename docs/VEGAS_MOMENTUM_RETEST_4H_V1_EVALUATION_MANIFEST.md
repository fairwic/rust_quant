# Vegas Momentum Retest 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_momentum_retest_4h_research`。
- 入场规则版本：`momentum_retest_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v38_momentum_retest_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，回测 `10976..11075`。
- 仅运行 `ResearchBar`；100 个配置保持 `enabled=false`，不覆盖 v27/v36，不进入 Paper、Live 或生产默认消费路径。

## 2. 亏损归因与新 setup

v35 证明“新腿首棒、没有延迟量能确认”的 8 笔原成交全部亏损；直接删除它们能提高质量，但会把月频从约 5.15 进一步降低。v37 又证明无条件开放低波动延迟 Fib 只会增加 1 胜 6 负。

因此本候选不放宽原 Fib，也不在冲击棒追单，而是新增一个独立的“量价冲击后回踩实体中位并收复”setup。其目标是把首棒冲击转化成可验证的后续结构确认，同时增加非重叠交易机会。

## 3. 冻结规则

所有判断只使用当前及此前已完成的 4H K 线：

1. 在当前棒之前的 1—2 根内，存在与候选方向同向的量价冲击棒；冲击棒继续复用 v27 的相对量能 `>=3.0`、相对振幅 `>=2.0` 和 20 根基线。
2. 多头：当前棒下探到冲击棒实体中位或更低，随后收阳且收盘重新站上该实体中位；当前 leg 为 bullish，EMA 不能是明确空头。
3. 空头完全对称：当前棒上探到冲击棒实体中位或更高，随后收阴且收盘重新跌破该实体中位；当前 leg 为 bearish，EMA 不能是明确多头。
4. 只在当前确认棒收盘生成信号；若窗口内未确认则过期，不使用更晚 K 线补造机会。
5. 保护止损放在冲击棒与确认棒共同极值之外，并复用 v27 现有 Fib 止损缓冲 `0.6%`；不新增风险参数。
6. 仅当原 v27 没有方向信号时补充本 setup；原信号与过滤逻辑保持不变。

候选只新增一个布尔开关 `allow_momentum_retest_entry=true`；不扫描实体中位、等待窗口、量比、振幅、方向或缓冲值。

## 4. 统一回测与停止门禁

- 100 币真实重放；组合固定初始资金 `100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 本候选承担频率目标：accepted trades 需达到完整样本约 `8` 笔/月，effective events/month 也必须明显增加；容量跳过不算交易频率。
- 净 EV `>=0.6R`、净 PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、保守盘中回撤 `<=15%`。
- 新增 setup 自身必须有正 EV/PF；long/short、`<2026-01-01` 与 `>=2026-01-01` 分段必须单独报告，不能由单一币种或单一事件主导。
- 标准成本硬门禁失败即拒绝；通过后再执行双倍额外成本压力。
- 任一门禁失败即拒绝 v38，不调整中位、方向、窗口或冲击阈值，不与其他候选组合救参。

## 5. 冻结后结果

- 100 币回测：`back_test_log.id=12182..12281`。
- accepted trades：`268`，约 `8.9` 笔/月；effective market events：`223`，约 `7.34` 个/月。
- 组合口径：收益 `+79.856%`，净 PF `1.59893`，净 EV `0.32475R`，Sharpe `1.2676`，Recovery `3.5571`，保守盘中最大回撤 `15.9404%`。
- 时间分段：
  - discovery：`191` 笔，PF `1.2016`，EV `0.1442R`；
  - validation：`77` 笔，PF `2.5148`，EV `0.7727R`。
- 相对 v27 的新增多头：`93` 笔，`52` 胜，合计 `-23.1816R`，EV `-0.2493R`，PF `0.4632`。
- 相对 v27 的新增空头：`21` 笔，`7` 胜，合计 `+10.3639R`，EV `0.4935R`，PF `1.7039`；但 discovery 合计亏损、validation 主要由少量大盈利贡献，跨时段方向不稳定。

新增多头只有低 ATR 分组在两个时间段都保持微弱正值：discovery `6` 笔、EV `0.053R`、PF `1.304`；validation `3` 笔、EV `0.184R`。样本与效应都不足以支持事后增加低 ATR 过滤。EMA、Fib、MACD、布林、腿部与 RSI 的单特征或双特征组合均未形成可晋级的跨时段多头子集。

## 6. 决策

`v38` 拒绝，保持全部配置 `enabled=false`：

1. 虽然原始成交频率首次接近长周期目标，但有效事件仍低于 `8/月`；
2. PF、EV、Sharpe、Recovery 与最大回撤同时未过门禁；
3. 新增多头是明确负期望，新增空头存在显著时间集中，不能用事后方向开关或低 ATR 子集救参；
4. 失败说明“量价冲击后的实体中位回踩”不是 Vegas 4H 可直接通用化的独立入场族，后续频率扩展必须换结构假设，而不是继续收窄本版本。
