# Vegas New-Leg Activation Guard 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_new_leg_activation_guard_4h_research`。
- 入场规则版本：`new_leg_activation_guard_v1_20260720`。
- 候选配置版本：`xasset_4h_new_leg_activation_guard_v35_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，回测 `10976..11075`。
- 运行精度：`ResearchBar`。候选配置全部保持 `enabled=false`，不覆盖 v27，不进入 Paper、Live 或 `production_default`。

## 2. 已查看样本与证据限制

- v27 的完整区间和 `< 2026-01-01` / `>= 2026-01-01` 结果已经被查看，本候选属于开发样本上的缺陷诊断，不是密封 OOS。
- 本清单冻结后，完整重放仍按两个时间段分别报告，用于检查规则是否只依赖单一时期；但不得把该切分表述为严格样本外证据。
- 后续即使改善，也只能保持 disabled 研究态；真正晋级需要冻结后的新增数据或未见时间窗口。

## 3. 亏损归因

v27 已成交交易中，`leg_detection_value.is_new_leg=true` 共 `13` 笔：

- 带 `used_delayed_volume_confirmation=true`：`5` 笔，2 胜 3 负，合计约 `+5.875R`；仅有的两笔 new-leg 大赢家 CFX `+5.558R`、ADA `+3.476R` 都属于该组。
- 不带延迟量能激活：`8` 笔，0 胜 8 负，合计约 `-8.583R`；覆盖 long/short、多个币种和多个年份。

这说明问题不是“新腿永远不能做”，而是新腿刚被识别时，仅靠当前棒放量立即入场容易把同棒冲击当成可持续趋势。已有延迟激活表示放量冲击发生在 1—2 根已完成 K 线之前，当前棒才完成 Fib 入场判断，时序上更接近确认而不是追单。

## 4. 固定候选规则

```text
若最终 Vegas 信号准备入场：
    leg.is_new_leg == true
    and fib.used_delayed_volume_confirmation == false
则阻断本根入场。
```

- long/short 对称应用，不新增 RSI、影线、成交量或 Fib 数值阈值。
- 不修改止损、止盈、仓位、容量、资金成本和其他已有信号。
- 下一根 K 线必须由原 Vegas evaluator 使用当时完整可见信息重新产生信号；不保存未来承诺，不补造入场。
- 若下一根仍满足入场且 `is_new_leg=false`，允许按正常规则交易，因此这是因果确认门禁，不是永久删除 setup。

## 5. 统一回测口径

- 100 个 v27 币种配置逐一克隆为 v35，仅开启本规则，全部 `enabled=false`。
- 单币回测使用相同 K 线范围、初始资金和风险配置；必须真实重放，不能静态删除旧交易。
- 组合回放使用初始资金 `100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费压力 `1 bps/8h`。
- 同时报告 accepted trades、trades/month、effective events/month、净 EV、净 PF、保守盘中回撤、Recovery、日频 Sharpe、多空贡献和时间切分。

## 6. 预注册停止门禁

- 候选组合交易频率和有效事件频率不得低于 v27；当前频率已经不足，不能用减少样本换取表面 EV。
- 净 EV、净 PF、Recovery、Sharpe 和保守盘中回撤不得恶化。
- `< 2026-01-01` 与 `>= 2026-01-01` 两段的净 EV/PF 均不得相对 v27 恶化。
- 若改善只来自阻断原 8 笔而没有产生可解释的后续重入，记录为诊断有效但频率失败，不晋级。
- 任一门禁失败即拒绝 v35；不扫描 `new_leg` 窗口、成交量阈值、等待根数或方向子集，不叠加第二条规则挽救候选。

## 7. 完整回放结果与决策

100 币真实重放生成 `back_test_log.id=11882..11981`。统一组合成本和容量口径下：

| 指标 | v27 | v35 |
|---|---:|---:|
| accepted trades | 154 | 146 |
| trades/month | 约 5.15 | 约 4.88 |
| effective events/month | 4.051 | 3.817 |
| 净 PF | 2.254 | 2.493 |
| 净 EV | 0.693R | 0.789R |
| 日频 Sharpe | 1.647 | 1.774 |
| Recovery | 4.214 | 4.422 |
| 保守盘中回撤 | 13.12% | 13.12% |

- v35 阻断 9 个信号，9 个理论结果均为亏损；实际成交比 v27 少 8 笔，没有形成足够的后续确认重入。
- 发现段 PF/EV 从 `1.655 / 0.450R` 改善到 `1.846 / 0.549R`；验证段从 `3.873 / 1.384R` 改善到 `4.065 / 1.448R`，缺陷诊断跨两个时间段成立。
- 但交易频率和有效事件频率都下降，明确触发预注册停止门禁。

**决策：拒绝 v35。** 规则保留为 disabled 诊断证据，不晋级、不叠加第二条规则挽救，也不覆盖 v27。
