# Vegas 入场预计执行成本效率门禁 V1 清单

## 1. 身份与来源

- 策略键：`vegas_projected_execution_cost_efficiency_4h_research`。
- 版本：`xasset_4h_top100_v68_projected_double_cost_cap020_20260721`。
- 冻结来源为 V60 `back_test_log.id=15288..15387`；V60 有 251 笔、约 `8.31/月`，标准组合已过聚合数值线，但双倍成本 EV/PF 只有 `0.582R/2.041`。
- V68 不改变任何信号方向、K 线指标、止损、止盈或风险比例，只增加入场时可计算的执行成本效率门禁；不覆盖 V60/V63/V65。

## 2. 冻结经济假设

窄初始风险会把固定手续费和滑点放大为较高的成本 `R`。本轮不按最终盈亏挑选，而是在入场时计算双倍压力下的预计往返执行成本：

`projected_cost_r = quantity * 2 * entry_price * (0.0007 + 0.0010) / initial_risk_amount`

- `0.0007` 是当前 Vegas legacy 每边基础手续费；`0.0010` 是双倍压力每边额外滑点。
- `entry_price`、`quantity` 与 `initial_risk_amount` 均为入场时冻结事实；公式使用两边相同入场名义，避免读取未来退出价格。
- 资金费取决于持仓时间，不参与入场门禁，仍在组合回放中按实际跨越的 8 小时区间扣除。
- `projected_cost_r > 0.20R` 时阻塞该交易；缺少或非正初始风险同样阻塞。`0.20R` 是固定成本预算，不扫描阈值。

## 3. 统一回放与门禁

- 标准组合继续使用 `100U / risk-scale 0.375 / 容量12 / 每边额外5bps / 资金费1bps每8h`。
- 双倍压力固定为每边额外 `10bps`、资金费 `2bps/8h`。
- 必须报告过滤数量、成交频率、有效事件、方向、IS/OOS、12/3 月 fixed-parameter walk-forward、年度、收益集中度和历史币池限制。
- 标准与双倍成本均须满足净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、保守回撤 `<=15%`；实际频率必须仍为 `8—40/月`。
- IS/OOS 必须都为正，所有有成交的 walk-forward 窗口不得出现负 EV；历史币池缺口继续阻止最终晋级。
- 任一门禁失败即淘汰，不扫描 `0.15/0.25/0.30R`，不按方向、币种、信号家族或月份设置不同成本上限。

## 5. 实测结果

V68 在 V60 的 251 笔原始交易中按信号时点预计成本过滤 39 笔，统一资金组合实际接受 212 笔、覆盖 63 个币种和 159 个有效市场事件，约 `7.02 笔/月`、`5.26 个有效事件/月`。

| 成本口径 | EV | PF | 日频 Sharpe | Recovery | 保守盘中回撤 |
|---|---:|---:|---:|---:|---:|
| 标准成本 | 0.735R | 2.421 | 1.842 | 6.613 | 6.09% |
| 双倍成本 | 0.671R | 2.230 | 1.695 | 6.072 | 6.10% |

- 标准成本 IS 为 143 笔、`EV 0.538R / PF 1.900 / Sharpe 1.333 / Recovery 4.159`；OOS 为 69 笔、`EV 1.144R / PF 3.573 / Recovery 3.731`。
- 双倍成本 IS 为 `EV 0.476R / PF 1.751 / Recovery 3.485`；OOS 为 `EV 1.077R / PF 3.312 / Recovery 3.502`。
- 原本为负的 walk-forward test-2 被修复到约 `EV 0.098R / PF 1.195`，所有有成交测试窗均转正，但该弱窗仍远低于职业门槛。

## 6. 亏损簇逆向归因

- 39 笔被过滤交易中，38 笔为 `compressed_breakout` 空头，1 笔为 V27 baseline 多头；门禁主要识别的是初始风险过窄的压缩突破空头，不是普遍方向问题。
- 被过滤组在 IS 20 笔仍有 `PF 1.826 / 平均 +0.642R / 合计 +12.85R`，OOS 19 笔才转为 `PF 0.928 / 平均 -0.055R / 合计 -1.04R`。因此成本效率确实发生时间漂移，但不能据此把同类历史交易全部定义为坏单。
- 保留的压缩突破空头为 45 笔、`PF 2.518 / 平均 +0.826R`；成本/R 对该家族有区分度，但过滤同时损失了足够多的早期盈利交易，使频率跌破硬门槛。
- 不再尝试把该家族止损机械放宽到 `1ATR`：V43 已对主要受影响家族验证过同类假设，EV/PF 和弱 walk-forward 均恶化。

## 7. 最终决策

`rejected_not_promotable`。V68 的标准与双倍成本聚合指标均达标，但组合频率仅约 `7.02 笔/月`，IS 质量、OOS Recovery、walk-forward 强度和历史 point-in-time 币池合同仍失败。该门禁只保留为亏损诊断证据；不扫描成本上限，不创建可运行配置，不进入 Paper/Live。
