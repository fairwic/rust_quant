# Vegas 震荡区动态止盈消融 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_range_dynamic_tp_ablation_4h_research`。
- 出场规则版本：`range_dynamic_tp_ablation_v1_20260720`。
- 候选配置版本：`xasset_4h_top100_v47_disable_range_dynamic_tp_20260720`。
- 冻结来源：v42 `12682..12781`；不携带已判退的 v46 失败突破新增入场。
- 仅运行本地 `ResearchBar`；100 个配置必须保持 `enabled=false`，不覆盖 v27/v42，不进入 Paper、Live 或生产默认消费路径。

## 2. 预注册亏损归因

v42 中被 `RANGE_TP_RATIO` 或 `RANGE_TP_ONE_TO_ONE` 标记的 21 笔交易，盈利时经常只兑现约 `0.14R~0.80R`，而失败时仍承担约 `-1.05R`。该组空头 PF 为 `0.824`、多头 PF 为 `1.145`，说明窄布林带不是无优势入场的充分证据，当前问题更直接地来自“缩短止盈、保留完整止损”的负向盈亏不对称。

本候选只消融震荡区基于入场 K 线振幅的近端动态止盈，让完全相同的入场继续使用既有 `2.5 ATR` 止盈、信号止损和 ATR 风控。它不新增过滤器，不修改信号时点，也不扫描新的 R 倍数。

## 3. 冻结规则

1. 从 v42 原样继承全部入场、止损、仓位、容量、成本、压缩突破弱扩张门禁和低 ATR 扫高确认。
2. 仅设置 `range_filter_signal.is_open=false`，取消 `RANGE_TP_RATIO` / `RANGE_TP_ONE_TO_ONE` 生成的近端动态止盈价格。
3. v42 的 `entry_block_config.block_low_volume_inside_range_entry=false`，因此该开关按冻结配置只影响退出；候选入场集合必须与 v42 完全相同，否则先判定存在合同漂移，不解释收益。
4. 不修改既有 `atr_take_profit_ratio=2.5`、`fixed_signal_kline_take_profit_ratio=0.25`、初始保护止损、移动止损或同 K 线止损优先级。
5. 不按多空、币种、年份、RSI、ATR、Fib 或历史输赢选择性关闭动态止盈；唯一变量是整个震荡动态止盈模块的消融。

## 4. 统一回放与停止门禁

- 固定组合：`100U`、单笔风险 `0.75%`、容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 联合目标：实际成交频率 `>=8/月`；净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、盘中回撤 `<=15%`。
- 必须核对候选与 v42 的入场键集合完全一致，并单列原 21 笔震荡交易在新退出规则下的 discovery/validation EV、PF 与退出类型迁移。
- 标准成本任一联合门禁失败即拒绝，不扫描替代 TP 倍数，也不叠加 v46 来补频率。
- 即使质量门槛改善，若频率仍低于 `8/月`，本候选只能作为下一独立 setup 的质量基线；不得单独宣称晋级。
- 标准成本全部通过后才运行双倍成本；即使通过，也只能标记为 `development_candidate_forward_shadow_required`。

## 5. 冻结后结果与决策

- 本地禁用配置 100 个，回测 `13184..13283`。
- 关闭动态止盈后持仓时间改变，ETH `2024-09-16 04:00`、ETC `2025-09-22 08:00`、BTC `2026-06-18 00:00` 等后续入场被同币种未平仓仓位阻塞，执行入场从 v42 的 238 笔变为 235 笔。
- 因入场集合不再相同，违反第 3 条消融身份门禁；更长持仓还产生未闭合记录，使组合回放在非空 `close_price` 合同处显式失败，不能生成可比较收益结论。
- v47 按协议拒绝；不修补结果、不扫描替代 TP，也不把解码失败解释为策略改善。配置保持 `enabled=false`。
