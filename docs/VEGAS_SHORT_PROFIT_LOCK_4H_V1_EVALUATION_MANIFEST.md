# Vegas Short Profit Lock 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_short_profit_lock_4h_research`。
- 出场规则版本：`short_profit_lock_2r_to_1r_v1_20260720`。
- 候选配置版本：`xasset_4h_short_profit_lock_v34_20260720`。
- 冻结基线：`xasset_4h_top100_v27_risk075_cap12_20260719`，单币回测 `10976..11075`。
- 只运行 `ResearchBar`；配置保持 `enabled=false`，不覆盖 v27，不进入 Paper、Live 或 `production_default`。

## 2. 候选来源

- v27 的空头亏损存在盈利回吐，但 v33 证明 `1.5R → 保本` 触发过早，会大量截断趋势延续盈利单。
- 本候选不扫描阈值，固定采用常见的二阶段 R 保护：先让行情证明达到 `2R`，再只锁定 `1R`；相较 v33，触发更晚且保留正收益缓冲。
- 在提出本候选前已经查看完整区间的 MFE 与 v33 结果，因此它仍是同样本诊断候选，不能作为严格 OOS 或晋级证据。

## 3. 固定规则

```text
仅限 short：
若一根已经完成的持仓中 4H K 线最低价首次达到 entry - 2.0 * initial_R：
    在该 K 线完成后，把保护止损移动到 entry - 1.0 * initial_R；
    新止损从下一根 K 线开始生效。
```

- `initial_R = abs(entry - initial_stop_price)`，整笔交易冻结不变。
- 不修改入场、仓位、初始止损、ATR 止盈、多头规则或并发上限。
- 同一根 K 线同时达到 `2R` 和回抽 `1R` 时，不允许回测在棒内锁盈；只允许下一根 K 线触发新止损。

## 4. 决策口径

- 分别报告 `< 2026-01-01` 与 `>= 2026-01-01` 的交易数、净 R、EV 和 PF；任一时段明显恶化即拒绝。
- 完整回测必须允许提前退出后重新接收后续信号，交易频率不允许因入场过滤下降。
- 同时报告被锁盈交易中原盈利/原亏损的迁移，确认改善不是只来自单币或单月。
- 即使通过，也只能保留为 disabled 研究候选，等待未见时间窗口或 walk-forward 复核。

## 5. 实际结果与结论

- 本地回测范围：`back_test_log.id=11781..11880`，100 个币种配置均保持 `enabled=false`。
- 候选共完成 156 笔交易；空头 124 笔、65 胜，胜率 52.42%，但空头净收益仅 55.801R、EV 0.450R、PF 1.897。
- 冻结 v27 的空头基线为 122 笔、净收益 102.013R、EV 0.836R、PF 2.363。候选虽然提高胜率，却截断了决定策略期望的趋势右尾。
- 发现段 `< 2026-01-01`：候选 115 笔、净收益 42.982R、EV 0.374R、PF 1.726，弱于 v27 的 114 笔、58.622R、0.514R、1.841。
- 验证段 `>= 2026-01-01`：候选 41 笔、净收益 27.718R、EV 0.676R、PF 2.878，弱于 v27 的 40 笔、58.290R、1.457R、4.455。
- 32 笔盈利保护退出合计约 30.296R，但原本可继续触发 ATR 止盈的右尾收益被大量提前兑现；发现段与验证段同时恶化，不属于单一区间偶然波动。

**决策：拒绝 v34，不晋级，不继续搜索保护阈值。** 配置继续保持 disabled，冻结 v27 不变。
