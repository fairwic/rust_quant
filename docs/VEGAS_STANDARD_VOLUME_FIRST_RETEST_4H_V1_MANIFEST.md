# Vegas 普通放量首次回踩 4H V1 清单

## 1. 身份与冻结来源

- 策略键：`vegas_liquidity_sweep_first_retest_4h_research`；本轮只改变同一家族的量能阈值，因此保留既有 key、使用独立版本。
- 版本：`xasset_4h_top100_v69_first_retest_volume2_0_costcap020_20260721`。
- 冻结来源：V60 `back_test_log.id=15288..15387`；统一组合继续使用 V68 已预注册的 `projected_double_execution_cost_r <= 0.20R` 入场成本门禁。
- V69 只扩展“扫流动性后首次回踩”机会，不覆盖 V60/V63/V65/V68，不进入 Paper/Live。

## 2. 预注册机会假设

V60 的首次回踩家族共有 13 笔，样本内外均为正，但触发冲击量固定为 `2.5x`，机会覆盖不足。V69 只验证一个新假设：首次回踩不必要求巨量冲击，只要达到项目已有的普通放量边界 `2.0x`，完整的“扫流动性 -> 反向确认 -> 紧邻首次回踩守住”序列仍可能提供独立优势。

- `2.0x` 是 V63 已使用的普通放量语义，不根据 V69 结果扫描或调整。
- 只把首次回踩专用冲击量从 `2.5x` 降到 `2.0x`；低 ATR 两棒扫高、上方扫单后跌破确认低点、压缩突破及其他 Vegas 路径继续使用原配置。
- 多头与空头保持对称；确认、首次回踩窗口、结构保护止损和现有 `2R` 目标上限全部不变。
- 成本门禁只使用入场价、数量和初始保护风险；资金费仍按实际持仓路径扣除。
- 不增加 MACD、FVG、BOS/CHoCH、RSI、影线、EMA 或币种特调条件。

## 3. 固定回放合同

- 单币：当前 100 币、4H、V60 相同历史范围和 `0.75%` 配置风险，所有配置 `enabled=false`。
- 组合标准成本：`100U / risk-scale 0.375 / 最大并发12 / 单边额外5bps / 资金费1bps每8h`。
- 双倍压力：单边额外 `10bps`、资金费 `2bps/8h`。
- 时间切分：`2026-01-01 00:00:00 UTC`；固定参数 `12个月训练隔离 + 3个月测试` walk-forward，不在窗口内重新拟合。
- 与 V60 做精确入场键差分，新增交易必须带首次回踩审计标签；共同交易不得漂移。

## 4. 晋级与停止规则

- 组合实际成交频率 `8—40笔/月`，同时报告有效市场事件数。
- 标准与双倍成本均须达到：净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、日频 Sharpe `>=1.5`、保守盘中回撤 `<=15%`。
- IS/OOS 必须都为正；所有有成交的 walk-forward 窗口不得为负；新增首次回踩组在 IS/OOS 也必须分别为正。
- 新增机会不能由单币或单一相关事件主导；必须保留历史 point-in-time 币种池缺口 blocker。
- 任一硬门禁失败即拒绝本版本；不追加 `1.8x/2.2x`、方向、影线、MACD 或市场状态补丁。

## 5. 预登记状态

- 记录时间：`2026-07-21`，早于读取 `2.0—2.5x` 首次回踩候选数量与盈亏结果。
- 决策：`research_only_pre_registered`。
- 配置/Paper/Live 晋级资格：`false`。

## 6. 实现与身份核对

- 为首次回踩分支新增独立可选字段 `first_retest_min_volume_ratio`；未配置时严格回退既有全局冲击量阈值，旧版本行为不变。
- V69 的 100 条配置均为 `enabled=false`；除研究身份与 `first_retest_min_volume_ratio=2.0` 外，与 V60 冻结配置没有非预期差异。
- 单币回测为 `back_test_log.id=15921..16020`，共 254 笔。与 V60 精确入场键差分为共同 251 笔、新增 3 笔、移除 0 笔、共同交易结果漂移 0 笔。
- 新增 DOGE、ETHFI、CFX 三笔均为多头，成本前后均盈利，合计约 `+1.156R`、平均约 `+0.385R`；没有按币种或结果追加条件。

## 7. 统一组合结果

叠加 V68 的 `0.20R` 预计双倍成本上限后，39 笔被过滤，实际接受 215 笔、覆盖 64 个币种和 160 个有效市场事件，约 `7.12 笔/月`、`5.30 个有效事件/月`。

| 成本口径 | EV | PF | 日频 Sharpe | Recovery | 保守盘中回撤 |
|---|---:|---:|---:|---:|---:|
| 标准成本 | 0.730R | 2.432 | 1.854 | 6.661 | 6.09% |
| 双倍成本 | 0.666R | 2.239 | 1.706 | 6.114 | 6.10% |

- 标准成本 IS 为 144 笔、`EV 0.538R / PF 1.906 / Sharpe 1.341 / Recovery 4.187`；OOS 为 71 笔、`EV 1.120R / PF 3.592 / Recovery 3.763`。
- 双倍成本 IS 为 `EV 0.475R / PF 1.756 / Sharpe 1.191 / Recovery 3.509`；OOS 为 `EV 1.054R / PF 3.328 / Recovery 3.529`。
- 最弱 walk-forward test-2 仍只有约 `EV 0.098R / PF 1.195`；新增三笔没有修复核心时间稳定性问题。

## 8. 最终决策

`rejected_not_promotable`。普通放量首次回踩的三个新增样本方向正确，但机会密度远低于预期；组合频率仍低于 `8 笔/月`，且 IS、OOS Recovery、双倍成本分段与历史币池合同未通过。按预登记停止，不扫描 `1.8x/2.2x`，不叠加 MACD、FVG、BOS、影线或币种条件；100 条配置继续保持 disabled，不进入 Paper/Live。

## 9. 组件去耦补充审计

2026-07-21 按入场时 `dynamic_config_log.adjustments` 重新做互斥归因后，V60 可审计的首次回踩已成交口径为 11 笔，V69 为 14 笔；第 2 节“13 笔”不再作为已成交组件口径使用。三个新增多头事实不变。

V69 的 254 笔原始交易由 153 笔 Legacy Core、83 笔压缩突破空头、4 笔即时扫流动性空头和 14 笔首次回踩组成。成本门禁拒绝的 39 笔中，38 笔来自压缩突破，说明组合质量改善主要来自独立质量政策清洗压缩空头，而不是首次回踩本身已经稳健。

完整证据见 [V69 组件去耦审计](VEGAS_V69_COMPONENT_DECOUPLING_AUDIT_4H_20260721.md)。本清单最终决策不变。
