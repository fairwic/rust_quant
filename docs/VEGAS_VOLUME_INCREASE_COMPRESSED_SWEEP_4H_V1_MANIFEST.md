# Vegas 既有放量标准压缩突破 4H v1 评估清单

## 1. 研究身份与边界

- 独立研究策略键：`vegas_volume_increase_compressed_sweep_4h_research`。
- 配置版本：`xasset_4h_top100_v63_volume2_compressed_sweep_20260721`。
- 冻结来源：V60 `15288..15387`；不携带 V61 的 `2.5x` 全量门禁，也不携带 V62 的第二根首次回测机会。
- 仅运行本地 `ResearchBar`；100 个配置必须保持 `enabled=false`，不覆盖 V60/V61/V62，不进入 Paper、Live 或生产默认消费路径。
- 本轮是在查看 V60/V61 分桶后提出的事后假设，只能形成 `forward_shadow_candidate_disabled`；历史门禁全部通过也不构成独立样本验证。

## 2. 冻结归因与市场机理

V61 要求压缩突破空头相对量 `>=2.5x` 后，组合 EV/PF 提升到 `0.722R / 2.387`，但交易数从 251 降到 224，约 `7.42/月`，低于全市场 4H 的 `8/月` 下界；V62 只新增 1 笔，无法补足频率。

对 V61 移除的 27 笔按项目已经存在的两档量能标准切分：

- `1.5x <= relative volume < 2.0x`：样本内 3 笔、EV/PF `1.339R / 2.801`，但收益由 BTC `+6.250R` 主导；样本外 5 笔、EV/PF `-0.657R / 0.257`。
- `2.0x <= relative volume < 2.5x`：样本内 7 笔、EV/PF `0.117R / 1.125`；样本外 12 笔、EV/PF `0.229R / 1.362`。两个时段期望同为正，但该增量家族自身 PF 仍低于组合目标。

`2.0x` 直接复用 `VolumeSignalConfig.volume_increase_ratio` 的既有放量标准；`2.5x` 是流动性冲击标准。V63 验证“普通压缩突破至少需要既有放量，而不必全部达到流动性冲击量”这一单一机理，不扫描二者之间的新阈值。

## 3. 冻结规则

1. V60 的 legacy Vegas、Fib 延迟激活、两棒扫单、首次回测、扫高跌破低点 + MACD 零轴位置、退出、风险和组合合同全部不变。
2. 只修改新增的 `compressed_range_breakout_short` 家族；其 5 根整理、`3%` 宽度、`1%` 收盘跌破、`60%` 实体、MACD 空头加速、EMA/BOS 冲突门禁与结构止损保持不变。
3. 当前信号棒相对量必须 `>=2.0x`；`1.5x <= relative volume < 2.0x` 不生成压缩突破空头，边界 `2.0x` 包含在内。
4. V63 不启用弱量一棒延迟，也不允许价格位移替代量能；不增加 EMA、MACD、RSI、ATR、FVG、BOS/CHoCH、币种、月份或市场状态过滤。
5. 多头压缩突破和其他入场家族不受该门禁影响。必须精确证明相对 V60 只移除预期的 8 笔 `<2.0x` 压缩空头，且共同交易的时点、方向与退出不发生实质改变。
6. 预期原始交易为 243 笔；该数量来自已经查看的历史诊断，只用于执行合同核对，不视为未见结果。

## 4. 统一门禁与停止条件

- 固定组合：`100U` 初始资金、单笔风险 `0.75%`、最大容量 `12`、单边额外滑点 `5 bps`、资金费 `1 bps/8h`。
- 联合目标：实际成交频率 `8—40/月`；净 EV `>=0.6R`、PF `>=2.2`、Recovery `>=4`、Sharpe `>=1.5`、盘中最大回撤 `<=15%`。
- 同时报告有效市场事件、样本内/样本外、12/3 月 walk-forward、双倍成本压力、年度、多空和收益集中度。
- `2.0—2.5x` 增量家族必须继续单列；其跨期正期望不能被 V60 基线掩盖，但 PF 低于目标也必须保留为限制说明。
- 标准成本任一联合门槛失败即拒绝，不修改 `2.0x`、不增加第一根退出或其他指标。标准成本全部通过后才运行双倍成本与时间稳定性检查。
- 即使历史联合门禁全部通过，V63 仍只能保留为 disabled forward-shadow 候选，必须等待未见未来数据后再讨论晋级。

## 5. 实际结果与决策

- 本地回测 `15620..15719` 共 100 个配置、243 笔；相对 V60 共同 `243`、移除 `8`、新增 `0`，共同交易没有实质变化。8 笔移除项全部为 `<2.0x` 的压缩突破空头，6 负 2 正，其中 BTC `2024-08-04` 的 `+6.250R` 是被截断的主要右尾。
- 标准组合接受 243 笔、63 个币种、179 个有效事件，约 `8.04/月`；EV `0.674R`、PF `2.271`、日频 Sharpe `1.759`、Recovery `6.653`、保守盘中回撤 `6.09%`，三年收益均为正。聚合门槛全部通过，但频率只比下界多约一笔。
- `2026-01-01` 历史切分中，样本内 160 笔仅为 `EV 0.525R / PF 1.838 / Sharpe 1.284 / Recovery 3.832`；留出段 83 笔为 `0.959R / 3.144`。该切分已被查看，不是严格 OOS。
- 固定参数 12/3 月 walk-forward 的 test-2 为 `EV -0.330R / PF 0.733`，test-7 为 `0.439R / PF 1.544`。双倍成本虽保留 `EV 0.604R`，PF 下降到 `2.084`。
- `2.0—2.5x` 增量家族 19 笔的样本内/留出 EV 都为正，但自身 PF 仅 `1.125/1.362`；它补足频率，却没有修复弱窗口与成本脆弱性。

结论：V63 标准总表过线，但时间稳定性和双倍成本 PF 失败，只能保留 disabled 诊断版本，不进入 Paper/Live，也不以该历史宣称策略目标已经达到。
