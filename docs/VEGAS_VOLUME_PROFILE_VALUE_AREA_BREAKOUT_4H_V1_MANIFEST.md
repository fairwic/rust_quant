## 2. 预注册假设

V71 的回踩确认多头有约 71% 胜率，但确认后盈利通常只剩约 `0.215R`；12 根路径也证明单纯延长退出不足以达到目标。V72 只验证一个新问题：价值区外接受的方向信息是否在放量突破收盘时更有价值，等待下一根回踩是否已经错过主要位移。

- 用当前突破棒之前的 48 根完成 4H K 线冻结 24 分箱、70% 成交量价值区和平均成交量。
- 多头：突破棒开盘位于价值区内、收盘高于 VAH、为阳线且成交量 `>=2.0x` 历史均量；空头严格镜像 VAL。
- 入场为突破棒收盘，不等待回踩；只使用该时点已经完成的 K 线。
- 结构止损放在被突破边界内侧 `0.6%`：多头 `VAH×0.994`，空头 `VAL×1.006`，并继续受既有最大损失合同约束。
- 保留现有动态退出，不增加固定 R 目标；这样只检验“提前一棒入场”，不同时修改入场与退出。
- 不要求或扫描 EMA、MACD、FVG、BOS/CHoCH、RSI、影线、币种、分箱、价值区比例、量能或缓冲参数。

## 3. 因果、回放与门禁

- 配置默认关闭；100 条研究配置全部 `enabled=false`，不进入 Paper/Live。
- 单元测试覆盖多空、49 根窗口、量能、新鲜跨越、未确认 K 线和当前突破棒不污染冻结价值区。
- 有效回放必须只包含 V72 信号和专属边界止损；V69 旧交易由组合层优先合并，不能在单币状态机里被 V72 修改。
- 新增家族总样本、IS、OOS必须分别为正且 PF `>1`；失败即早停，不由 V69 基线掩盖。
- 若增量通过，再执行 V68 成本上限、统一资金/容量、有效事件、walk-forward、标准和双倍成本。最终门槛仍为 EV `>=0.6R`、PF `>=2.2`、MDD `<=15%`、Recovery `>=4`、Sharpe `>=1.5`、频率 `>=8笔/月`。
- 任一门禁失败即拒绝；不追加回踩、固定目标、趋势过滤或参数邻域。历史 point-in-time 币种池缺口仍阻断生产晋级。

## 5. 回放结果

- 有效单币回放 `back_test_log.id=16321..16420`，共 702 笔独立 V72 交易；100 条配置全部 disabled。
- 全部交易 208 胜，净 EV/PF `-0.002226R / 0.997099`；IS 508 笔为 `+0.061426R / 1.082076`，OOS 194 笔为 `-0.168904R / 0.793238`，增量门禁失败。
- 多头 190 笔、77 胜，EV/PF `-0.597938R / 0.104943`；IS/OOS 分别为 `-0.506963R / 0.139081` 与 `-0.761158R / 0.060422`，即时向上突破明显没有优势。
- 空头 512 笔、131 胜，EV/PF `+0.218839R / 1.272127`；IS/OOS 分别为 `+0.241073R / 1.301782` 与 `+0.150726R / 1.183686`。空头方向跨期为正，但仍远低于职业门槛。

## 6. 多空差异解释

- 多头 77 笔动态 ATR 盈利平均只有 `+0.173R`，85 笔信号止损平均 `-1.146R`，另有 28 笔最大损失；向上突破更多表现为短促挤压或冲高后重新回到价值区。
- 空头 104 笔 ATR 盈利平均约 `+4.659R`，但 393 笔信号/最大损失止损；向下突破胜率低，却更容易在去杠杆或风险释放时形成多根 4H 长尾延续。
- 因此“更早入场”只验证了方向不对称，没有把 V72 变成可交易策略。多头不能靠回踩或 MACD 修复；空头虽然是可继续研究的机制，但其 PF `1.27` 与 EV `0.22R` 仍不足以并入 V69。

## 7. 最终决策

- V72 总样本与 OOS 为负，按预登记早停，不进入 V69 组合、walk-forward 或成本压力晋级。
- 不在 V72 内关闭多头后直接宣称通过，也不扫描价值区、量能、止损或退出。若继续，空头方向筛选必须作为新的版本假设并承认其来自已查看方向拆分，只能等待独立验证。
- 最终状态：`rejected_total_and_oos_negative`；未进入 Paper/Live、未部署、未触发交易 mutation。
