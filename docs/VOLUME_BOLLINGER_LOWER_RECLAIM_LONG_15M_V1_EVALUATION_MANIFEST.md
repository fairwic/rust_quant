# 放量布林下轨收回做多 V1 评估清单

## 1. 研究身份

- 策略：`volume_bollinger_lower_reclaim_long_15m_v1`
- 周期：15分钟
- 状态：`research_only_not_promoted_no_samples`
- 上一 TradingView 源码：FNV-1a 32 `403adb2b`
- 当前 TradingView 源码：FNV-1a 32 `90c8fc84`

- 数据语义：`volume == vol_ccy`，不计算 `volume × close`

## 2. 预注册假设

当15分钟价格处于前48根已完成 K 线区间底部，完整量能把低点打到布林下轨外，但长下影和高位收盘把价格收回轨内，同时 RSI 与 MACD 显示连续动量修复，且冻结布林中轨仍提供至少 `1.1R` 空间时，可能形成可交易的短周期底部反转。

该策略是独立 Research 家族，不修改现有 RSI 超卖反转规则。

## 3. 冻结入场

- 当前 K 线必须是既有完整量能事件：

```text
filtered_volume_ratio[t] >= 2.5
&& vol_ccy[t] >= weekly_p90(vol_ccy[t-672 ... t-1])
```

- `low[t] < BOLL_LOWER_20_2[t]`。
- `close[t] > BOLL_LOWER_20_2[t]`。
- 下影线占整根振幅至少 `50%`。
- 收盘位于整根振幅顶部 `75%` 以上。
- 位置区间只使用 `t-48～t-1`：

```text
bottom_position =
    max(0, (low[t] - prior48_low) / (prior48_high - prior48_low))

bottom_position <= 15%
```

- `35 <= RSI14[t] <= 50`。
- RSI 严格连续回升：`RSI14[t] > RSI14[t-1] > RSI14[t-2]`。
- 标准 `MACD(12,26,9)` 三根柱均为负。
- MACD 负柱严格连续缩短：`HIST[t] > HIST[t-1] > HIST[t-2]`。
- 只在 `t` 收盘确认，最早于 `t+1` 开盘成交。
- 同棒多空冲突不交易。
- 已有同向持仓不加仓；本分支原始信号与实际订单分别计数。

## 4. 冻结退出

- 初始止损：信号 K 线低点下方一个最小价格单位，再向下取整到 tick。
- 结构目标：信号收盘时的 `BOLL_MIDDLE_20[t]`，向下取整到 tick。
- 信号收盘预期：

```text
expected_r =
    (frozen_middle - close[t])
    / (close[t] - frozen_stop)
```

- `frozen_middle <= close[t]` 或 `expected_r < 1.1` 时禁止开仓。
- 下一根实际开盘未知，因此 `1.1R` 只能使用信号收盘预检；不得读取未来开盘取消历史信号。
- 首次触达冻结中轨时平掉100%仓位，不分批、不移动目标、不启用保本。
- 独立订单为 `Long BLR`，保护单为 `Long BLR protection`，退出注释为 `BLR_TP / SL`。

## 5. 集成边界

- 不加入旧 `rsiPatternLong`，不放宽 RSI 超卖门槛。
- 不复用旧 `takeProfitAtr`；量比 `2.5～3.0` 仍可形成候选。
- 不使用逆势横盘目标；该分支以自身止损和中轨目标旁路对应门禁。
- 不加入突破多单家族，不启动冻结突破线保护。
- 与其他多头家族重合时，`Long BLR` 优先使用自身绝对止损和冻结中轨。
- 与空头候选同棒成立时沿用现有冲突规则，不交易。
