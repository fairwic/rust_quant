- 策略：`volume_effort_no_result_lower_high_boll_reclaim_short_15m_v1`
- 周期：15分钟
- 状态：`research_only_not_promoted_insufficient_cross_symbol_samples`

- 新 TradingView 源码：FNV-1a 32 `403adb2b`

## 2. 预注册假设

当较早高位锚点已经进入 RSI 超买区，当前使用更大的完整量能再次上冲，却只能形成接近前高的次高点，并以强阴线从布林上轨外收回轨内时，说明买方努力没有得到价格结果，可能形成可交易的高位供应拒绝。

该策略不是 RSI 顶背离的参数放宽，也不覆盖现有策略身份。

## 3. 冻结入场

- 锚点窗口：`t-20～t-80`，包含端点。
- 锚点：窗口内最高高点；同高取最近。
- 锚点先仅按价格确定；后续条件失败时不回退。
- 当前高点严格低于锚点。
- 两高距离满足：

```text
gap / q.high <= 0.5%
OR
gap / ATR14[t] <= 0.5
```

- 当前必须是既有完整量能事件。
- `vol_ccy[t] >= 1.25 × vol_ccy[q]`。
- `RSI14[q] >= 70`。
- `55 <= RSI14[t] <= 70`，且 `RSI14[t] < RSI14[q]`。
- 当前收阴。
- 阴线实体占振幅至少 `60%`。
- 阴线实体至少 `0.5 ATR14[t]`。
- 收盘位于当前振幅底部 `20%`。
- `high[t] > BOLL_UPPER_20_2[t]` 且 `close[t] < BOLL_UPPER_20_2[t]`。
- 只在信号棒收盘确认，最早下一根开盘成交。
- 同棒多空冲突不交易。
- 已冻结突破多单仍站在线上时阻断反手；保护解除后旁路普通逆势横盘目标门禁。

## 4. 冻结退出

- 初始止损：`max(q.high, t.high) + 1 tick`，向上取整到价格 tick。
- `1R` 后在确认棒收盘更新近似保本。
- `1.5R` 全部止盈。
- 不复用趋势延续 ATR 目标。
- TradingView 在下一根开盘前不知道实际成交价，因此 R 使用信号收盘到结构止损的距离近似；这是图表研究限制。
