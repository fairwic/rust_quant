## 3. 冻结规则

### 初次质量收复

```text
最近一次上穿发生在 t
&& t-1 收盘位于 EMA596 下方 0～0.5 ATR
&& t 收盘位于 EMA596 上方 1.0～1.8 ATR
&& EMA12 < EMA144 < EMA596 的完整空头排列已经解除
&& vol_ccy[t] >= 前 672 根 P90
&& vol_ccy[t] / 前 20 根中位量 >= 2.5
&& 阳线实体占振幅 >= 60%
```

### 收复接受后二次加速

```text
最近一次上穿距 t 为 8～24 根
&& 上穿后每根已完成 K 线均 close > EMA596
&& t-1 距 EMA596 为 0～0.5 ATR
&& t 距 EMA596 为 1.0～1.8 ATR
&& EMA12 > EMA144 且 EMA12 > EMA596
&& abs(EMA144 - EMA596) <= 0.25 ATR
&& EMA596 斜率非负
&& vol_ccy[t] / 前 20 根中位量 >= 2.0
&& 阳线实体占振幅 >= 50%
```

两个入口共同要求：

```text
close[t] > max(high[t-4 ... t-1])
&& high[t] > high[t-1]
&& low[t] > low[t-1]
&& 结构止损风险 > 0
&& 结构止损风险 <= 2 ATR
```

二次加速不要求初次质量收复曾经生成订单；它只依赖当时可见的 EMA596 收复事件及后续接受证据。同一次收复事件最多消费一次，退出后也不能在同一 8～24 根窗口重复开仓。

止损冻结在前 4 根最低点下方一个 tick；目标冻结为信号收盘风险的 2R。当前版本不启用保本、分批止盈或 ATR 目标。
