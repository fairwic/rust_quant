## 2. 读取结果前冻结的规则

```text
reclaim =
    最近 32 根内 close 上穿 EMA596
    && 上穿后所有已完成 K 线都保持 close > EMA596

distance_transition =
    (close[t-1] - EMA596[t-1]) / ATR14[t-1] <= 0.50
    && (close[t] - EMA596[t]) / ATR14[t] >= 1.00

structure =
    close[t] > max(high[t-4 ... t-1])
    && high[t] > high[t-1]
    && low[t] > low[t-1]

volume_expansion =
    vol_ccy[t] >= P90(vol_ccy[t-672 ... t-1])
    && vol_ccy[t] / median(vol_ccy[t-20 ... t-1]) >= 2.5

candle =
    close[t] > open[t]
    && abs(close[t] - open[t]) / (high[t] - low[t]) >= 60%

setup =
    reclaim
    && distance_transition
    && structure
    && volume_expansion
    && candle
```

这里故意不复用既有过滤后 `volume_event`：在刚经历抛售高潮的转换段，过滤后均值容易被前序尖峰抬高。该分支只使用信号时点已知的周 P90 与前 20 根原始 `vol_ccy` 中位数，两项必须同时通过；`volume` 不再乘以 `close`。

## 3. 冻结执行与风险合同

```text
initial_stop =
    向下取整到价格 tick(
        min(low[t-4 ... t-1]) - 1 tick
    )

signal_close_risk = close[t] - initial_stop

target =
    向下取整到价格 tick(
        close[t] + 2 * signal_close_risk
    )
```

- setup 在 `t` 收盘确认，使用独立订单 `Long EMA596-D`，最早在 `t+1` 开盘成交。
- 止损和 2R 目标在信号收盘冻结，之后不随 EMA、ATR 或后续结构移动。
- 目标首次触达时平掉 100% 仓位，不启用保本或分批止盈。
- 信号棒若同时存在旧多头候选，归属旧家族；仍保留同棒多空冲突门禁。
- 当前 TradingView 固定 1 单位，手续费、滑点、资金费和下一开盘跳空均未计入。

## 6. 四层认知与结论

### 已知的已知

- 旧规则未入场有确定的门禁原因，不是信号展示或订单执行故障。
- 新分支按收复、贴线到离轨、HH/HL、原始量能扩张和强阳线的组合，严格命中目标样本。
- TradingView 编辑器与本地源码均为 1914 行、UTF-16 FNV-1a 32 `26058470`，编译 0 错误。
- BTC 分支盈利，ETH 分支亏损；跨币种结果不成立。

### 已知的未知

- 当前加载窗口之外的成本后 EV、PF、回撤与有效市场事件数尚未验证。
- 32 根收复年龄、`0.5 → 1.0 ATR` 离轨转换、前 4 根结构和 `2.5x` 中位数量比的参数邻域是否稳定尚不清楚。
- 固定 1 单位没有体现 1% 风险仓位、真实交易所精度、点差和容量。

### 未知的已知

- 用户看到的是“刚从长期压制中脱离”，并不等同于“当根刚上穿”：该样本真实上穿发生在约 26 根之前。
- 旧过滤量比被前序放量尖峰抬高，说明转换段需要与反转锚点不同的量能基线；但这不证明所有市场都应绕过过滤量能。
- BTC 净利润提高的同时回撤翻倍以上，单看收益会掩盖风险恶化。

### 未知的未知

- ETH 失败可能来自币种波动结构、32 根观察窗过宽、2R 目标或未建模成本，当前样本不能归因到单一参数。
- 多个信号可能属于同一次全市场风险偏好切换，交易数不等于独立样本数。
- 下一开盘跳空可能显著改变实际 R，特别是在放量离轨棒之后。

当前最关键的判断是：`volume_ema596_reclaim_departure_hh_hl_long_15m_v1` 已正确实现并解决目标漏单，但它只是 BTC 当前窗口有效、ETH 失败的研究候选。最大风险是用目标 BTC 样本继续事后调参，或因总策略仍为正而误判跨币种通过。下一步只能在预先冻结的未见窗口中加入成本、1%风险仓位、BTC/ETH/其他币种和市场事件聚类后再决定是否创建 V2；当前版本不进入 Paper、Live 或 Rust parity。
