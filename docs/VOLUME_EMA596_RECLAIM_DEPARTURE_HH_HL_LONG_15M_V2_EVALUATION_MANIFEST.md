# EMA596 收复后放量 HH/HL 离轨做多 V2 评估清单

## 1. 预注册身份与边界

- TradingView Research 身份：`volume_ema596_reclaim_departure_hh_hl_long_15m_v2`
- 基线：`volume_ema596_reclaim_departure_hh_hl_long_15m_v1`
- 时间周期：15 分钟
- 设计样本：`OKX:ETHUSDT`，北京时间 `2026-07-24 15:00`
- 决策时点：信号 K 线 `t` 收盘
- 最早成交：`t+1` 开盘
- 状态：`research_only_not_promoted_preregistered_gate_failed`
- 替换关系：不覆盖 V1；V2 使用独立版本和订单身份
- Rust / Paper / Live：保持冻结，本轮只验证 TradingView Research

## 2. 读取 V2 汇总结果前冻结的改动

V2 完整保留 V1 的 32 根观察窗、持续站稳、周 P90、前 20 根中位数量比
`2.5x`、前 4 根 HH/HL 结构、60% 阳线实体、结构止损和 2R 全平，只增加：

```text
accepted_before_signal =
    1 <= reclaim_age[t] <= 32
    && close[t-1] > EMA596[t-1]
    && 0 < (close[t-1] - EMA596[t-1]) / ATR14[t-1] <= 0.50

pre_signal_slow_bear =
    (EMA144[t-1] - EMA144[t-4]) / (3 * ATR14[t-1]) <= -0.015
    && (EMA596[t-1] - EMA596[t-4]) / (3 * ATR14[t-1]) <= -0.0015

setup_v2 =
    setup_v1
    && accepted_before_signal
    && !pre_signal_slow_bear
```

两个斜率阈值直接复用现有 EMA 压缩扩张家族的冻结阈值，不按目标棒重新拟合。
趋势判断只读取 `t-1～t-4` 的已完成 K 线，不能让信号棒自身改变入场背景。

## 4. 预注册保留门槛

在相同 TradingView 数据窗口、固定 1 单位、零手续费/滑点口径下：

- BTC 与 ETH 分别比较 V1 / V2 的分支成交、净利润、PF 和最大回撤；
- V2 不能让任一币种净利润下降或最大回撤扩大；
- 至少一个币种必须严格改善，另一币种无被过滤样本时只能记为中性；
- 删除全部交易不能作为通过依据；
- 结果不满足时，V2 保留为失败研究制品，不回写 V1，也不继续围绕该样本调整阈值。

上述口径只决定是否保留 Research 假设，不等于 Paper 或生产晋级。晋级仍需费用后、
风险归一化、未见窗口、多月份、更多币种和有效市场事件验证。

## 5. 结果

### 5.1 设计样本

V2 已在 TradingView 主研究图表中编译通过，`OKX:ETHUSDT` 的
`2026-07-24 15:00` 不再生成 `Long EMA596-D2`。这不是事后延迟入场：
该棒的 `reclaim_age=0`、前棒离轨为 `-1.3295 ATR`，并且信号前
EMA144 / EMA596 的三棒归一化斜率分别为 `-0.0344 / -0.00574`，
因此“已接受”和“慢线强空头”两层门禁都会独立否决。

需要校正视觉判断：信号前 EMA12 斜率已经转为 `+0.1944 ATR/根`，
并非三条 EMA 全部向下；真正危险的是快线被单棒拉起，而两条慢线仍处于
显著下降状态。

若强制沿用 V1 追入，该棒下一根 `15:15` 开盘约 `1908.46`，
结构止损 `1878.73`，在 `17:15` 先触发止损；固定 1 ETH 毛亏损约
`-29.73 USDT`。`1967.20` 的目标直到 `07-27 07:00` 才触及，
不能使用这段后续行情反写入场决定。

### 5.3 消融与保留结论

当前窗口的 V1 原始候选中，只有 ETH 设计样本同时触发慢线强空头门禁；
所有被 V2 留下的候选本来就没有“两条慢线同时强负”。因此：

- `age>=1 + 0<前棒离轨<=0.5 ATR` 已经完成本窗口的实际交易筛选；
- 慢线斜率门禁为目标风险提供独立解释，但当前 BTC / ETH 样本中没有额外成交贡献；
- 不能把 V2 的整体变化全部归因于斜率过滤，也不能宣称该阈值已跨币种证明。

V2 成功修正了设计样本的语义错误，且相对“无该分支”基线在 BTC / ETH
都保持正向净贡献；但它没有通过预注册的“相对 V1 两币净利润都不下降”门槛，
因为 BTC 净利润降低。因此 V2 只保留为
`research_only_not_promoted_preregistered_gate_failed`，V1 不被覆盖，
Rust / Paper / Live 继续冻结。下一轮只允许在预先登记的未见窗口分别验证：

1. 接受语义门禁；
2. 两条慢线强负否决；
3. 手续费、滑点、1% 风险仓位和参数邻域。
