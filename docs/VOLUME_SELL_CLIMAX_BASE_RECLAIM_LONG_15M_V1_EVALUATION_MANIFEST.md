# 放量杀跌后低位接受失败与强阳收回做多 V1 评估清单

## 1. 研究身份

- 策略：`volume_sell_climax_base_reclaim_long_15m_v1`
- 周期：15 分钟
- 方向：仅做多
- 状态：`research_only_not_promoted`
- 对照基线：`tradingview_velocity_v19_ema_long_conservative_target_gap_v1`
- 数据：`quant_core` 已确认 OKX 永续 15 分钟 K 线，`volume == vol_ccy`
- 成交时序：信号 K 线 `t` 收盘确认，最早在 `t+1` 开盘成交
- 成本压力：单边手续费 5 bps + 单边滑点 3 bps

本分支不放宽现有 `volume_bollinger_lower_reclaim_long_15m_v1`。原规则要求同一根 K 线同时扫出布林下轨并收回；本分支研究的是跨数根 K 线完成的 `sell climax -> base acceptance failure -> bullish reclaim`。

## 2. 预注册假设

当放量长阴把价格打到布林下轨外并跌破 EMA576，随后 2～6 根已完成 K 线始终未接受在放量长阴收盘下方，最后由强阳线放量收回 EMA576、EMA12 和最近四根结构高点时，卖方冲击可能已经衰竭，未来向冻结 EMA676 阻力回归的净期望可能为正。

## 3. 冻结入场规则

### 3.1 杀跌源 K 线 `q`

- 只从 `t-6～t-2` 中选择距离 `t` 最近的完整量能事件；不因最近候选失败而回退到更老候选。
- `q` 必须为阴线。
- `q` 的实体占整根振幅至少 70%。
- `low[q] < BOLL_LOWER_20_2.5[q]`。
- `close[q] < EMA576[q]`。

### 3.2 低位接受失败

- `q+1～t-1` 至少包含 2 根、至多包含 5 根已完成 K 线。
- 期间所有收盘均不得低于 `close[q]`；影线可以再次扫低，但不能以收盘确认更低价格。
- 期间至少一根 K 线的低点不高于 `low[q] + 0.25 ATR14[q]`，证明价格真实回测过杀跌低位，而不是直接 V 型离开。

### 3.3 右侧触发 K 线 `t`

- `t` 为阳线。
- 实体占整根振幅至少 70%，实体至少为 `0.75 ATR14[t]`。
- `close[t]` 同时高于 `EMA12[t]`、`EMA576[t]` 与 `t-4～t-1` 的最高价。
- `vol_ccy[t]` 至少为 `t-20～t-1` 成交量中位数的 1.25 倍；触发棒不要求再次成为完整量能事件。
- `35 <= RSI14[t] <= 60`，且 `RSI14[t] > RSI14[t-1]`。
- `MACD_HIST[t] > MACD_HIST[t-1]`。
- `EMA576[t] > EMA576[t-12]`，避免在慢线仍持续下弯时抄底。
- `close[t] < EMA676[t]`，把本策略限定为 EMA576 收回后向上方慢线回归，而不是突破后追涨。

## 4. 冻结退出规则

- 初始止损：`q～t` 的最低点下方一个最小价格单位，并向下对齐 tick。
- 冻结目标：信号收盘时的 `EMA676[t]`，并向下对齐 tick。
- 以信号收盘预检的收益风险比不足 1.5R 时禁止开仓。
- 首次触达冻结 EMA676 目标时平掉 100% 仓位；不分批、不移动目标、不回写初始 R。
- 已有仓位或同棒多空冲突时沿用 V19 现有阻塞规则。

## 5. 目标案例

- 标的：`HYPE-USDT-SWAP`
- 杀跌源候选：`2026-06-12 14:30`（Asia/Shanghai）
- 低位接受区：`2026-06-12 14:45～15:45`
- 右侧触发候选：`2026-06-12 16:00`
- 最早成交：`2026-06-12 16:15` 开盘

目标案例只能验证规则是否按预期识别，不参与阈值调整；任一冻结条件失败时记录失败项，不事后修改参数补造该交易。

## 6. 多交易对评估口径

- 使用仓库冻结 `top60_v36_direct_kline_20260721_frozen_20260723` 币池。
- 本地数据不足 60/60 时只允许输出 `partial_data_diagnostic`，不得称为正式 Top60 结论。
- 基线与候选使用完全相同的评价窗口、60 天预热、tick size、费用、滑点和成交时序。
- 60 分钟内同方向成交仍按一个时间方向事件聚类，避免把同步市场反弹当作独立样本。
- 同时报告组合、BTC、ETH、其他币与新增家族自身的交易数、胜率、净 R、PF 和最大回撤。

## 7. 预注册决策规则

- 目标 HYPE 案例未被 `t=16:00` 收盘识别：假设实现与图形语义不一致，停止本轮，不调参。
- 新增家族成本后 `PF <= 1` 或净 R 不为正：否决，不并入主策略或 TradingView。
- 新增家族样本少于 30 笔或有效事件不足 20 个：即使为正，也只能保留为低样本 Research。
- 候选使当前 V19 Conservative Target Gap 的成本后净 R、PF 或最大回撤恶化：否决。
- 只有通过上述条件后，才允许另开参数邻域、月份、市场状态和费用压力验证；本轮不做二次调参。

## 8. 2026-08-01 冻结评估结果

### 8.1 HYPE 目标案例审计

- `q=2026-06-12 14:30` 是距离触发棒最近的完整量能事件：量比 3.49，实体/振幅 89.33%，最低价 56.92 低于布林下轨 57.08，收盘 56.94 低于 EMA576 59.17。
- `q+1～t-1` 共 5 根 K 线，最低收盘 56.96，没有收盘接受在 `q` 的 56.94 下方；最低价 56.72，完成了对低位的再次测试。
- `t=2026-06-12 16:00` 为强阳触发候选：实体/振幅 84.04%，实体 1.62 ATR，收盘 57.76 同时站上 EMA12 57.62 与前四根最高价 57.49；量比 2.56，RSI 由 32.09 升至 46.01，MACD 柱由 -0.1486 收缩至 -0.0816。
- 目标案例未通过两项冻结条件：`close[t]=57.76 < EMA576[t]=59.13`，且 `EMA576[t]=59.13 < EMA576[t-12]=59.20`。因此它是慢均线下方的逆势卖压衰竭反弹，不是本清单定义的 EMA576 收复做多。
- HYPE 未计成本的直接单币探针中，基线与候选均为 38 笔、胜率 34.21%、PF 0.859、固定 1 单位净损益 -1.963、平均 -0.1129R/笔；新增家族 0 笔，目标案例未被补造。
