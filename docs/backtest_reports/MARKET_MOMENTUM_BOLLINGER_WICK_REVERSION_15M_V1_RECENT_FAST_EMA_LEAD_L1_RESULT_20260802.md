# 15 分钟动量布林长影回归 V1：近期 EMA12 领先双慢线过滤 L1 结果

## 结论

- 当前等级：`L1 快速研究`。
- 决策：`stop`，保留为独立 Research-only 版本。
- 新定义已经修复旧版的两个漏判：不再要求信号 K 恰好 `false -> true`，也不再要求 EMA144 与 EMA576 完成严格排序。
- 5 个用户目标样本全部按预期年龄复算并被拒绝，说明定义与样本观察一致。
- 但该规则同时拒绝 537/673 个基础触轨 setup，占 `79.7920%`，超过预注册上限 `45%`。它不是一个局部“趋势刚形成”过滤，而是在否决绝大多数逆势候选。
- 因唯一失败门槛正是过度覆盖，本批次没有读取成交、未来 K、退出、R、胜负或 PnL，也没有进入 L2。

## 实际规则

执行顺序保持为：

1. 既有 `market_momentum_exhaustion_reversal_15m_v2` 先产生多空候选；
2. 只保留既有 `directional_wick_limit_12_candles` 分支；
3. 做空要求信号高点触碰 `Bollinger upper(20,2.5)`，做多要求信号低点触碰 `Bollinger lower(20,2.5)`；
4. 最后应用近期对向 EMA 否决，不由 EMA 产生或改写方向。

做空的对向状态为：

```text
EMA12 > EMA144 && EMA12 > EMA576
```

做多完全镜像：

```text
EMA12 < EMA144 && EMA12 < EMA576
```

EMA144 与 EMA576 的相对顺序不参与判断。该状态首次成立时年龄为 1，相邻 K 连续成立则逐根加一，中断归零；`1..=192` 根（48 小时）内拒绝候选。没有连续 3 根确认、EMA169、EMA696、EMA 斜率或均线距离条件。

## 既有 Momentum V2 方向定义未被替代

- 既有做空仍要求过滤量比至少 2.5、当前 `vol_ccy` 达到此前 672 根 nearest-rank P90、此前 96 根净移动至少 `+8%`、信号实体占比大于 10%、上影占比至少 60% 且上影严格长于下影，并以信号高点作为最多 12 根有效的限价。
- 既有做多保持镜像：此前 96 根净移动不高于 `-8%`，下影占比至少 60% 且严格长于上影，并以信号低点作为最多 12 根有效的限价。
- EMA 新规则只在上述方向和 Bollinger 触轨已经成立后否决候选。

## 认知框架

- 已知的已知：旧版漏判原因已经被修复；新规则确实识别 AGLD、SATS 的慢线尚未排序状态，也识别 YFI、NMR、ORDI 已持续一段时间的对向状态。
- 已知的未知：这些被拒绝 setup 的收益是否比保留组差。本轮按门禁禁止读取，因此没有答案。
- 未知的已知：640/673 个基础 setup 本来就处于对向 EMA12 领先状态，这说明该 Bollinger 长影策略天然大量逆着 EMA12 与慢线关系入场；仅靠 48 小时时间上限无法区分“危险的新趋势”和普通逆势回归背景。
- 未知的未知：更有效的早期趋势事件可能需要独立的穿越结构、均线间距或价格接受条件，但它们必须各自成为新的单变量假设，不能从本批次结果事后拼装。

当前最关键判断：这版已经解决“为什么 5 笔没有拒绝”的定义问题，但不具备进入盈亏回放的选择性。最大风险是为了保住这 5 笔而接受 79.79% 的过滤范围，最终把策略本身几乎关闭。
