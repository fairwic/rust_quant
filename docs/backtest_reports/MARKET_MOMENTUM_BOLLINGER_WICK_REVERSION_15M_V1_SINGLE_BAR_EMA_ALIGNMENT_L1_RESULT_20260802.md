# 15 分钟动量布林长影回归 V1：单根 EMA 排列刚形成过滤 L1 结果

> 纠错状态：`rejected_definition_mismatch`。用户最终确认只判断 `EMA12/EMA144/EMA576`；
> 本批错误使用 EMA169 与 EMA696，以下统计仅保留审计，不得用于筛选、晋级或运行。

## 结论

最终用户口径已经按原意冻结：趋势使用信号 K 单根 `EMA12/144/169/696` 严格排列；
不要求连续 3 根，不要求 EMA696 斜率。“刚形成”只表示上一根未按该方向排列、当前信号 K
首次按该方向排列。

同一 673 个 Bollinger 长影基础 setup 全部具备当前与上一根 EMA 数据。494 个 setup 在信号 K
已经处于对向严格排列，但其中 493 个在上一根就已经排列；只有 1 个发生 `false -> true`，影响
比例为 `0.1486%`。该样本为 1 个做空、1 个币种、1 个月份、1 个有效事件，没有做多样本。

除 EMA 完整性外，其余预注册门槛全部失败，因此状态为 `stop`。本轮没有读取成交、信号后 K 线、
MFE、MAE、退出、最终 R、胜负或 PnL，也没有修改 Pine、Paper、ReadOnly、Live、数据库或生产策略。

## 四层认知框架

### 已知的已知

- 基础形态保持不变：长上影且 `high >= upper(20,2.5)` 做空；长下影且 `low <= lower(20,2.5)` 做多。
- 对向单根排列为：做空检查 `EMA12 > EMA144 > EMA169 > EMA696`，做多检查完全镜像的空头排列。
- “刚形成”严格等于上一根 `false`、当前信号 K `true`；上一根只用于状态切换比较，不是确认 K。
- 60 个冻结成员中 44 个具备完整基础窗口，16 个缺数据成员按规则跳过；673 个基础 setup 全部 EMA-ready。
- 基础数据指纹为 `0c3d1e6ce33187fbc0fd528486d837574fe176b73a748b1f44dedd3c14c328f5`；699 根 EMA 输入扩展指纹为 `45496fd9db8998652e4e65c813d031b416abac99e73b9ef30cb053bfb960c2c5`。

### 已知的未知

- “信号 K 收盘接近中轨”的距离阈值尚未冻结，不能与本轮单根 EMA 变量混在一起研究。
- “对侧外轨附近”的距离、同根同时触及止损/中轨/外轨/5R 时的保守顺序尚未冻结。

### 未知的已知

- 状态切换分布为：`aligned -> aligned` 493 个、`false -> false` 179 个、`false -> aligned` 1 个、`aligned -> false` 0 个。
- 这说明基础长影触轨反转信号几乎总是在对向 EMA 排列已经存在一段时间后出现；精确“排列形成首根”与该形态很少同 K 重合。

### 未知的未知

- 15m OHLC 不能证明同一根 K 内多个价格事件的先后顺序，退出研究必须另行冻结保守成交规则。

## 当前关键判断与下一步边界

最关键判断是：用户要求的精确首根 EMA 排列过滤已经被正确表达，但在当前基础 cohort 中只影响
`0.1486%`，不足以进入结果回放。最大不确定性不是 EMA 定义，而是尚未量化的“收盘接近中轨”。
如继续研究，应另立一个 L1 批次，只冻结一个信号时中轨距离阈值；不得查看本轮唯一命中样本的
后续盈亏来决定阈值，也不得把连续确认或 EMA696 斜率重新加回本定义。
