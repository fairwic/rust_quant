# 15 分钟动量布林长影信号极值收回确认 V1：L2 结果

## 最终结论

`stop_at_l2_keep_research_only`。来源极值确认在 L1 有足够覆盖，但“确认后下一根开盘成交”在成本后回放中为负期望，且显著弱于同一确认 cohort 的来源极值被动成交基线。该版本不得进入 L3、Pine、Paper、ReadOnly、Live 或生产注册，也不得叠加中轨减仓、保本、对侧外轨或 5R 退出事后挽救。

## 为什么右侧确认反而更差

1. 139 个实际 pair 中，下一根开盘相对来源影线极值有 137 个是不利成交、2 个相同、0 个更有利；平均牺牲 `0.4806R`，中位数牺牲 `0.2905R`。
2. 83 笔在两侧都止损，40 笔在两侧都止盈；真正决定总差异的是路径翻转：13 笔由基线止盈变成候选止损，只有 2 笔由基线止损变成候选止盈，另有 1 笔候选同棒止损优先。
3. 长影均值回归的优势部分来自“在影线极值获得好价格”。等到价格收回极值再按下一根开盘追入，会天然让做空卖得更低、做多买得更高；风险和目标再按相同 ATR 距离重锚后，止损更容易先到、目标更难先到。
4. 因此问题不是 EMA 趋势年龄漏判，也不是中轨退出尚未叠加，而是本版本的成交政策直接消耗了入场边际。
