## 因果定义

设下一根连续 15m 开盘为 `entry`，信号完成时冻结的 EMA144±0.30ATR14 结构止损为
`stop`，初始价格风险为 `risk = abs(entry - stop)`，每边成本率为
`c = 0.0008`：

`stop_cost_r = c × (entry + stop) / risk`

- `stop_cost_r <= 0.50`：允许进入后续真实 broker 回放；
- `stop_cost_r > 0.50`：以 `stop_cost_r_above_max` 阻塞，不形成订单、不消费
  `symbol × direction × setup_ts` 的首笔真实成交资格；
- entry、stop、risk、cost 或比值非法：按既有明确 blocker 拒绝，禁止向后寻找补偿开盘。

该门禁只使用信号完成后生产可见的紧邻开盘、信号 EMA144、信号 ATR14、方向和冻结成本，
不读取退出时间、退出原因、后续最高/最低价、MFE、MAE、最终 R、胜负或后续 K 线。

## 0.50R 的事前经济含义

- 当前成本模型下，若交易触发结构止损，毛损为 `-1R`；
- 把止损成交成本限制在 `0.50R` 后，单笔止损净损不会差于 `-1.50R`；
- V15 目标成交净收益固定为 `+2.00R`，在最差允许止损下，对应理论盈亏平衡目标命中率
  不高于 `1.5 / (2.0 + 1.5) = 42.857%`；
- 该阈值来自“单笔成本最多消耗初始风险预算的一半”，不是从 V15 盈亏结果搜索出的最优点。

## L2 预注册停止条件

若 L1 通过，只运行一次 `0.50R` 主候选完整生命周期回放。以下任一成立即停止：

- 成本后 EV `<= 0` 或 PF `<= 1`；
- 多头或空头任一方向成本后 EV/PF 不为正；
- 移除最佳两笔或最佳事件后不为正；
- 正收益集中在单币或单事件超过既有 35% 门禁；
- 样本、月份、币种或有效事件覆盖低于既有 L2 门禁。

即使通过 L2，也只能标记为 `L2_pass_L3_required / Research-only`；不得创建 Pine，
不得接入 Paper、ReadOnly、Live、数据库写入、调度、compose 或生产。L3 仍需 point-in-time
币种池、OOS/walk-forward、参数邻域、成本压力、统一资金曲线和项目职业级联合指标。
