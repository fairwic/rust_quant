# EMA576 EMA144 回踩策略 V16：入场止损成本 0.50R 门禁结果

## 最终结论

V16 在 L1 通过、在 L2 停止，状态固定为 `stop / Research-only`。

`stop_cost_r <= 0.50R` 成功过滤了用户指出的 XRP、1INCH、UMA 三个极窄结构风险信号，
也把平均成本从 V15 的 `0.609721R/笔` 降到 `0.317838R/笔`。但 2,258 笔完整回放的成本后
期望仍为 `-0.273112R/笔`，PF 只有 `0.697804`；多头、空头和全部 13 个月都为负。

因此，这个条件可以保留为“交易经济性诊断候选”，但当前证据不支持把它升级为可交易策略，
也不支持继续在同一 outcome 上搜索更紧的成本阈值。

## 本轮唯一变量

沿用 V15 的全部形态、生命周期和退出合同，只在下一根连续 15m 开盘、EMA144±0.30ATR14
结构止损和成本均已知后增加：

`stop_cost_r = 0.0008 × (entry + stop) / abs(entry - stop) <= 0.50`

- 通过：允许进入真实回放；
- 拒绝：记录 `stop_cost_r_above_max`，不形成成交，也不消费
  `symbol × direction × setup_ts` 的首笔真实成交资格；
- 保持不变：净 2R 目标、24 小时、入场 K 参与退出、同 K 止损优先、一个币种一个持仓、
  无保本/追踪/分批/runner/反转、8 bps/side。

## 总结分析

### 已知的已知

- 0.50R 门禁准确过滤了三个指定的极窄风险失败信号；
- 它显著降低成本、改善净 EV 与 PF，但没有形成正边际；
- 当前失败不是单边、单币、单月或单事件造成。

### 已知的未知

- 当前“回踩不有效跌破 EMA144”是否还缺少真正的顺势恢复确认；
- 确认 K 的方向实体、收盘接受强度或突破后动量，哪一个能在不看 outcome 的前提下形成可证伪定义；
- point-in-time 币种池、资金费、真实滑点和统一资金路径尚未进入 L3，但当前 L2 已失败，暂不值得投入。

### 未知的已知

- V16 毛 EV 仍为 `+0.044726R`，说明形态存在很薄的成本前边际；但平均成本
  `0.317838R` 是毛边际的约 7.1 倍；
- 门禁拒绝 41.74% 的机会，却只减少 14.82% 的实际交易，因为被拒绝机会不消费 setup，
  后续合格候选可能成为首笔。这是既定正确生命周期，不是重复开单缺陷；
- 实际命中率离按当前平均亏损计算的盈亏平衡线仍差 8.23 pct，主问题已经从“止损太窄导致
  费用爆炸”转为“合格信号的方向延续率不足”。

### 未知的未知

- 同一市场事件的跨币相关性、真实可成交容量、盘口冲击和资金费可能进一步恶化结果；
- 若未来改用更宽结构或不同退出，成本与命中率会同时改变，不能从本轮结果直接推断最优参数。

## 下一步建议

停止继续收紧 `stop_cost_r`，也不再调整止盈止损。下一轮应退回 L0/L1，只研究一个新的
“入场确认质量”变量。建议先定义：确认 K 必须顺交易方向收实体，并达到一个事前冻结的
ATR14 实体下限；先做无 outcome 覆盖与用户图例命中，不能同时改 EMA 条件、结构止损、成本上限
或净 2R 目标。若这一形态无法在 L1 保持覆盖，当前策略家族应直接停止，而不是继续调参。
