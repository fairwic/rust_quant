# TradingView 严格视觉横盘突破多单确认收盘强接受余量 V8 L1/L2 结论

## 结论

V8 停止在 L2，不晋级，不创建或修改 Pine，不接入 Paper、ReadOnly、Live 或生产。

`0.40 × 突破源 ATR` 确实删除了 97 笔实际严格视觉交易，并把该家族成本后总收益从
`-61.0147R` 改善到 `-40.6796R`。但这只是从一个负期望家族中机械减少交易数量：删除子集的
平均收益和 PF 反而略好于保留子集，V8 的家族平均每笔与 PF 均恶化；全 Candidate V20 的净
PnL 与 PF 也同时恶化。因此“确认棒离上沿越高，后续突破质量越好”的假设没有获得支持。

## L1 无 outcome 选择

acceptance_margin_atr
  = (confirmation_close - frozen_range_upper) / frozen_breakout_source_atr

事件簇，不读取入场、退出、MFE、MAE、R、PnL、PF 或胜负。

预注册要求选择拒绝比例最接近 30% 的合格阈值，因此唯一选中 `0.40 ATR`。Rust L1 实现再次

来源 ATR 与信号时间漂移为 0。

## L2 成本后结果

范围：本地可用 `43/60` 个冻结成员，`15m`，60 天指标预热，评价窗口
`2025-07-01 08:00 ～ 2026-07-19 22:15`（上海时间），每边 `5 bps` 手续费加 `3 bps`
滑点压力。该结果是当前 Top60 幸存者偏差下的部分成员诊断，不是正式全市场 OOS。

### 严格视觉家族

| 指标 | V6 | V8 0.40 ATR | 变化 | 判读 |
|---|---:|---:|---:|---|
| 实际成交 | 290 | 193 | -97 | 显著删减 |
| 成本后净 R | -61.0147R | -40.6796R | +20.3351R | 总亏损减少 |
| 平均每笔净 R | -0.210396R | -0.210775R | -0.000380R | 恶化 |
| 成本后 PF | 0.750223 | 0.747981 | -0.002242 | 恶化 |
| 胜率 | 29.31% | 30.05% | +0.74pct | 不能抵消赔率与成本 |
| 零成本净 R | -1.2195R | -0.5803R | +0.6391R | 两者仍近似无毛边际 |

97 笔被删除交易覆盖 39 币、13 个上海月份和 93 个 60 分钟事件，成本后合计
`-20.3351R`，平均 `-0.209640R`，PF `0.754590`。保留下来的 193 笔平均
`-0.210775R`、PF `0.747981`，质量反而略差。这证明总净 R 的改善完全等于被删除交易的亏损，
不是门槛筛出了更高质量的突破。

改善分布并非只靠两笔：26 个币、9 个月和 67 个事件的聚合贡献为正；移除贡献最大的两笔后
仍为 `+17.5511R`。但门槛也删除了多个相对有利子集，按币聚合的负贡献包括：
`1INCH -5.2547R`、`DOGE -4.1958R`、`EIGEN -3.6761R`、`MOVE -3.2907R`、
`BTC -2.6381R`。接受高度不是稳定的质量排序变量。

| 实际成交 | 2760 | 2674 | -86 |
| 成本后净 PnL | -3386.5703 | -4162.7402 | -776.1699 |

减少的毛损仅 `66.09`，但同时损失 `842.26` 毛利，最终总净 PnL、PF 和最大回撤均恶化。

## 预注册门禁判定

| 门禁 | 结果 | 证据 |
|---|---|---|
| 1. 家族净 R、平均 R、PF 全部优于 V6 | 失败 | 只有净 R 改善；平均 R 与 PF 恶化 |
| 2. V8 家族净 R、平均 R 为正且 PF > 1 | 失败 | `-40.6796R`、`-0.210775R`、`0.747981` |
| 3. 至少改变 20 笔、10 币、6 月、15 事件 | 通过 | 97 笔、39 币、13 月、93 事件 |
| 4. 改善跨 3 币/月/事件且去除头部两笔后仍正 | 通过 | 26 币、9 月、67 事件；余 `+17.5511R` |
| 5. 全家族净 PnL 与 PF 不得同时恶化 | 失败 | 两者分别恶化 `776.17` 与 `0.028395` |
| 6. 共同严格信号冻结合同零漂移 | 通过 | 193 个共同成交的上沿、ATR、风险、下一开盘与退出均零漂移 |
| 7. 数据、可执行文件、Pine、成本、币池可审计 | 通过 | 数据/Pine/币池一致，V6/V8 可执行文件与独立策略版本均留存 |

联合门禁失败，V8 淘汰。

## 形态解释与下一步

当前最关键的事实不是“0.40 ATR 还不够高”，而是整个严格视觉家族在零成本时接近盈亏平衡，
加入每边 8 bps 后平均每笔约 `-0.21R`。继续搜索更高的接受余量，只会在负期望样本中继续删量，
并存在用结果反选阈值的风险。

下一轮不应再扫描接受高度。更值得进入新的 L0/L1 假设是“初始止损距离相对于往返成本过小”，
即只用信号时可见的冻结止损距离构造成本占初始 R 的压力指标，先做无 outcome 分布与覆盖审计；
只有覆盖充分后，再验证它能否在不破坏突破形态的前提下改善成本后平均 R 与 PF。

## 验证

- 新增 V8 低于阈值消费来源、精确等于 0.40 通过、冻结来源 ATR 与实体中点优先级测试均通过。
- L1 runner 既有 6 个时序测试与 Top60 V8 CLI 身份测试通过；Release L1/L2 均实际完成。
- Rustfmt 与 2,000 行硬门禁通过；4 个历史研究文件仍高于 1,000 行目标，只记录告警。
- 扩大到整个 `strict_visual_breakout` 名称过滤测试时，当前 Baseline 路径的
  `old_range_cannot_reappear_from_an_overlapping_window_after_break` 既有断言仍失败；该测试不经过
  V8 枚举、接受窗口或余量分支，本轮没有修改其横盘重建逻辑。合并前应单独修复或校正该断言，
  但不能把它计作 V8 已通过。
