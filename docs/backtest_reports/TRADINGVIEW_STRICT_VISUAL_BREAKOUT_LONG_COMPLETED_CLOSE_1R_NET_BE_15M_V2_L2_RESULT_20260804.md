# TradingView 严格视觉横盘突破多单完成收盘 1R 净保本 V2 L2 结论

## 决策

- 当前等级：`L2_LOCAL_MULTI_SYMBOL_DIAGNOSTIC`。
- 状态：`stopped_at_l2_negative_exit_edge`。
- 唯一变量“完成棒最高价达到 1R”改为“完成棒收盘价达到 1R”没有通过预注册门禁。
- 每边 `8 bps` 成本下，V2 相对 V6 少 `14.1646R`，净 R、平均 R、PF 与回撤全部恶化。
- V2 相对上一版最高价 1R 也少 `2.4142R`；更严格的确认没有解决硬净保本截断趋势赢家的问题。
- 因此停止在 L2：不创建或修改 Pine，不接入 Paper/ReadOnly/Live，不覆盖 V6 或主策略。

## 冻结口径

- 基线：`volume_strict_visual_consolidation_weak_departure_one_bar_probation_body_strength_long_15m_research_v6`。

- 唯一变量：保护激活证据由已完成 K 线的 `high >= 1R` 改为 `close >= 1R`。
- 激活阈值固定 `1.0R`；净保本价覆盖双边 `8 bps` 成本并向上取 tick。
- 确认棒只更新状态，保护从下一棒生效；跳空穿越时必须按实际开盘价成交。
- 入场、初始止损、冻结目标、信号排序、币种池、窗口与其他家族全部保持不变。
- 仍是冻结交易清单上的隔离退出反事实，提前退出不释放容量、不制造后续交易。

## 为什么完成收盘确认仍然失败

V2 实际改变的 `58` 笔全部是正常净保本价止损，没有跳空退出：

- 救回 `34` 笔原止损，贡献 `+41.6654R`，平均每笔改善约 `+1.2255R`；
- 截断 `24` 笔原止盈，损失 `-55.8300R`，平均每笔损失约 `-2.3263R`；
- 合计相对 V6 为 `-14.1646R`。

问题不在触发次数，而在收益不对称：每救回一笔止损通常节省约 1R，但每误伤一笔趋势赢家会放弃
约 2R～3R。只要仍对全仓使用开仓成本保本价，少量被截断的大赢家就足以覆盖更多被救回的止损。

分布也没有显示局部稳定优势：

- `43` 个币中 `17` 个改善、`21` 个恶化、`5` 个不变；
- `13` 个上海月份中 `6` 个改善、`7` 个恶化；
- `250` 个事件簇中 `32` 个改善、`23` 个恶化、`195` 个不变，但恶化事件的损失幅度更大。

## 与最高价 1R 的精确差异

收盘确认比最高价确认少 `28` 笔激活，并少改变 `34` 笔退出：

- 保留了 `11` 笔原止盈，较 V1 收回 `+23.6761R`；
- 也放弃了 `23` 笔原止损保护，较 V1损失 `-26.9848R`；
- 另有 `10` 笔两版都退出但 V2 更晚，合计改善 `+0.8945R`；
- 最终 V2 仍比 V1 少 `2.4142R`。

因此“要求收盘确认”确实过滤了一部分上影触发误伤，但它并不能事前区分正常二次回踩与真正失败，
而且过滤掉的失败保护价值更大。

## 四层认知结论

### 已知的已知

1. 完成收盘、下一棒生效、确认棒不得自触发、tick 向上取整和跳空实际成交均已由 Rust 测试固定。
2. V2 在完全相同的 290 笔交易身份上比 V6 少 `14.1646R`，不是入场或样本漂移。
3. 继续把固定 R 激活条件调得更严格，只是在“保留赢家”和“漏救止损”之间移动，尚未解决保护价与正常回踩空间冲突。

### 已知的未知

- 使用横盘上沿或回踩结构作为失效边界，能否比开仓成本保本价更好地区分正常回踩与失败突破。
- 若不要求全仓立即保本，部分减仓或分级保护能否保留趋势尾部；这会改变仓位与退出合同，必须另立研究身份。

### 未知的已知

- 当前入场逻辑允许突破后的二次测试，但成本保本止损位于开仓价上方；两条规则对“可接受回踩”的定义互相冲突。
- V2 提高了确认质量，却没有改变保护位置，所以核心冲突仍然存在。

### 未知的未知

- 缺失的 17 个成员、真实改单延迟与盘口冲击仍可能影响结果；这些只能增加不确定性，不能把当前负边际解释为可上线。
- 本轮是查看 V1 后形成的自适应样本内研究；即使结果为正，也仍需新窗口 OOS，本次负结果更不能继续晋级。

## 下一步

- 不再继续搜索 `0.5R/1R/1.5R` 或更多收盘确认根数，这会变成同一窗口内的阈值追逐。
- 下一轮应退回 L0，单独定义“结构失效保护”变量：先确认冻结横盘上沿与允许回踩深度在信号时可见，
  再研究 1R 后的保护位置是否应落在结构失效边界，而不是开仓成本保本价。
- 该方向的目标是给正常二次回踩留空间，同时缩小真正失败突破的损失；它不应与分批止盈、目标调整或
  新入场过滤同时研究。
