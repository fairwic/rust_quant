# TradingView 严格视觉横盘突破外部结构上沿门禁 V9 L1/L2 结论

## 结论

V9 停止在 L2，不晋级，不创建或修改 TradingView Pine，不接入 Paper、ReadOnly、Live 或生产主策略。

这次验证支持了“绘图上沿与交易突破上沿应分开”的业务语义，但否定了当前这条具体实现：

```text
N = min(横盘长度, 32)
external_high = 横盘开始前 N 根的最高价
若该高点尚未被收盘解决，则突破棒必须收盘越过 external_high + 1 tick
```

V9 能准确拒绝目标 BTC 样本，也保持了无未来数据和 V8 严格子集合同；但它过滤了 V8 的
`138/277 = 49.82%` 候选，明显比预注册预计的 5%～40% 更激进。进入成本后回放后，剩余
交易的平均净 R、Profit Factor 和胜率全部恶化，说明“前置原始最高价”不是稳定的突破质量排序变量。

## 四层认知框架

### 已知的已知

- `visual_upper` 继续是父横盘内部 P90，仅负责绘图和回踩接受；V9 没有改变它。
- `trade_breakout_upper` 只负责判断突破来源，取尚未解决的外部高点与 `visual_upper` 的较大值。
- 外部证据只读取横盘开始前的完成 K 线；解除状态只读取横盘开始至突破棒之前的完成收盘。
- 目标 `BTC-USDT-SWAP 2026-07-15 06:15` 被正确拒绝。
- V9 在 L1 与 L2 都是 V8 的严格子集，没有新增或向后补造信号。
- V9 家族成本后仍为负期望，且平均净 R 与 PF 比 V8 更差。

### 已知的未知

- 本地只有冻结 Top60 中 `43/60` 个成员满足完整预热和评价窗口，不能外推为正式全市场结论。
- 这轮只验证了 `min(L, 32)` 的原始最高价，没有验证“已确认摆动高点”“最近一次有效结构峰值”或
  “只在横盘形成前仍活跃的阻力”等其他外部结构定义。
- 当前结果不能回答横盘持久性止盈和 `0.8R` 净保本是否有效；两者本轮保持 V8 不变。

### 未知的已知

- 过滤并不等于提质。V9 删除的 77 笔实际成交自身成本后 PF 为 `0.797701`，高于 V8 全体的
  `0.747981`，也高于 V9 保留集合的 `0.716759`；被删集合相对“没那么差”。
- 固定前置窗口对不同横盘长度含义不同。V9 删除的 96 根横盘交易合计为 `+4.9868R`、PF
  `3.0622`，说明长横盘之前的旧高点经常已经失去当前交易意义。
- 目标 BTC 被正确删除且该币被删 4 笔共 `-5.5052R`，证明规则能解释个别图形；但单个图形解释
  成功不等于跨币种预测有效。

### 未知的未知

- 外部高点是否需要结合摆动确认、触碰次数、距离衰减、成交量接受或更高周期结构，当前没有因果证据。
- 事件相关性、币种波动层级和 tick 粒度可能改变“越过 1 tick”的实际强度，尚未做正式 L3 压力测试。
- 缺失 17 个成员及历史币池幸存者偏差可能改变绝对结果，但不足以推翻本轮已触发的 L2 停止条件。

## 唯一变量与因果时序

V9 相对 V8 只新增外部结构上沿门禁。横盘识别、P90/P10、强突破实体、量能、接受窗口、
`0.40 ATR` 接受余量、下一根开盘成交、止损、止盈、冲突和退出政策全部保持不变。

```text
L = frozen_range_length
N = min(L, 32)
external_high = max(high[range_start - N .. range_start - 1])

resolved_before_breakout =
    any(close[range_start .. breakout - 1] >= external_high + tick)

trade_breakout_upper =
    resolved_before_breakout ? visual_upper : max(visual_upper, external_high)

qualified = breakout_close >= trade_breakout_upper + tick
```

证据在突破棒完成时冻结。确认棒及其后的价格不参与重算；被拒绝来源仍在 V8 原决策时点被消费，
不会释放状态后补造一个更晚的信号。

## 最关键判断、风险与下一步

当前最关键的判断是：`visual_upper` 与 `trade_breakout_upper` 分离仍然合理，但“取横盘前
`min(L,32)` 根的原始最高价”太宽泛，尤其会把长横盘之前已经失效的旧高点继续当作当前阻力。

最大风险是看到目标 BTC 被成功修正后，就继续围绕 16、24、32 根或摆动参数按结果调窗；这会
把单图解释变成样本内过拟合。当前 V9 参数不得继续微调，也不得叠加后续止盈或保本变量。

下一轮应回到通过身份审计的 V8 基线，按既定顺序只研究“横盘持久性决定止盈”这一项；不得把
失败的 V9 当作新基线。外部交易边界若要重启，应另开 L0/L1 假设，把“外部结构”改成可证伪的
已确认摆动结构，而不是继续扫描 raw-high 回看长度。
