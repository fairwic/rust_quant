# 严格视觉横盘突破棒极值止损 V1 回测结论

## 结论

本轮已经把初始止损改为突破棒整根极值外一 tick，并完成多空镜像与 43/60 冻结币池回放。结构止损让零成本结果略有改善，但在每边 `5 bps` 手续费加 `3 bps` 滑点等价成本后明显变差，因此按预注册规则停止在 L2：不创建 Pine，不进入 Paper、ReadOnly 或 Live。

## 唯一变量

- 多头：突破棒最低价减一 tick，再向下按 tick 对齐。
- 空头：突破棒最高价加一 tick，再向上按 tick 对齐。
- 止损在突破棒完成时冻结；第 1～5 根接受确认期间不重算。
- 下一根实际开盘若已经越过止损，候选直接阻塞，不把止损反转到持仓另一侧。
- 横盘、突破、接受确认、目标、币池、窗口和成本均保持 V10 不变。

## 为什么结构看起来合理，成本后反而更差

V10 的严格视觉止损基本固定在成交价外约 `1.5 ATR`；V11 的止损由突破棒极值决定，并在实际下一开盘成交后形成真实风险距离。V11 的真实风险相对信号 ATR 分布为：

| 风险距离 / 信号 ATR | 数值 |
|---|---:|
| P10 | 0.624 ATR |
| P25 | 0.860 ATR |
| 中位数 | 1.219 ATR |
| P75 | 1.659 ATR |
| P90 | 2.181 ATR |
| 均值 | 1.329 ATR |
| `< 0.5 ATR` | 722 笔 |
| `< 1.0 ATR` | 5,254 笔 |
| `> 1.5 ATR` | 5,005 笔 |

止损越靠近实际入场价，固定的双边交易成本换算成初始风险 R 后越大：

| 实际风险距离 | 交易 | 零成本 EV | 成本后 EV | 平均成本侵蚀 |
|---|---:|---:|---:|---:|
| `< 0.5 ATR` | 722 | +0.2271R | -0.6898R | 0.9169R |
| `0.5～1.0 ATR` | 4,532 | -0.0173R | -0.4184R | 0.4011R |
| `1.0～1.5 ATR` | 5,001 | -0.0161R | -0.2730R | 0.2570R |
| `>= 1.5 ATR` | 5,005 | +0.0082R | -0.1590R | 0.1672R |

极端样本是 `ALGO-USDT-SWAP` 多头：实际入场 `0.1026`、冻结止损 `0.10259`，风险只有 `0.00858 ATR`。它的零成本结果为 `-1R`，加入成本后为 `-17.4152R`，其中交易成本侵蚀 `16.4152R`。这不是未来函数，而是“结构止损仍在正确方向，但确认后的实际开盘离止损只剩一个 tick”造成的。

另有 16 个候选因下一开盘已经越过冻结止损而被正确阻塞，其中多头 10 个、空头 6 个。

## R 的口径

本报告中的 `R` 仍是实际入场价到初始止损的风险距离；ATR 只作为 `风险距离 / 信号 ATR` 的诊断单位。结构止损改变后，`1R` 不再恒等于 `1 ATR`。这是为了保持仓位风险和止损亏损的可审计定义，也符合当前回测引擎的统一 R 口径。

如果下一轮要把 `1R` 明确定义成 `1 ATR`，需要单独冻结新的报告/目标计量合同，不能与本轮止损位置同时调参。尤其不能直接用 ATR-R 美化本轮结果，而仓位仍按结构止损风险下单。

## 已知边界与下一步

- 当前是 43/60 的 `partial_data_diagnostic`，不是正式 Top60、point-in-time OOS 或可上线结论。
- L2 数据指纹为 `eda87a30667f040cd74048e659def7453a5d49f6c81e062d012bebcb1c2ad5c4`，币池版本为 `top60_v36_direct_kline_20260721_frozen_20260723`，窗口为 `1751328000000..=1784470500000`，预热 60 天。
- 当前最关键判断：突破棒极值是有意义的结构信息，但不能单独作为最终风险距离；实际开盘与结构止损过近时，固定成本会吞掉多个 R。
- 最大不确定性：增加最小风险距离后，零成本结构优势能否保留；本轮各风险分桶成本后仍为负，不能预设一个 ATR 下限就一定能修复策略。
- 下一步最值得研究的单变量是“保留突破棒极值结构止损，但候选在实际开盘时必须满足预注册的最小成本覆盖/最小 ATR 风险距离”；它必须另开版本走 L1，不能回写 V11 结果。
