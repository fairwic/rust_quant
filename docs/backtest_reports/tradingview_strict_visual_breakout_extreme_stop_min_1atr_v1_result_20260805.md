# 严格视觉横盘突破棒极值止损 + 最小 1ATR 风险 V12 结果

## 结论

V12 已修复 V11 中“突破棒极值离实际开仓价过近，导致 R 被压缩、手续费按 R 计被异常放大”的问题。

最终初始止损定义为：

- 多单：`min(突破棒最低价 - 1 tick, 实际开仓价 - 向外取整的 1.00 × 确认棒 ATR14)`；
- 空单：`max(突破棒最高价 + 1 tick, 实际开仓价 + 向外取整的 1.00 × 确认棒 ATR14)`；
- 确认后的下一开盘若已经越过突破棒结构止损，仍直接阻塞，1ATR 下限不能复活失效结构；
- `1R` 继续等于实际开仓价到最终初始止损的真实风险，因此结构更远时可以大于 1ATR。

修复有效：V11 的 5,254 笔 `<1ATR` 风险在 V12 中降为 0，V12 最小风险为 `1.000002ATR`；
平均成本拖累由 `0.30156R` 降至 `0.23971R`。但策略本身仍没有成本后边际：V12 成本后
`EV -0.24568R / PF 0.65780`。因此按预注册停止在 L2，保持 Research-only，不进入 L3，
不创建 Pine，也不接 Paper、ReadOnly、Live、worker、调度或生产。

## 唯一变量与未改变合同

唯一变量是给 V11 的突破棒结构止损增加 `1ATR` 最小风险下限。以下保持不变：

- 严格视觉横盘及区间上下沿；
- 突破棒实体占整根至少 50%，方向实体涨跌幅至少 0.15%；
- 突破后第 1～5 根内首次合法回踩接受；
- 多空镜像、下一根开盘成交、一个冻结横盘高度目标；
- 币种池、窗口、冲突与资金路径；
- 单边 5bps 手续费 + 3bps 滑点的冻结成本。

独立策略身份为
`strict_visual_consolidation_symmetric_breakout_candle_extreme_stop_min_1atr_15m_research_v1`，
没有覆盖 V10 或 V11。

## L1：无标签身份门禁

- V11 与 V12 均产生 15,998 个信号候选：多头 7,857、空头 8,141；
- 覆盖 43 个可用币种、13 个上海月份、4,126 个方向 + 60 分钟事件簇；
- 未解决弱离区、旧拒绝路径和非法风险合同均为 0；
- 删除 V12 新增的 `breakout_candle_extreme_stop_min_atr_multiple` 后，V11/V12 候选账本 SHA-256
  同为 `2f28aee3817660a051bfe6c9d678a057d3472a48ed2e4cf347f125e370834db4`。

这证明 V12 没有利用 outcome 改选信号，只改变实际成交时的最终风险宽度。

## 四层认知框架

### 已知的已知

- V12 的全部已平仓交易实际风险均不低于 1ATR，止损尺度修复已成立；
- L1 候选身份未改变，结果差异来自风险、退出时点及共享资金路径；
- 43/60 partial 样本中成本前与成本后均未达到晋级门槛。

### 已知的未知

- 缺失的 17 个币种未补造，本轮不能表述为正式 Top60 全市场结论；
- 未进入 L3，因此没有 OOS、walk-forward、费用压力和统一生产容量晋级证据。

### 未知的已知

- 13 笔实际下一开盘已经到达或越过冻结目标，目标收益距离 `<=0R`；这是账本中已存在但不属于
  本轮唯一变量的入场几何问题；
- 另有 1,350 笔目标收益处于 `(0, 0.5R)`，主要因为风险下限变宽而目标仍固定为一个横盘高度；
- 这些事实说明“修正初始 R”后，目标与下一开盘之间还需要独立合同审计，不能在本轮同时改目标。

### 未知的未知

- 尚不能确认一个独立的、信号时可见的入场质量变量能否把零成本弱边际提升到足以覆盖成本；
- 高相关币种同一事件中的结果依赖仍可能高估独立样本量，只有 L3 才能正式评估。

- 最大不确定性：43/60 partial 与尚未审计的下一开盘目标几何；
- 还需补充的信息：若未来进入新研究，需要先补全币种数据，并为“下一开盘已经达到目标”建立独立
  因果定义；当前 L2 失败不需要用户再补信息；
- 下一步最值得采取的行动：停止继续搜索 0.8/1.2/1.5ATR；若继续研究，另起 L0/L1，只研究一个
  信号时可见的入场质量或目标可交易性变量。
