# 严格视觉横盘突破：1.0H 成本后保本退出 V4 结果

## 结论

本轮停止在 L2，否决把“价格达到冻结横盘高度 `1.0H` 后，下一根开始把止损移到成本后保本价”无条件接入主策略。

该规则能减少一部分假突破的完整止损，但会更大幅度截断成功突破的趋势延续：在 8bps 单边成本下，9 笔原本止损的交易得到改善，合计增加 `10.1255R`；同时 11 笔原本止盈的交易被提前保本退出，合计减少 `23.8817R`，最终净损失 `13.7561R`。

因此，横盘高度 `H` 可以描述形态尺度，但不能单独代表趋势已经成熟到适合保本。成功突破在达到 `1H` 后回踩开仓附近，再继续走向原目标，是本样本中的真实常见路径。

## 冻结规则

- 研究身份：`strict_visual_breakout_range_height_1_0_net_be_15m_research_v4`。
- 基线：`volume_strict_visual_consolidation_stronger_acceptance_margin_0_40_atr_long_15m_research_v8`。
- 唯一变量：`H = visual_upper - visual_lower`；多单激活价为 `max(entry + H, 8bps 单边成本后的净保本价)`，空单镜像。

- 跳空越过保护价时按实际开盘成交；原始止盈不变，保护只能收紧止损。
- 仅作用于纯 `strict_visual_consolidation_break_long + Fixed` 交易；混合家族和其他退出政策保持原样。
