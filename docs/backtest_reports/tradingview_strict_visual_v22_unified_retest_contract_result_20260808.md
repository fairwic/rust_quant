# 严格视觉横盘突破 V22 统一合同结果

## 结论

V22 已把多空入场、突破棒、成本和弱离区生命周期统一到同一个可审计合同，并同步到 Rust 与独立
TradingView Research 脚本。因果身份门禁通过，但多空在统一成本后都为负，因此结论固定为
`stopped_at_l2_negative_cost_adjusted_edge / Research-only`，不进入 L3，不接 Paper、Live、worker、
调度或生产。

## 最终合同

1. 多头和空头都不得在突破棒直接入场。强突破后，只在第 1～5 根完成 K 线中取首次合法回踩，
   再由下一根开盘成交。
2. 强突破棒要求实体 / 整根振幅不小于 50%，方向实体 / 开盘价不小于 0.15%。原 TradingView
   的整根振幅至少 1.5% 门禁已删除。
3. 空头继续保留 V20 三道信号时可见门禁：越界 / 来源 ATR 不大于 0.39、突破收盘相对突破棒
   EMA144 不低于 `-4.65ATR`、突破实体 / 来源 ATR 不大于 0.915。
4. 初始止损冻结在突破棒极值外一 tick，并保证实际入场到止损至少 1ATR；目标为一个冻结横盘高度。
5. 成本为入场 maker 2bps + 1bps 滑点，出场 taker 5bps + 1bps 滑点，分别按入场、出场名义价值计提。

## “弱离场”的准确含义

界面里的“弱离场”不是持仓退出，而是“价格弱势离开横盘区”。准确生命周期是：

1. 已存在完成确认的冻结横盘区。
2. 当前完成棒收盘越过 P90 上沿或 P10 下沿，但没有同时满足 50% 实体占比与 0.15% 方向位移，
   因而不能成为强突破锚点；成交量不参与这个判断。
3. 旧横盘进入一根棒观察期，只检查紧邻下一根完成棒。
4. 下一根收盘回到闭区间 `[lower, upper]` 内，恢复旧横盘；该棒只解决 pending，不能同棒升级旧边界
   或补算旧横盘突破。
5. 下一根仍在区间外，消费旧横盘，旧横盘结束时点固定在首根弱离区棒；确认棒可成为以后新横盘的
   第一根，但不能反过来改变旧横盘结论。

L1 实际观察到上沿弱离区 5,354 次，其中回区 2,065、消费 3,289；下沿 6,287 次，其中回区
2,375、消费 3,912。未解决状态均为 0，最大决策年龄严格为 1 根完成棒。
