# 严格视觉 V23 确认保留率 75% 成本回放预注册

## 假设卡片

- 研究等级：L2 多币种成本诊断。
- 基线：`v23_unified_retest_no_short_gates_maker2_taker5_slippage1`。
- 唯一变量：在 V23 原首次合法回踩确认时点，要求确认保留率至少为 `0.75`。
- 候选身份：
  `strict_visual_consolidation_symmetric_retest_50pct_15bps_no_short_gates_acceptance_retention_75pct_maker2_taker5_slippage1_15m_research_v1`。
- 因果定义：只使用突破棒完成时冻结的视觉边界、突破收盘和首次合法确认棒完成收盘；不读取确认后的 K 线决定资格。
- 预计影响：上一批 outcome-blind L1 已冻结保留 12,014/17,880 个原始确认候选，预计完整回放保留
  V23 严格视觉成交的 60%～75%，且不少于 1,000 笔、30 币、5 个月、100 个方向加 60 分钟事件簇，
  多头和空头各不少于 200 笔。
- 停止条件：覆盖不足；候选不是 V23 原确认身份的严格子集；成本后 EV 或 PF 没有同时改善；候选自身
  成本后 EV 不大于 0 或 PF 不大于 1；收益依赖头部交易、币种或单一事件簇。
- 保持不变：冻结币池、15m 周期、数据窗口、横盘与突破棒合同、一棒弱离区、第 1～5 根首次合法回踩、
  下一根开盘成交、冲突与反手、结构止损、最少 1ATR 风险、量度目标和全部退出路径。
- 禁止项：不测试 0.70、0.80 或任何其他保留率；不调整止损、止盈、确认窗口、手续费或滑点；不创建 Pine，
  不接 Paper、ReadOnly、Live 或生产。

## 唯一变量的镜像公式

```text
多头 retention = (confirmation_close - visual_upper)
                 / (breakout_close - visual_upper)

空头 retention = (visual_lower - confirmation_close)
                 / (visual_lower - breakout_close)
```

V23 仍先在原确认棒按 `retention >= 0.25` 判断“首次合法回踩”。候选只在同一根确认棒继续检查
`retention >= 0.75`：不通过即消费该突破来源，不能继续等待后来 K 线补成候选。

## 四层认知框架

### 已知的已知

- 上一批 L1/L2 结构研究已在当前冻结 Top60 数据上得到 17,880 个原 V23 确认候选。
- `retention >= 0.75` 是预注册顺序中首个通过结构质量门禁的阈值，验证窗保留 4,400/6,602 个候选。
- V23 现有成本合同为入场 maker 2bps、入场滑点 1bps、退出 taker 5bps、退出滑点 1bps。

### 已知的未知

- 结构质量率提高是否足以覆盖完整交易成本，以及候选自身净 EV、PF 和 R 权益回撤是否转正。
- 删除低保留确认后释放的单币仓位，是否会改变后来实际成交和冲突路径。
- 收益是否集中在少数币种、月份、交易或同时发生的市场事件。

### 未知的已知

- 高保留确认离冻结量度目标更近，结构标签提升含有目标距离优势；完整交易回放可能因剩余奖励缩短而变差。
- 该币池是当前冻结 Top60，不是历史 point-in-time 成员；即使 L2 正向也不能直接称为全市场 OOS 证据。
- 多币回放是独立单币固定风险诊断，不是容量和相关性受限的生产组合。

### 未知的未知

- 真实 maker 成交率、点差、冲击和资金费可能进一步侵蚀高保留确认的可实现收益。
- 同一市场事件内的多币并发风险可能高于逐笔统计显示的风险。

## 数据、成本与权益口径

- 冻结币池：`top60_v36_direct_kline_20260721_frozen_20260723`；运行时必须复核 manifest SHA、
  数据指纹、实际成员、统一评价末端与预热完整性。
- 只读数据源：本地 `quant_core` 已存在的 OKX 15m K 线；不补数、不写库。
- 成本：入场 `2bps maker + 1bps slippage`，退出 `5bps taker + 1bps slippage`，分别按各自成交名义价值计提。
- 跨币 PF、EV、净收益和集中度统一使用成本后 `net_r`；不能把不同价格尺度的固定一单位 PnL 相加后解释为策略优势。
- 回撤：按实际退出时间稳定排序累计成本后 `net_r`，报告 chronological max drawdown R。
- 归一化参考：初始权益 100R、每笔固定初始风险 1R（即初始权益 1%）、不复利；同时报告最大并发持仓和
  对应并发风险。该口径用于 L2 可比诊断，不冒充容量受限组合回测。

## L2 联合门禁

候选只有同时满足以下条件才允许进入 L3 准备；否则在 L2 停止：

1. 资格覆盖达到假设卡片下限，且候选原始确认身份是 V23 的严格子集，新增身份为 0；
2. 成本后交易级平均净 R 和 R Profit Factor 同时高于 V23；
3. 候选自身成本后平均净 R `> 0`、R Profit Factor `> 1`，发现窗与验证窗分别也都满足；
4. 多头和空头各自成本后平均净 R `> 0`、R Profit Factor `> 1`；
5. chronological max drawdown R 不高于 V23；
6. 移除成本后净 R 最高的 5 笔交易后，剩余净 R 仍 `> 0` 且 PF `> 1`；
7. 移除净 R 最高的单一币种后，剩余净 R 仍 `> 0`；
8. 最大正收益方向加 60 分钟事件簇占全部正收益事件簇净 R 不超过 10%。

即使全部通过，本批次仍只允许标记为 L3 候选：阈值已经在同一历史数据的结构标签上被选择，后续还必须
使用 point-in-time 币池、forward OOS/walk-forward、成本压力、统一容量资金曲线和 Pine/Rust parity。
