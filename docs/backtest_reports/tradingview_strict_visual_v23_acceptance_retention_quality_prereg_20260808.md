# 严格视觉横盘 V23 突破确认保留率质量研究预注册

## 研究等级与边界

- 当前等级：L1 outcome-blind 覆盖审计；覆盖通过后才进入 L2 固定标签诊断。
- 研究对象：V23 `v23_unified_retest_no_short_gates_maker2_taker5_slippage1` 已确认的多空镜像回踩候选。
- 运行边界：Research-only；不修改 V23、V26、TradingView、Paper、ReadOnly、Live 或生产入口。
- 本轮只研究一个变量，不搜索其他突破棒、横盘、EMA、成交量、止损或止盈门槛。

## 四层认知框架

### 已知的已知

- V23 在本地完整 43/60 冻结成员上有足够多且分散的候选，但成本后整体为负。
- V26 放宽突破锚点后，零成本质量只有很小改善，成本后的平均 R 与 PF 反而下降。
- V23 合法回踩确认至少保留突破棒越界幅度的 25%；确认发生在突破后第 1～5 根完成棒。

### 已知的未知

- 25% 的最低保留是否过松，尚未用独立结构标签和时间切分验证。
- 更高保留率是否同时改善多头、空头和独立市场事件，而非只集中于少量币种或月份。

### 未知的已知

- “回踩确认”不等于“突破仍然健康”。确认收盘只略高于最低门槛时，价格可能已回吐大部分突破位移。
- 结构质量与可交易盈利不是同一件事；即使质量率提高，也必须另做冻结成本合同的完整回放才能晋级。

### 未知的未知

- 同一小时内多个币种的同向信号可能来自同一个市场事件，逐笔统计会高估独立样本数。
- 当前冻结币池缺少 17 个完整成员，并且不是 point-in-time 历史币池；结果只能作为局部研究证据。

## 唯一变量

定义确认保留率：

```text
多头 = (确认收盘 - 冻结 visual_upper) / (突破收盘 - 冻结 visual_upper)
空头 = (冻结 visual_lower - 确认收盘) / (冻结 visual_lower - 突破收盘)
```

分母、边界和方向都在突破棒完成时冻结；分子只使用首次合法确认棒的完成收盘。候选阈值在查看未来结果前固定为：

- 基线：`retention >= 0.25`；
- 候选 A：`retention >= 0.50`；
- 候选 B：`retention >= 0.75`；
- 候选 C：`retention >= 1.00`。

候选只在 V23 原确认时点做严格子集过滤；失败样本不会释放 pending、延后确认或补造新信号。

## 独立结构质量标签

标签不读取 V23 当前止损、保本或资金退出结果：

- 起点：首次合法确认棒完成后；
- 固定观察窗：后续 16 根完成 15m K 线；
- 质量突破：价格先触及冻结边界外一个完整横盘高度的量度目标；
- 结构失败：在到达目标前，任一完成收盘重新进入原区间；
- 同一根同时触及目标且收盘回区：因缺少 tick 路径，保守记为结构失败并单独计数；
- 16 根内两者都未发生：记为未决，不强行归入成功或失败；
- 未来不足 16 根：记为 forward-incomplete，不进入质量率分母。

这是研究标签，不是新的交易退出规则。

## 时间切分与事件口径

- 发现窗：`2025-07-01 08:00:00` 至 `2026-03-01 00:00:00` 上海时间之前；
- 验证窗：`2026-03-01 00:00:00` 至冻结数据结束；
- 事件簇：同方向、同一个 60 分钟桶内的全部币种候选视为同一市场事件；
- 阈值、方向和胜负定义在两个窗口中完全相同，不根据发现窗结果移动。

## L1 outcome-blind 覆盖门禁

每个候选阈值必须在验证窗同时满足：

- 至少 500 个确认候选；
- 至少 30 个币种；
- 至少 5 个上海自然月；
- 至少 100 个方向加 60 分钟事件簇；
- 多头、空头各至少 200 个候选。

覆盖不足的阈值在读取结构结果前即停止，不以小样本高命中率继续研究。

## L2 联合成功条件

按从宽到严的顺序，选择第一个同时满足以下条件的阈值；不按最终收益挑最优阈值：

1. 发现窗已解决样本的质量率相对 V23 基线至少提高 3 个百分点；
2. 验证窗已解决样本的质量率相对基线至少提高 5 个百分点；
3. 验证窗多头、空头质量率分别至少提高 2 个百分点；
4. 验证窗按事件簇配对后的平均质量率提升大于 0，且近似 95% 区间下界大于 0；
5. 满足全部 L1 覆盖门禁。

若没有阈值通过，结论必须是“确认保留率不能稳定识别高质量突破”，不得继续在 0.25～1.00 之间追小数阈值。若有阈值通过，也只能进入下一轮冻结成本回放，不能直接修改策略。

## 保持不变

- 冻结币池、15m 周期、预热、数据窗口与 V23 状态机；
- 横盘识别、突破棒 50% 实体与 0.15% 方向位移门；
- 一棒弱离区生命周期、1～5 根首次合法回踩、多空镜像；
- 结构止损、至少 1 ATR 风险、量度目标和执行成本合同；
- 不创建 Pine，不补数据，不读取信号后信息决定候选资格。
