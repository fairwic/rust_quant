# 严格视觉横盘 V23 突破确认保留率质量研究结论

## 结论

本轮找到了一个在信号时点可见、发现窗与验证窗方向一致的**结构质量排序变量**：

```text
确认保留率 = 确认收盘仍留在冻结边界外的距离 / 突破收盘原始越界距离
```

按预注册从宽到严判断，`retention >= 0.75` 是第一个通过全部结构质量门禁的阈值：

- 发现窗已解决质量率：`34.91% -> 39.63%`，提升 `+4.72pct`；
- 验证窗已解决质量率：`34.11% -> 39.18%`，提升 `+5.07pct`；
- 验证窗多头提升 `+5.67pct`，空头提升 `+4.50pct`；
- 验证窗事件簇配对平均提升 `+2.24pct`，近似 95% 区间为 `+1.63～+2.85pct`；
- 验证窗保留 `4,400 / 6,602 = 66.65%` 候选，覆盖 55 币、5 个月、2,415 个方向加 60 分钟事件簇。

因此，**回踩确认不能只要求“仍在边界外”；至少保留原突破越界幅度的 75%，能够稳定排序出更高的后续结构延续率。**

但这还不是可直接交易或可保证成功的“真突破门禁”：`retention >= 0.75` 的验证窗已解决质量率仍只有 `39.18%`，约六成已解决样本仍会先收盘回区。它是排序器，不是确定性标签；本轮没有做成本后资金回放，因此不修改 V23、TradingView 或任何运行态。

## 四层认知框架

### 已知的已知

- L1 在完全不读取未来标签的前提下得到 17,880 个 V23 原确认候选。
- 当前本地数据已覆盖冻结 Top60 的 60/60 成员；验证窗实际有候选的币种为 55 个。
- 0.50、0.75、1.00 三档都通过 L1 样本与分散度门禁，不存在小样本高命中率问题。
- 0.75 档在发现窗、验证窗、多头、空头、事件簇和全部 5 个验证月份上均提高结构质量率。
- 17,880 条 L2 账本中无非法冻结证据；只有数据末端 13 条 forward-incomplete，未进入质量率分母。

### 已知的未知

- 本轮没有把 0.75 子集送入 V23 的 maker 2 bps、taker 5 bps、双边各 1 bps 滑点资金回放；尚不知道结构提质能否覆盖真实成本和入场追价。
- 未做统一资金曲线、容量、相关簇敞口、OOS/walk-forward 或历史 point-in-time 币池，因此不满足 L3 晋级条件。
- 质量标签固定为确认后 16 根内“原边界外一个横盘高度目标先于完成收盘回区”；其他持有窗口不在本轮结论范围内。

### 未知的已知

- 更高确认保留率意味着确认价离原量度目标更近，结构质量率提升含有一部分目标距离优势；不能把它直接等价成更好的交易盈亏比。
- 非累积区间显示真正明显的断点更接近 `retention >= 1.00`：验证窗 `0.75～1.00` 档质量率只有 `28.87%`，而 `>=1.00` 为 `40.66%`。0.75 累积集合能够过门，主要由其中大量 `>=1.00` 样本贡献。
- `retention >= 1.00` 的业务含义更直观：盘中完成边界回踩，但确认收盘至少重新站回突破棒收盘位置。它是本轮预注册的更强档，也通过全部门禁；但预注册选择规则要求保留第一个通过档，因此正式候选仍冻结为 0.75，不能看完结果后改选 1.00。

### 未知的未知

- 更低流动性币种的真实点差和冲击可能使高保留确认后的追价成本更高。
- 市场状态、板块共振和币种上市阶段可能影响保留率的有效性；当前只有方向加小时事件簇的初步去相关，没有完整 regime 分层。
- 若后续成本回放失败，可能说明高保留率只提高“先碰近端目标”的概率，却没有提高可实现净 R。

## 冻结质量定义

本轮没有用当前交易止损、保本或手续费结果定义“好突破”。独立结构标签为：

```text
从首次合法回踩确认完成后开始观察 16 根：
1. 先触及冻结边界外一个完整横盘高度 -> quality
2. 先有完成收盘重新进入原横盘 -> failed_close_back
3. 同棒既触目标又收盘回区 -> 保守记 failed_close_back
4. 两者都未发生 -> unresolved
5. 未来不足 16 根 -> forward_incomplete，不进分母
```

候选资格只读取确认完成时已经存在的数据，未来标签只用于 L2 评价。

## 非累积区间诊断

这项诊断只解释变量形状，不用于事后移动正式阈值：

| 确认保留率区间 | 发现窗已解决质量率 | 验证窗已解决质量率 |
|---|---:|---:|
| 0.25～0.50 | 23.54% | 22.96% |
| 0.50～0.75 | 27.21% | 25.35% |
| 0.75～1.00 | 29.73% | 28.87% |
| >= 1.00 | 41.04% | 40.66% |

排序是稳定且近似单调的，但主要跃迁发生在“确认收盘完全收复原突破收盘”这一点。后续人工核图时，应重点对照 `>=1.00` 的强接受形态与 `0.75～1.00` 的中间形态，而不是把所有 `>=0.75` 画成同一种强度。

5/5 验证月份方向一致。55 个有候选币种中，51 个至少保留 30 条；其中 BAT、RENDER、IOST 的币种内提升略为负，分别约 `-0.72 / -0.29 / -0.18pct`，说明该变量不是对每个币种逐一保证有效，但总体结论不依赖单一币种。

## 对“有质量突破”的当前可执行理解

在不使用未来数据的前提下，当前最合理的候选描述是：

1. 先满足 V23 已冻结的有效横盘、强突破棒和第 1～5 根首次合法回踩；
2. 回踩确认收盘至少保留原始突破越界幅度的 75%；
3. `>=1.00` 是更强的视觉接受等级：盘中回踩后，收盘至少回到原突破收盘；
4. 不把该等级直接叫成功交易，必须等待同一信号身份下的成本后回放。

## 决策与下一步

- 决策：确认保留率是当前第一个通过时间切分、多空镜像、逐月和事件簇审计的结构质量变量。
- 冻结候选：按预注册选择 `retention >= 0.75`，不在本批次追 0.70、0.80、0.90 等小数阈值。
- 当前状态：Research-only，不修改 V23、V26、Pine 或生产。
- 下一步：以 V23 为同身份基线，只增加 `retention >= 0.75` 原确认时点严格子集，使用 maker 2 bps、taker 5 bps、双边各 1 bps 滑点做完整成本回放。只有净 EV、PF、回撤与收益集中度同时改善，才考虑独立新版本。
