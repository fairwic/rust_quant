# 严格视觉横盘突破 V23 移除空头附加门禁预注册

## 研究边界

- 当前等级：L1 单变量因果与无标签覆盖审计；L1 通过后只执行一次 L2 本地多币种诊断。
- 唯一变量：把 V22 的空头三道附加门禁作为一个用户指定的门禁组合整体关闭。
- V23 保持 Research-only，不覆盖 V22，不接入 Paper、Live 或生产订阅，也不执行真实交易。
- 本轮不修改强突破方向位移。50% 实体占比与 0.15% 方向位移继续冻结；0.05% 与 0.5% 的单位歧义留给下一轮独立研究。

## 因果定义

1. 多空继续只在强突破后第 1～5 根完成 K 线中寻找首次合法回踩；突破棒不得直接入场。
2. 强突破继续要求实体占整根振幅至少 50%、方向实体相对开盘价至少 0.15%，且不设置 1.5% 整根振幅门。
3. 空头合法回踩确认后，不再检查以下三项：
   - 突破收盘越界幅度 / 来源 ATR 不超过 0.39；
   - `(突破收盘 - EMA144) / 来源 ATR >= -4.65`；
   - 突破实体 / 来源 ATR 不超过 0.915。
4. 横盘识别、弱离区一棒观察、冻结边界、回踩接受、突破棒极值止损、实际入场最少 1 ATR 风险距离与一倍冻结区间高度目标全部沿用 V22。
5. 成本继续固定为入场 maker 2 bps、出场 taker 5 bps，入场和出场各计 1 bps 滑点等价成本。

## 保持不变

- 币种池、样本窗口、数据指纹、缺失成员处理、冲突处理和独立单币资金口径沿用冻结 Top60 runner。
- 不使用 MFE、MAE、退出时间、最终 R 或胜负来筛选候选。
- 不搜索其他阈值、确认窗口、止损、目标、费用或滑点。

## 预期影响与停止条件

- V22 无标签账本中空头合法回踩确认共有 8,141 个，三门禁拒绝 6,012 个、接受 2,129 个；V23 预期空头候选恢复到全部 8,141 个，影响面约为 V22 空头候选的 282.4%。
- L1 必须满足：多空直接入场均为 0；空头门禁拒绝为 0；空头候选等于合法回踩确认数；候选不少于 30、覆盖不少于 8 个币种、3 个月和 10 个方向加 60 分钟事件簇；弱离区恰好在下一根完成棒解决；无非法结构止损或最少 1 ATR 合同错误。
- 任一身份门禁失败即停止，不执行 L2。
- L2 若空头成本后每笔期望不为正或 Profit Factor 不大于 1，结论固定为“不晋级”；组合结果只作辅助，不得用多头已知负边际掩盖空头结论。
- L2 是 43/60 本地可用成员的局部诊断；缺失成员不补造数据，不得表述为正式全市场结论。
