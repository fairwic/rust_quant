# 严格视觉横盘 V24 最小有效离区深度 L1 预注册

## 假设卡片

- 研究等级：L1 无标签结构覆盖；本轮禁止读取退出时间、MFE、MAE、最终 R 或胜负选阈值。
- 基线版本：V23 Research-only 信号合同；V23 已在 L2 为负，本轮只检验横盘生命周期定义，不改变其晋级状态。
- 唯一变量：完成棒收盘越过视觉 P90/P10 边界后，成为离区事件所需的最小越界深度 `departure_excess / source_ATR`。
- 主候选：`0.10 ATR`；邻域只检查 `0.05 ATR` 与 `0.15 ATR` 的覆盖单调性，不按盈亏择优。
- 目标样本：BTC-USDT-SWAP 15m，2026-08-03 01:15（北京时间），仅使用该完成棒及之前数据。
- 保持不变：50% 实体占比、0.15% 方向位移、P90/P10 横盘识别、强弱方向镜像、一棒弱离区确认、第 1～5 根回踩、止损、目标、费用、滑点、冲突和资金路径。

## 因果定义

```text
向上越界深度 = max(0, close - frozen_visual_upper) / frozen_source_ATR
向下越界深度 = max(0, frozen_visual_lower - close) / frozen_source_ATR
```

1. 收盘没有越过视觉边界：继续属于原横盘。
2. 收盘越过视觉边界，但越界深度低于本变体阈值：记为“边界渗出”，保留活动横盘；不产生强突破锚点，也不启动弱离区观察。
3. 越界深度达到阈值后，再检查既有 50% 实体与 0.15% 方向位移：通过则形成强突破来源，未通过则形成弱离区待确认。
4. 边界渗出后的后续完成棒只能使用当时仍冻结的活动横盘重新判断；不得把未来棒反算为前一棒的突破。
5. 弱离区一旦成立，下一根完成棒回到包含边界的原区间则恢复，否则消费；确认棒不能补算为旧横盘的强突破。

## L1 成功与停止条件

- 目标样本必须输出冻结视觉边界、来源 ATR、绝对越界和越界 ATR；不得只凭截图像素判断。
- 主候选 0.10 ATR 若把目标样本归为边界渗出，同时影响不少于 30 个基线离区事件、覆盖不少于 8 个币种和 3 个月，则目标样本与覆盖门通过。
- 0.05/0.10/0.15 ATR 的边界渗出数量必须单调不减；直接入场、未来数据读取和未解决状态不得增加。
- 若目标样本数据在本地不可用、其越界深度达到或超过 0.10 ATR、只影响 1～2 笔，或实现必须同时改变第二个变量，则停止在 L1。
- L1 只选 0.10 ATR 主候选；即使覆盖通过，也不在本轮自动执行 L2，先向用户报告目标点和全样本无标签影响。
