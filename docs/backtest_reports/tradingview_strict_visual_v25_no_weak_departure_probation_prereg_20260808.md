# 严格视觉横盘突破 V25 移除弱离区观察期预注册

## 假设卡片

- 当前等级：先执行 L1 无标签因果与覆盖审计；只有 L1 通过后才执行一次 L2 本地多币种诊断。
- 基线版本：V23 Research-only，保留 50% 实体占比、0.15% 方向位移、多空第 1～5 根首次合法回踩、突破棒极值止损、最少 1 ATR 实际风险、一倍冻结区间高度目标，以及统一交易成本。
- 候选版本：V25 Research-only；不覆盖 V23，不接入 Paper、Live 或生产订阅。
- 唯一变量：关闭弱离区的一棒观察期。弱棒收盘越过活动横盘边界后，立即结束并消费旧横盘，不再等待下一根完成棒决定恢复或消费。
- 预期机制：此前“弱离区后下一根回到原区间”能够恢复的旧横盘将不再恢复，因此候选与交易数应减少；本轮不预设收益方向。

## 因果定义

1. 完成棒收盘仍在冻结视觉边界内：继续沿用活动横盘。
2. 完成棒收盘越界，且同时满足方向对应的 50% 实体占比与 0.15% 方向位移：沿用 V23，形成强突破来源。
3. 完成棒收盘越界，但未同时满足上述强突破门槛：V23 进入一棒观察；V25 立即消费旧横盘，且该弱棒不形成突破锚点。
4. V25 的下一根完成棒只能参与离区后新横盘的形成，不能恢复旧横盘，也不能补算为旧横盘的强突破。
5. 不把“移除弱离区”解释为无限保留横盘或把弱棒视为区间内；本轮只比较“观察一棒”与“立即消费”。

## 保持不变

- 冻结视觉 P90/P10 边界、最长有效父横盘、强突破判定、外部结构边界、回踩接受、信号过期、止损、目标、冲突和资金路径全部保持 V23。
- 空头额外越界、EMA144 与突破实体三门禁继续关闭。
- 成本固定为入场 maker 2 bps + 1 bps 滑点、出场 taker 5 bps + 1 bps 滑点。
- 币种池、样本窗口、行情数据指纹、缺失成员处理和独立单币资金口径保持一致。
- L1 不读取 MFE、MAE、退出时间、最终 R 或胜负；不搜索第二个阈值。

## L1 成功与停止条件

- V25 的弱离区 pending、returned、consumed 计数必须全部为 0；弱越界只通过当棒离区事件消费旧横盘。
- V25 与 V23 的候选身份差异不少于 30 个，覆盖不少于 8 个币种与 3 个月；否则认为影响不足并停止。
- 多空突破棒直接入场均为 0；不得出现未解决接受、未来数据读取、非法结构止损或最少 1 ATR 合同错误。
- 任一身份或因果门禁失败即停止，不执行 L2。

## L2 判断标准

- 数据仅使用冻结 Top60 中本地满足预热要求的成员；缺失成员不补造，必须明确报告实际覆盖数。
- 主判断是成本后交易质量：V25 的严格视觉家族每笔 EV 与 Profit Factor 必须同时高于同次运行的 V23，才能称为“变好”。
- 成本后净 R、交易数与最大回撤单独报告。若只是交易减少、总亏损变小，但 EV 或 PF 下降，结论固定为“少做少亏，交易质量变差”；若指标方向不一致，结论固定为“混合”。
- 即使 V25 优于 V23，只要成本后 EV 不为正、PF 不大于 1 或不满足职业级联合门槛，仍停止在 Research-only，不晋级。
