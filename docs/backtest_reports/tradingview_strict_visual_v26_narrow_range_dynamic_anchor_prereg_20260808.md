# 严格视觉横盘 V26 窄区间动态强突破锚点预注册

## 假设卡片

- 当前等级：L0 因果定义已完成，进入 L1 无标签覆盖；只有 L1 通过后才执行一次 L2 本地多币种诊断。
- 基线：V23 Research-only，保留一棒弱离区观察。上一轮 V25 的“立即消费弱离区”不作为本轮基线。
- 候选：独立 V26 Research-only；不覆盖 V23，不接 TradingView、Paper、ReadOnly、Live 或生产。
- 唯一变量：在固定强突破门之外增加一个按冻结横盘高度归一化的替代强突破门，把窄区间中的有效方向实体从弱离区升级为锚点。
- 预计影响：至少把 30 个 V23 弱离区来源升级为最终候选，覆盖不少于 8 个币种和 3 个月；否则停止。

## 因果定义

原固定强突破门保持不变：

```text
实体占整根振幅 >= 50%
且 方向实体 / 开盘价 >= 0.15%
```

V26 新增替代门：

```text
实体占整根振幅 >= 45%
且 方向实体 / 冻结视觉区间高度 >= 25%
```

最终强突破判定为“原固定门通过，或替代门通过”。

1. 替代门只使用完成突破棒的 OHLC 与该棒出现前已冻结的视觉上沿、下沿和区间高度，不读取下一根或 outcome。
2. 多头方向实体为 `close-open`，空头为 `open-close`；反向实体不能通过。
3. 原固定门通过的突破来源必须继续通过，V26 只能新增锚点，不能拒绝既有强突破。
4. 替代门未通过时，继续沿用 V23 的一棒弱离区观察；本轮不修改弱离区恢复/消费时序。
5. 45% 是对 50% 实体效率门的有限放宽；25% 区间高度要求保证实体相对横盘本身具有结构意义，避免只因币价百分比小就把普通小 K 升级为锚点。

## 保持不变

- 最长有效父横盘、P90/P10 边界、横盘质量门、多空第 1～5 根首次合法回踩保持 V23。
- 空头额外的越界、EMA144 和突破实体三门禁继续关闭。
- 弱离区仍只观察下一根完成棒；回区恢复，否则消费，确认棒不能补算旧横盘突破。
- 突破棒极值外一 tick 止损、实际入场最少 1 ATR 风险、一倍冻结区间高度目标不变。
- 成本固定为入场 maker 2 bps + 1 bps 滑点、出场 taker 5 bps + 1 bps 滑点。
- 币种池、窗口、数据身份、缺失成员处理、冲突、反手与资金路径保持一致。

## L1 无标签成功与停止条件

- L1 只读取信号时可见字段，禁止用退出时间、MFE、MAE、最终 R 或胜负选择门槛。
- 动态门最终确认候选不少于 30 个，覆盖不少于 8 个币种、3 个月和 10 个方向加 60 分钟事件簇。
- V26 与 V23 的候选身份差异不少于 30 个，覆盖不少于 8 个币种和 3 个月。
- 单元测试必须证明多空镜像、固定门通过集合是 V26 的严格子集、动态门只读取冻结区间高度。
- 直接入场、未解决接受、非法结构止损和最少 1 ATR 合同错误必须为 0；任一门禁失败即停止，不执行 L2。

## L2 判断标准

- 仅使用冻结 Top60 中本地已有且满足预热要求的成员；缺失成员不补造，结果明确标记 partial diagnostic。
- 只完整回放 45%/25% 这一主候选，不在看到 outcome 后搜索其他比例。
- 主判断为严格视觉家族成本后 EV 与 PF：两者必须同时高于 V23，且候选自身 EV 为正、PF 大于 1，才允许进入 L3。
- 总净 R、交易数与组合资金曲线单列；不能把增加交易带来的总损益变化冒充交易质量改善。
- 成本后边际不为正则停止在 L2，不创建 Pine、不进入任何运行态。
