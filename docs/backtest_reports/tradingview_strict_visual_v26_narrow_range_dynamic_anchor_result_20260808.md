# 严格视觉横盘 V26 窄区间动态突破锚点研究结论

## 结论

第二种动态方案已按独立 Research-only 版本 V26 实现并完成 L1、L2。结论是：**不优于 V23，停止在 L2，不晋级、不生成 Pine、不进入任何运行态。**

V26 保留 V23 的边界和一棒弱离区生命周期，只在原固定强突破门失败时增加替代门：

```text
原固定门：实体 / 整根振幅 >= 50%，且方向实体 / 开盘价 >= 0.15%
动态替代门：实体 / 整根振幅 >= 45%，且方向实体 / 冻结横盘高度 >= 25%
最终强突破：原固定门通过，或动态替代门通过
```

动态门只读取当前已完成突破棒 OHLC 和此前已冻结的横盘高度；多空镜像，不读取后续 K 线，因此没有未来函数。

## L1：形态覆盖成立

- 数据：冻结 Top60 中本地完整 43 个成员，2025-07-01 08:00 至 2026-07-19 22:15（北京时间），共 13 个月；17 个缺失成员未补造。
- V23 候选 15,998 个，V26 候选 16,474 个。
- V26 动态门最终贡献 577 个确认候选，覆盖 43 个币种、13 个月和 499 个方向加 60 分钟事件簇。
- 候选身份相对 V23：新增 613 个、移除 137 个、保持 15,861 个。
- 多空镜像、固定门子集、弱离区一棒解决、结构止损和最少 1 ATR 风险合同均通过；未解决生命周期和非法合同计数均为 0。

因此这不是“样本太少导致看不出结果”：动态门确实对大量、分散的历史信号产生了影响，允许进入 L2。

## 为什么看起来合理，成本后却更差

### 已知的已知

- 零成本下，V26 的每笔 EV 从 -0.005961R 改善到 -0.005230R，PF 从 0.989562 改善到 0.990808。
- 但成本后，每笔 EV 和 PF 同时变差。
- 586 个新增成交本身成本后 EV 为 -0.175901R、PF 仅 0.716389；它们不是正边际样本。

### 已知的未知

- 当前只完成 43/60 本地可用成员的 L2 诊断，不能把结果外推成完整全市场结论。
- 本轮严格冻结 45%/25% 一个比例，没有回答其他比例是否有效；按研究纪律不能在看到盈亏后继续追阈值。

### 未知的已知

动态门带来的毛质量有极小改善，但它让平均每笔的 R 归一化成本拖累从 0.134833R 增加到 0.136895R，增加 0.002062R；这一成本恶化大于零成本 EV 的 0.000731R 改善，所以净 EV 反而下降。换句话说，窄风险交易里同样的 9 bps 往返成本会占更大的初始 R。

577 个动态候选中，460 个主要是实体占比落在 45%～50% 附近，只有 123 个是方向涨跌幅低于 0.15%；这次放宽实际主要改变的是突破棒的影线/实体形态，而不是只救回“涨跌幅很小但相对窄区间足够大”的棒。

### 未知的未知

- 较低流动性币种的真实点差和冲击可能高于当前固定 1 bps 滑点，实际结果可能比本次更差。
- 完整资金组合中的并发、相关簇和容量约束尚未进入 L3；由于 L2 已失败，没有必要继续消耗验证预算。

## 最终判断

- 当前最关键判断：**动态按区间高度放宽强锚点在视觉逻辑上成立，但没有形成成本后交易优势。**
- 最大风险：用零成本小幅改善或胜率上升 0.128 个百分点误判为策略升级；实际 EV、PF 都下降。
- 决策：V23 继续作为当前比较基线；V26 仅保留为可审计的失败研究版本，不接 TradingView 或生产。
- 下一步：若继续研究，应新开单变量假设，优先研究“成本占初始 R 的上限门”或重新定义止损风险，而不是在本批次追 45%/25% 附近阈值。
