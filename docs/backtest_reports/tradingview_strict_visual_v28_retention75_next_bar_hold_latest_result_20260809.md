# 严格视觉横盘 V28：75% 接受后额外一棒守稳 L1/L2 结果

## 结论

V28 在 L1 通过，但在 L2 成本边际门停止，状态为 `stopped_l2_cost_edge_negative`。它能因果过滤
用户指出的 BTC 样本，也整体改善基线，但成本后 EV 和 PF 仍为负，因此只保留 Research-only
证据，不创建 Pine、不接 Paper/Live，也不继续搜索等待 2～3 根或相邻守稳比例。

## L1：无标签覆盖

同一数据指纹下，53 个完整成员产生 699 个 V23 首次确认来源：

- 额外一棒守稳通过 485 个，拒绝 214 个，拒绝率 `30.62%`；
- 通过者含多头 211、空头 274，覆盖 53 币和 233 个方向小时事件簇；
- `BTC-USDT-SWAP 2026-07-31 09:15` 来源在 `09:30` 完成棒被正确拒绝；
- 扫描未读取订单、退出、MFE、MAE、胜负或 R。

目标严格横盘的真实冻结上沿是 `64990.0`，突破收盘 `65166.6`，因此额外一棒必须守住的 75%
接受价为 `65122.45`。`09:30` 完成收盘只有 `64808.1`，来源被消费，且不得在 `09:30`
开盘提前成交。

币种后仍为 `-86.11R`，所以不是收益集中度掩盖了正边际，而是整体仍没有成本后优势。

## 重要归因边界

V28 已移除目标时点的 `strict_visual_consolidation_break_long` 家族，但冻结 V20 组合回放里，旧的
`confirmed_range_acceptance_long` 家族仍在同一 `09:15` 形成意图，并于 `09:30` 开仓。因此：

- “严格横盘来源被拒绝”已经实现并验证；
- “组合账户绝不下这笔单”尚未成立；
- 若要让一个家族的拒绝否决其他独立家族，必须另立跨家族仲裁合同，不能把它暗藏在 V28
  单变量研究里。
