# 严格视觉横盘 V29：High P96 / Low P04 研究结论

## 结论

`V29BoundaryP96P04` 在 L1 有足够覆盖并通过边界实现审计，但在同一冻结数据、成本和退出合同下，
成本后单笔 EV、PF、胜率与最大回撤均劣于 V23。状态固定为
`stopped_l2_cost_edge_negative`；不得替换 V23，不继续搜索 P95/P05、P97/P03 等相邻分位，不创建
Pine，也不接入 Paper/Live。

## L1 无结果标签审计

- 完整成员：53 / 61；数据集指纹与 V23 基线一致。
- V23 确认来源 699 个，V29 确认来源 520 个，其中多头 230、空头 290。
- V29 覆盖 53 个币和 237 个方向小时事件簇。
- 843 个两版本共享的相同原始窗口中，全部满足 `P96 upper >= P90 upper` 且
  `P04 lower <= P10 lower`，实现反例为 0。
- 确认身份对称差为 1,053，说明这不是轻微边界微调，而是显著改变横盘生命周期和信号来源。

成本合同保持为入场 maker 2 bps、出场 taker 5 bps、双边各 1 bps 滑点。V29 虽减少 171 笔交易，
但删掉的并不是更差的稳定子集：剩余样本胜率、EV、PF 和回撤同时恶化。净 R 只少亏 0.323R，来自交易
数下降，不能解释为质量提高。

## 为什么 P96/P04 没解决错误横盘

P96/P04 会把上沿向高点外推、下沿向低点外推，扩大同一窗口的价格带。扩大后虽然突破必须越过更极端
边界，信号数量会减少，但触边容差仍按区间高度计算，漂移又以区间高度归一化。结果是脉冲、急跌和 V
型收回可能被更宽的带吸收，而不是真正形成双向价格接受。图 2 暴露的核心不是分位点不够极端，而是
当前定义缺少对“内部单次冲击 / U-V 型路径”的独立约束。

图 2 没有可唯一定位的时间轴或十字光标，因此本轮没有补造该截图的数据库命中结论。后续若研究横盘
形态质量，应把“内部冲击或真实极差相对稳定带过大”作为独立假设，而不是继续移动分位阈值。
