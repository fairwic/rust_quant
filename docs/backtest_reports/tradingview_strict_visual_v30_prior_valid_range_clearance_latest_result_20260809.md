# 严格视觉横盘 V30：前方旧横盘净空研究结论

## 结论

`V30PriorValidRangeClearance` 有足够广义覆盖，但只命中两个预注册 BTC 目标中的一个，状态固定为
`stopped_l1_target_miss`。按研究合同不得读取成交后结果，因此没有 V30 L2 收益、EV、PF 或回撤结论；
不得接入 TradingView、Paper 或 Live，也不得在同一数据上追 64/128 根或 0.5/1.5 个区间高度。

## 命中的 `65014.3` 结构

- 当前冻结横盘：`[64646.0, 64931.1]`，高度 `285.1`，16 根。
- 前方旧横盘：`[64782.4, 65192.8]`，8 根；北京时间 07-23 21:00 开始、23:00 离开。
- 当前突破棒：北京时间 07-24 04:00；确认来源：05:00。
- 两个区间重叠，方向净空为 `0 / 285.1 = 0` 个当前区间高度，因此因果规则能够拒绝。

## 为什么不能继续做 V30 收益回放

`66653.6` 在固定 96 根、一个当前区间高度合同下没有找到可阻挡的“此前已完成且未解决的严格视觉
横盘”。这不等于图上没有供应压力，而是说明黄色区域与“严格横盘障碍”不是同一种结构。它更接近
摆动高点、历史供应带或前高密集区。为了命中它而在看到结果后把“有效横盘”改成任意前高，属于更换
形态定义并追目标样本，不能伪装成 V30 的小修。

若后续要研究图 4，应另立预注册：用因果 swing/pivot 形成历史供应带，并在全新窗口或 walk-forward
验证；不能复活已经失败的 V9 raw-high 规则，也不能与 Fibonacci 同时加入。

## Fibonacci 边界

本轮没有加入 Fibonacci。图 5 的 0.618/0.786 与历史供应带看起来有重合，但 swing 的起止点若由事后
目测选择，会引入主观锚点甚至未来数据。只有在逆势交易场景中，先用信号前已经确认的高周期 pivot
冻结 swing，再把某一个固定回撤位作为单变量，才有资格进入新的 L1。
