1. “两个实体触碰组”在任何成熟横盘内部几乎必然存在，导致 `98.5%` 的双侧可用率；这个字段不能区分高质量外壳。
2. 上侧最外层实体只有一次独立接受，算法按预注册规则拒绝它，因此上沿退回 P90 核心上沿。
3. 更本质的是，V31 会先按核心边界结束旧横盘；黄色框允许价格短暂离开核心但仍属于更宽的实体接受父区间。外壳若不拥有自己的生命周期，就会在 `20:00` 提前结束。
4. 把黄色框左端回画到 `06:00` 还涉及“确认后历史绘图起点”，它可以作为只读视觉回画，但绝不能反过来把 `18:30` 才确认的结构伪装成 `06:00` 已可交易。
