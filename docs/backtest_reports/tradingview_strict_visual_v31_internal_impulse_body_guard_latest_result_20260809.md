# 严格视觉横盘 V31：首次目标映射 L1 结论

## 结论

首次预注册按截图十字光标把目标冻结为北京时间 `2026-07-30 09:00` 的“活动横盘”，但 Rust V23
在该完成时点没有活动横盘，因此目标门禁失败，状态固定为 `stopped_l1_target_time_mismatch`。本批次
没有读取订单、退出、MFE、MAE、最终 R 或胜负，也没有进入 L2。

这不是内部冲击规则零覆盖：53 个完整成员中，V31 发生 206 次活动横盘结构重置，覆盖 51 个币；
确认来源从 V23 的 699 个变为 410 个，其中多头 183、空头 227，覆盖 53 个币和 214 个方向小时
事件簇。目标失败只说明十字光标不是该蓝框的因果确认时点。

## 黄色框的真实因果时序

当前数据库 OHLC 与截图十字光标完全一致：北京时间 `09:00` 为
`63672.2 / 63860.0 / 63666.9 / 63680.0`。但 V23 蓝框直到 `09:30` 完成后才确认：

- 回画起点：`05:45`；
- 首次及边界确认：`09:30`；
- 长度：16 根；
- P90/P10 边界：`64088.0 / 63580.0`；
- V23 随后在 `09:45` 形成突破接受等待来源。

因此图上蓝框覆盖 `09:00` 属于“确认后向左绘制历史窗口”，不代表 `09:00` 当时已经存在可交易
横盘。V31 在同一数据上没有生成 `09:30` 的该横盘，也没有 `09:45` 的对应来源，说明过滤方向与用户
指出的视觉问题一致；但按首次预注册，不能用扫描后发现的 `09:30` 替换 `09:00` 并在同一批次继续
读取收益。
