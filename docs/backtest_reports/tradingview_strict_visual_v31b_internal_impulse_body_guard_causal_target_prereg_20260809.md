## 冻结因果定义

设冻结横盘高度为 `H = upper - lower`：

```text
internal_body_to_range_height = abs(close - open) / H
```

1. 形成候选横盘时，只读取候选窗口内已经完成的 K 线；任一根比例 `>= 0.50`，候选无效。
2. 已确认横盘内的新完成棒收盘仍处于闭区间 `[lower, upper]`，但比例 `>= 0.50` 时，完成该棒后重置
   当前横盘，并从下一根重新累计。
3. 收盘越界仍先执行 V23 的强突破或弱离区合同，不把真正离区棒归为内部冲击。
4. 多空镜像；方向、成交量、ATR 和后续表现不参与门禁。
5. 阈值固定 `0.50`；本批次禁止搜索相邻阈值。
