# 严格视觉横盘 V31b：内部冲击棒门禁研究结论

## 最终判断

`max(abs(close - open)) / (upper - lower) < 0.50` 能解决用户黄色框的视觉误判，并在当前多币种
窗口显著减少交易、改善成本后 EV、PF 和回撤；但 V31 仍为负期望，因此结论为
`stopped_l2_negative_net_edge`。

本版本保持 Research-only：不替换 V23，不生成 Pine，不接入 Paper、Live 或生产消费路径，也不在同一
数据上继续搜索 0.40、0.60 或横盘长度阈值。

## 规则实现

设冻结横盘高度 `H = upper - lower`：

```text
internal_body_to_range_height = abs(close - open) / H
```

1. 候选窗口任一完成 K 线比例 `>= 0.50`，不确认该横盘。
2. 活动横盘内的新完成棒仍收在 `[lower, upper]`，但比例 `>= 0.50`，完成该棒后重置横盘；该棒不作为
   新横盘第一根，下一根才重新累计。
3. 收盘越界仍使用 V23 原强突破/弱离区合同；多空镜像。
4. V23 行为保持不变，V31 使用独立版本身份。

伪装成一笔被过滤的盈利或亏损交易。

### 信号身份变化解释

V31 会重置横盘并从下一根重新累计，不是简单删除 V23 交易的严格子集：

| 子集 | 交易数 | 净 R | EV | PF |
|---|---:|---:|---:|---:|
| V23-only，被 V31 生命周期移除 | 442 | -105.314 | -0.2383R | 0.6262 |
| V31-only，重置后产生的新身份 | 172 | -7.108 | -0.0413R | 0.9317 |
| 两版共同身份 | 219 | -48.422 | -0.2211R | 0.6521 |

这说明门禁确实删除了一批明显较差的旧来源；但保留下来的共同来源仍为负期望，重置后新增来源也只是
接近盈亏平衡，尚不足以形成可交易优势。

### 收益集中度与长度诊断

- 移除 V31 头部 5 笔盈利后：386 笔、`-74.107R`、EV `-0.1920R`、PF `0.6954`。
- 移除最佳正贡献币种 XRP 后：385 笔、`-61.576R`、EV `-0.1599R`、PF `0.7468`。
- 53 个有交易币种中仅 22 个净盈利，31 个净亏损；负期望不是由少数赢家掩盖。
- 32 根横盘在本窗口为 52 笔、EV `+0.3386R`、PF `1.7083`；96 根为 34 笔、EV `+0.1269R`、
  PF `1.1692`，其余离散长度均为负。该切片是在读取结果后发现的诊断，禁止直接反向加入本版本；如要
  研究长度，必须作为新的单变量假设并使用独立/OOS 数据。
