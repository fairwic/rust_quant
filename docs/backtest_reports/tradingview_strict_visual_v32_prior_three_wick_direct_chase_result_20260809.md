# V32 前三根承接影线直接追随：研究结论

## 结论

不晋级，不合并 V31。目标 BTC 样本得到改善，但该形态在多币种样本中显著恶化。

## L1 与目标核对

- BTC `2026-07-30 16:15` 突破棒前三根存在 `lower_wick/source_atr >= 0.50`，正确切换为直接追多。
- 多空镜像后影响 381/1270 个强突破来源，覆盖 53 个币种；L1 通过。
- 目标 BTC 交易由 V31 的 `+0.09849R` 改善到 V32 的 `+0.41713R`。
