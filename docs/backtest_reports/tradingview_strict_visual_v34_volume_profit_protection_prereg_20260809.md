# 严格视觉横盘 V34：盈利后放量净保本保护预注册

## 研究等级与唯一变量

- 当前等级：L1 触发覆盖；通过后才允许一次 L2 成本后退出回放。
- 基线：`V31InternalImpulseBodyGuard`。
- 候选：`V34VolumeProfitProtection`，独立 Research-only 身份。
- 唯一变量：持仓后首次出现既有 `volume_event` 且完成收盘已经覆盖交易成本时，从下一根开始启用净保本止损。

## 因果定义

1. 不修改入场、初始止损、目标、冲突或成交顺序；仅作用于已成交的严格视觉横盘交易。
2. 只读取入场后的完成棒；成交所在 K 线不允许激活，避免未知棒内顺序。
3. `volume_event` 完全复用当前指标定义，不新增或搜索成交量阈值。
4. 多头净保本价为 `entry*(1+0.0003)/(1-0.0006)` 后向上对齐 tick；空头镜像并向下对齐。
5. 只有完成收盘已经位于净保本价的盈利侧才激活；激活止损从下一根 K 线生效，跳空则按实际开盘成交。

## 目标样本与停止条件

- `BTC-USDT-SWAP` 北京时间 `2026-07-20 13:30` 入场的空单，必须在 `14:30` 完成棒后激活净保本保护。
- L1 至少有 3 笔交易激活，覆盖至少 2 个币种；目标样本未命中即停止。
- L2 只比较冻结入场集合的退出变化；成本固定为入场 3 bps、出场 6 bps。候选须改善净 EV、PF 与最大回撤，且改善不集中于单一交易或事件簇。
