# 严格视觉横盘 V36：视觉边界与交易突破边界分离预注册

## 研究等级与唯一变量

- 当前等级：L1 无结果标签覆盖；通过后才允许一次 L2 多币种成本回放。
- 基线：`V31InternalImpulseBodyGuard`。
- 候选：`V36SplitTradeBoundary96`，独立 Research-only 身份。
- 唯一变量：P90/P10 继续作为视觉与回踩边界；强突破还必须收盘越过左侧未解决有效横盘的方向远边。

## 因果定义

1. `visual_upper/visual_lower` 始终等于当前子横盘 High P90 / Low P10，用于画图、回踩触碰、75% 接受、区间高度、止损和目标。
2. 只扫描突破棒左侧最近 96 根已完成 K 线内、在当前子横盘开始前已经完成的严格视觉横盘。
3. 多头选择上方价格最近且尚未被完成收盘越过的旧横盘，`trade_breakout_upper=max(visual_upper, prior.upper)`。
4. 空头完全镜像，`trade_breakout_lower=min(visual_lower, prior.lower)`；这里使用旧支撑区的远边，不是近边。
5. 若没有方向上的未解决旧横盘，交易边界退化为视觉边界。强突破棒必须收盘越过交易边界至少一个 tick；否则消费当前来源，不进入回踩窗口。
6. 交易边界只在突破棒完成时冻结；后续回踩仍以视觉边界确认，不用未来 K 线解除结构。

## 目标样本与停止条件

- `ETH-USDT-SWAP` 北京时间 `2026-07-24 08:15` 与 `2026-07-29 11:30` 对应来源必须因尚未突破更大支持区远边而被拒绝。
- L1 至少拒绝 3 个来源，拒绝比例不超过 V31 强突破来源的 60%；候选仍须覆盖多空及至少 8 个币种。
- 任一目标未命中或覆盖条件失败即停止，不读取最终盈亏。
- L2 成本固定为入场 3 bps、出场 6 bps；候选须同时改善净 EV 与 PF，且改善不集中于 1～2 笔、单币或单一事件簇。
