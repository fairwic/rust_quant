# 严格视觉横盘 V36b：视觉边界与横盘前外部极值边界分离预注册

## 研究等级与唯一变量

- 当前等级：L1 无结果标签覆盖；通过后才允许一次 L2 多币种成本回放。
- 基线：`V31InternalImpulseBodyGuard`。
- 候选：`V36PreRangeExtremeTradeBoundary96`，独立 Research-only 身份。
- 唯一变量：P90/P10 继续作为视觉与回踩边界；强突破还必须收盘越过当前横盘开始前 96 根的方向外部极值。

## 因果定义

1. `visual_upper/visual_lower` 始终等于当前子横盘 High P90 / Low P10，用于画图、回踩触碰、75% 接受、区间高度、止损和目标。
2. 外部结构窗口严格止于当前子横盘开始前一根完成 K 线，最多向左读取 96 根，禁止读取突破后数据。
3. 多头外部结构取该窗口最高价；若当前横盘形成至突破前已有完成收盘越过该高点一个 tick，则视为已解决并退化为 `visual_upper`；否则 `trade_breakout_upper=max(visual_upper, external_high)`。
4. 空头完全镜像：外部结构取该窗口最低价；已解决则退化为 `visual_lower`；否则 `trade_breakout_lower=min(visual_lower, external_low)`。
5. 强突破棒必须收盘越过交易边界至少一个 tick；否则消费当前来源，不进入回踩窗口。后续回踩仍使用视觉边界。

## 目标样本与停止条件

- `ETH-USDT-SWAP` 北京时间 `2026-07-24 08:15` 与 `2026-07-29 11:30` 对应来源必须因尚未突破更大外部支撑而被拒绝。
- L1 至少拒绝 3 个来源，拒绝比例不超过 V31 强突破来源的 60%；候选仍须覆盖多空及至少 8 个币种。
- 任一目标未命中或覆盖条件失败即停止，不读取最终盈亏。
- L2 成本固定为入场 3 bps、出场 6 bps；候选须同时改善净 EV 与 PF，且改善不集中于 1～2 笔、单币或单一事件簇。
