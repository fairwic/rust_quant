# 严格视觉横盘 V37：顺向影线抵扣突破实体门槛预注册

## 研究等级与唯一变量

- 当前等级：L1 无结果标签覆盖；本轮不读取订单、退出、MFE、MAE、最终 R 或胜负。
- 基线：`V31InternalImpulseBodyGuard`，突破棒实体占比至少 50%，方向位移至少 0.15%。
- 候选：`V37SupportiveWickBodyCredit`，仅研究、不接入 Paper、Live 或默认 TradingView 交易信号。
- 唯一变量：顺突破方向的拒绝影线可以降低实体占比门槛；其他横盘、弱离区、回踩、止损、目标和成本合同不变。

## 因果定义

设整根振幅 `R = high - low`，实体占比 `B = abs(close - open) / R`。

- 多头的顺向影线为下影线，反向影线为上影线。
- 空头的顺向影线为上影线，反向影线为下影线。
- `net_supportive_wick = max(0, supportive_wick / R - opposing_wick / R)`。
- `wick_credit = min(0.10, 0.20 * net_supportive_wick)`。
- `required_body = max(0.40, 0.50 - wick_credit)`。
- 候选突破仍须满足 `B >= required_body`，且方向位移至少 0.15%。

该定义意味着净顺向影线每增加 5%，实体门槛降低 1 个百分点；净顺向影线达到 50% 时才获得完整
10 个百分点抵扣。没有顺向拒绝证据的 K 线仍使用 50% 门槛，不能仅凭实体达到 40% 放行。
