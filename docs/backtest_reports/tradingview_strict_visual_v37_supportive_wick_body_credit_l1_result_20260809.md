## 结论

V37 停止在 L1，不进入盈亏回放，也不同步到 V31 的 Rust 或 TradingView 交易判定。

公式具有足够的一般覆盖，但预注册 BTC 目标没有在 Rust 的 OKX V31 状态机中复现为弱离区。由于
目标门禁失败，不能只凭截图把 40% 动态实体门槛升级成交易规则。

- 开 62739.1，高 62916.4，低 62525.8，收 62899.9。

但 Rust V31 在该时点没有产生 `WeakDeparturePending`。补充的逐棒状态审计确认：目标棒前、目标棒后

01:15 才完成确认。因此失败不在单根 K 线强度，而在目标棒没有 V31 横盘来源。

## Pine / Rust 因果状态对齐

TradingView Binance V31 与 Rust OKX V31 在目标时刻的状态结论一致，不存在 Pine/Rust 首个分歧：

- Pine V31 在北京时间 2026-08-03 21:30 没有活动横盘。此前最近一次生命周期事件是 11:15 的
  向下弱离区，来源区间为 `63575.6 / 63063.5`；之后该来源已消费。
- Pine V31 下一段区间从 22:30 开始，边界为 `63960.0 / 63610.2`；目标棒不属于该区间。
- Rust OKX 在目标棒前后同样是空状态；下一段区间也从 22:30 开始，并于次日 01:15 以
  `63989.9 / 63612.7` 确认。边界小差异来自 Binance / OKX 行情源，不改变状态身份。
- 截图同时叠加了 V22 与 V31。覆盖 21:15 的旧蓝框边界约为 `62848.0 / 62403.9`，该区间存在于
  V22，不存在于 V31。因此截图中的“扫高后回区”是 V22 结构，不能作为 V31 动态实体门槛的目标样本。

本轮由此固定为“图层身份不一致”，而不是“Pine/Rust 状态机不一致”。不把 V22 横盘补算成 V31
来源，也不因该截图改写 V31 的内部冲击门禁。
