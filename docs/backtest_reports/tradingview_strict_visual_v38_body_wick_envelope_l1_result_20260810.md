# V38 实体包络与扫影线容忍边界 L1 结果

## 结论

- 状态：`stopped_l1_scope_excess_and_target_quality_gate`。
- 新公式在机械定义上成立：全部实体均被包含，每侧约 10% 的极端 High/Low 端点可以留在边界外作为扫高、扫低。
- 新公式不能直接替换 V31 的可交易横盘边界：样本外有效窗口身份受影响比例为 `75.78%`，超过预注册上限 `40%`；目标 BTC 窗口的新下沿也只有 1 个独立触碰组，未达到现有至少 2 组的横盘接受要求。
- 本轮按 L1 停止，没有读取盈亏或成交后路径，没有执行完整回测，没有创建或修改 Pine，也没有覆盖 V31、Paper、Live 或生产入口。

## 已知的已知

- 冻结公式为 `100% 实体包络 + 约 90% 影线端点覆盖`。
- 每侧允许越界影线数为 `max(1, floor(N / 10))`：48 根窗口每侧允许 4 根。
- 评价窗口为北京时间 `[2026-07-28 00:00, 2026-08-09 12:15)`；61 个请求成员中 53 个满足完整 60 天预热与评价覆盖，8 个预热不足成员被隔离且未补数据。
- 数据集指纹为 `ce8b7c31cb720e50f32689c35d5c1b28148f55b0b07f82ed4ee4be7fce8f648c`。

## 被忽略但已存在的事实

- “包住全部实体”回答的是视觉归属问题；“上下沿各有至少两组触碰”回答的是价格接受问题，两者不是同一个边界职责。
- 单次极端实体可以合理属于一个父级震荡外壳，但不能仅凭该实体证明新的可交易支撑或阻力已经被反复确认。

## 尚未覆盖的风险

- 若视觉外壳参与突破判断，边界扩大可能延迟或吞掉真实突破。
- 若视觉外壳参与区间高度、止损或目标计算，会同时改变风险距离，不能与本轮边界变量混合验证。
- 视觉父区间与交易核心区间的生命周期、失败突破恢复和弱离区归属仍需单独定义，避免同一根 K 线在两个层级间反复重算。
