# V40 视觉父区间执行边界 L1/L2 预注册

## 假设卡片

- 当前等级：先执行 `L1_OUTCOME_BLIND_COVERAGE`；只有 L1 通过才允许执行一次冻结成本的 `L2_MULTI_SYMBOL_DIAGNOSTIC`。
- 基线：`V31InternalImpulseBodyGuard`。
- 唯一变量：V31 `trade_core` 继续确认横盘质量；同一完成窗口冻结的 `visual_parent` 仅替换离区、突破与入场回踩使用的方向边界。
- 可证伪假设：把“全部实体 + 约 90% 影线”的父边界用于执行，能够把核心边界外但父区间内的波动继续归为横盘，并减少过早突破来源；保留下来的来源仍应覆盖多方向、多币种和多个独立事件簇。
- 因果定义：父边界只读取 `range.start_index..=range.boundary_confirmation_index` 的已完成 K 线。离区棒、确认棒及其后价格不得扩张或反改父边界。
- 保持不变：候选长度、V31 横盘质量门、核心区间高度、内部冲击门、突破棒 50% 实体 / 15 bps 位移门、弱离区一棒观察、1～5 根首次回踩、75% 越界保留、突破棒极值止损、最小 1 ATR 风险、量度目标、保本、手续费、滑点、冲突与资金路径。

## 冻结职责

### acceptance_core

- 等于 V31 `trade_core`，仍使用 `High P90 / Low P10`。
- 只负责横盘候选身份和质量：宽度、双侧触碰、包含率、漂移、方向效率、边沿交替和内部冲击。
- 继续提供核心区间高度；本轮止损、目标与 R 的计算不得改用父区间高度。

### execution_parent

- 等于 V39 已验证的 `visual_parent`：全部实体被包含；每侧允许 `max(1, floor(N/10))` 根极端影线端点留在边界外；最终再外包 `acceptance_core`。
- 当前收盘越过核心但仍位于父区间内，不构成离区、弱离区或突破。
- 当前收盘越过冻结父边界且通过 V31 突破棒强度门，才冻结强突破来源。
- 弱离区的返回/消费、突破越界幅度、75% 保留价、1～5 根回踩触碰和失效，均使用同一个已冻结方向父边界。
- 父边界不得参与横盘质量判定、区间高度、止损、目标或仓位计算。

## L1 无结果标签门禁

- 对同一数据指纹同时扫描 V31 与 V40，机器账本不得包含成交、MFE、MAE、退出时间、最终 R、盈亏或胜负。
- V40 强突破来源必须同时满足：父边界已冻结、突破棒索引晚于边界确认索引、方向边界确实来自该父区间。
- V40 来源不得少于 V31 来源的 10%，也不得高于 100%；否则分别视为覆盖塌陷或实现污染。
- V40 必须同时覆盖多头与空头、至少 8 个币种、至少 10 个按“方向 + 小时”归并的事件簇。
- 至少 3 个 V31 来源应因核心到父边界的差异被改变；否则变量没有实质覆盖。
- 任一父区间未包含核心、未包含全部实体、超过允许影线数量，或读取边界确认之后的 K 线，立即停止。

## 条件 L2 固定回放

- 只有 L1 全部门禁通过才执行；不搜索相邻阈值、不同时调整任何其他合同。
- 本地已有完整预热成员，固定评价窗口为北京时间 `[2026-07-19 22:30, 2026-08-09 12:15)`；缺失或预热不足成员隔离，不同步 K 线。
- 成本固定为：入场 maker `2 bps` + 滑点 `1 bps`，出场 taker `5 bps` + 滑点 `1 bps`。
- V31 与 V40 使用同一行情指纹、成员、窗口、止损、目标、冲突和资金路径。
- L2 停止条件：V40 成本后净 EV `<= 0R`、PF `<= 1.0`、收益集中于 1～2 笔或单一事件簇，或相对 V31 没有正向边际。
- L2 通过仅允许保留为 L3 候选；未完成 point-in-time 币种池、OOS/walk-forward、参数邻域、成本压力和统一资金曲线前不得晋级或生成 Pine。
