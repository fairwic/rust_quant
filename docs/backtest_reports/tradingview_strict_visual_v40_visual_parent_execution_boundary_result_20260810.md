# V40 视觉父区间执行边界 L1/L2 结论

## 最终判断

`visual_parent` 不适合直接替代 V31 的交易边界。本轮保留它作为“全部实体 + 约 90% 影线”的绘图区间；突破、弱离区恢复和 1～5 根回踩继续使用 V31 `trade_core`。

V40 在无结果标签的 L1 中覆盖充分且没有因果违规，但固定成本 L2 明显变差。按预注册停止条件，本轮停止，不创建或同步 TradingView/Pine 版本，也不在同一数据上继续搜索影线比例。

## 认知框架

### 已知的已知

- V40 只改变执行边界；V31 横盘质量、核心高度、突破棒门禁、回踩窗口、止损、目标、R、保本和成本合同保持不变。
- `visual_parent` 只读取边界确认及之前的完成 K 线；突破棒和后续 K 线不能反向扩张边界。
- 本轮使用本地 `quant_core` 已有数据，没有同步或补造缺失 K 线。

### 已知的未知

- `visual_parent` 是否可作为辅助语境，例如只用于展示、假突破说明或失效分级，仍需新的独立假设与样本外研究。
- 本轮不是 point-in-time 币种池，也不是统一资金和容量约束组合，不能据此形成生产晋级结论。

### 未知的已知

- 更宽的父边界并不只是删除核心边界的早突破；它会改变横盘状态机的离区与恢复时点，从而重新生成一批更晚的突破来源。
- V40 新增的晚突破来源明显更老、更迟，恰好是本轮主要亏损来源。

### 未知的未知

- 不同市场阶段、历史成分币池、统一资金冲突和真实成交容量可能进一步改变结果。
- 若未来研究“父边界只做辅助门禁”，必须预先冻结单一用法，不能根据本轮亏损样本反推阈值。

## 差异来源

按 `symbol + direction + signal_time` 对齐实际成交：

| 成交队列 | 笔数 | 胜 / 负 | 净 R | 单笔净 EV |
|---|---:|---:|---:|---:|
| 两版共有，按 V31 计算 | 279 | 124 / 155 | -56.0956 | -0.2011R |
| 两版共有，按 V40 计算 | 279 | 124 / 155 | -55.9523 | -0.2005R |
| 仅 V31 | 112 | 51 / 61 | +0.5661 | +0.0051R |
| 仅 V40 | 96 | 25 / 71 | -48.6332 | -0.5066R |

共有交易几乎没有变化。恶化主要来自 V40 重新产生的 96 笔交易：

- 多头 46 笔，净 `-21.8396R`，EV `-0.4748R`。
- 空头 50 笔，净 `-26.7935R`，EV `-0.5359R`。
- 其中 66 笔止损，合计 `-76.0704R`；27 笔目标退出仅贡献 `+27.4533R`。
- 96 个来源中 91 个确实使用了不同于核心边界的父边界。
- V40 独有来源的方向父边界平均外扩 `0.1664` 个核心区间高度，最大 `0.5882`。
- V40 独有来源平均横盘长度 `53.75` 根，共有来源为 `22.11` 根。
- 从边界确认到突破，V40 独有来源平均等待 `18.41` 根，共有来源为 `6.14` 根。

这说明父边界把部分核心突破继续视为横盘后，后续突破往往已经变成较老、较迟的结构。它不是单纯过滤噪声，而是重定时并新增了低质量晚突破；这是本轮性能恶化的主要机制。

## 决策与下一步

1. V31 继续作为交易边界基线；本轮不修改其生产或 TradingView 交易合同。
2. `visual_parent` 保留为绘图职责，表达实体全包和约 90% 影线的视觉横盘。
3. V40 保持 research-only，结论为 `STOP_V40_DO_NOT_PROMOTE_OR_CREATE_PINE`。
4. 若继续研究，下一张假设卡片应只测试一种辅助用途，例如“父边界只参与假突破恢复展示，不参与突破触发”；必须换样本或走 walk-forward，不能在本窗口继续追比例阈值。
