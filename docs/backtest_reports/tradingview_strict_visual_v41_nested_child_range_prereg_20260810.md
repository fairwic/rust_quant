# V41 父区间内局部盘整交易源 L1/L2 预注册

## 假设卡片

- 当前等级：先执行 `L1_OUTCOME_BLIND_COVERAGE`；只有 L1 通过才允许执行一次冻结成本的 `L2_MULTI_SYMBOL_DIAGNOSTIC`。
- 基线：`V31InternalImpulseBodyGuard`；V31 父区间及既有父区间交易来源完整保留。
- 唯一变量：V31 父区间活动期间，允许一个起点更晚、仍满足全部 V31 横盘质量门的局部盘整作为独立子交易源。
- 可证伪假设：父区间会遮蔽一批信号时已经完成、边界更局部的有效横盘；独立保存这些子区间能够覆盖图中 BTC 目标，同时在多币种上形成非集中、可重复的子突破来源。
- 保持不变：候选离散长度、P90/P10 `trade_core`、V31 质量门和内部冲击门、50% 实体 / 15 bps 突破棒门、弱离区一棒观察、1～5 根首次回踩、75% 越界保留、突破棒极值止损、最小 1 ATR 风险、量度目标、保本、手续费、滑点、持仓容量与退出合同。

## 冻结因果定义

### 父区间

- 父区间继续由原 V31 单活动区间状态机产生；子区间不得扩张、缩窄、关闭或替换父区间。
- 父区间的 `visual_parent` 只读取父区间边界确认及之前的完成 K 线，用于判定子区间在视觉上仍属于父结构；父区间交易仍只使用自己的 `trade_core`。

### 子区间

- 只在父区间已经确认且仍活动时扫描；候选必须使用 V31 原离散长度 `[8, 12, 16, 24, 32, 48, 64, 96]` 和全部原质量门。
- 子区间起点必须严格晚于父区间起点，首次确认必须严格晚于父区间首次确认，避免在父区间首次确认同一棒上把较短窗口重复命名为子区间。
- 子 `trade_core` 必须完整位于冻结父 `visual_parent` 内；上下边界至少一侧与父 `trade_core` 相差一个 tick，避免把同一区间重复命名为子区间。
- 同一完成时点若有多个合法子候选，只选择原扫描顺序中的最长候选；不得根据后续盈亏改选长度。
- 一个父区间同一时刻最多保留一个活动子区间。子区间离开、失败或过期后，新子区间必须从旧子区间离开棒之后重新积累。
- 子区间使用自身冻结的 `trade_core`、高度、突破棒、回踩、止损和目标；子突破只消费子区间，不消费仍有效的父区间。
- 父区间发生强突破、弱离区、内部冲击重置或被新父区间替换时，活动子区间及其待确认来源同时结束，不能跨父区间续接。

### 父子冲突

- 原 V31 父来源优先，确保既有父信号身份不被子区间改写。
- 同一完成棒父、子同时形成突破来源时只保留父来源；子来源不重复开仓。
- 子来源等待回踩期间若父区间形成突破来源，立即取消子来源并按原 V31 父来源推进。
- 父区间没有来源等待时，子来源才可以进入原 1～5 根接受窗口。实际持仓仍沿用原单持仓、下一开盘成交和反手/冲突合同。

## BTC 目标样本

- 目标：用户黄色框所示、北京时间 2026-08-07 日内、位于更大活动父区间内部的局部盘整。
- 通过条件：在不读取目标之后 K 线的前提下，机器账本必须给出一个起点位于黄色框左缘北京时间 `[07:30, 08:30]`、并在黄色框右缘 `16:30` 之前完成首次确认的合法子区间，记录父/子起止、确认时点、父视觉边界、子核心边界及所有门禁；不得用手工指定长度或价格补造。
- 预注册勘误：首次机器扫描曾把黄色框右缘误写为“首次确认窗口 `[15:45, 16:30]`”。横盘首次确认可以早于绘图终点并继续存续；在查看任何成交后结果前，将目标审计修正为上述左缘起步、右缘前已确认的因果语义。结构、交易和 L2 门禁均未改变。

## L1 无结果标签门禁

- 机器账本只允许包含信号时可见结构、突破和确认字段；禁止成交后价格、MFE、MAE、退出、最终 R、盈亏或胜负。
- BTC 目标必须命中；否则立即停止。
- 子区间确认来源至少 10 个，同时覆盖多头与空头、至少 3 个币种、至少 3 个按“方向 + 小时”归并的事件簇。
- 子来源数必须介于 V31 父确认来源的 2%～50%；低于下限视为只修个例，高于上限视为把局部结构泛化成重复信号。
- 父视觉包含、子核心包含、确认时序、父子身份、单活动子区间和父来源优先任一违例非零，立即停止。

## 条件 L2 固定回放

- 只有 L1 全部门禁通过才执行；不搜索候选长度、包含比例、优先级或任何相邻阈值。
- 使用本地已有完整预热成员，固定评价窗口为北京时间 `[2026-07-19 22:30, 2026-08-09 12:15)`；缺失或预热不足成员隔离，不同步 K 线。
- 成本固定为：入场 maker `2 bps` + 滑点 `1 bps`，出场 taker `5 bps` + 滑点 `1 bps`。
- V31 与 V41 使用同一行情指纹、成员、窗口、止损、目标、冲突、容量和资金路径。
- L2 停止条件：新增子区间成交成本后净 EV `<= 0R`、PF `<= 1.0`、收益集中于 1～2 笔或单一事件簇，或 V41 组合相对 V31 的净 EV/PF/回撤没有正向边际。
- L2 通过只允许创建独立 Research-only Pine 并进入 L3 候选；未完成 point-in-time 币种池、OOS/walk-forward、成本压力、收益集中度和统一资金曲线前不得晋级或接入 Paper/Live。
