# V41 父区间内局部盘整交易源 L1/L2 结论

## 结论

V41 已在 Rust 中作为独立 `Research-only` 版本实现，能够因果地识别父区间内部、起点更晚且边界不同的局部盘整，并复用 V31 的突破、1～5 根首次合法回踩、开仓、止损和止盈合同。

固定成本后的 L2 联合门禁失败：V41 新增 21 笔成交只贡献 `+0.40935R`，新增子集 EV 为 `+0.01949R`、PF 为 `1.04014`；组合最大回撤却从 `67.56611R` 增至 `68.04880R`。该结果只否定当前突破、回踩、止盈止损组合的晋级资格，不否定 V41 父内局部横盘识别合同。

后续口径更正：V41 已作为独立 TradingView Research-only Pine 保存，用于横盘识别审计和交易合同诊断；它不替换 V31，也不接入 Paper/Live。识别版本是否保留与当前交易合同是否盈利分开判断。

## 冻结定义

- 父区间继续使用原 V31 状态机，子区间不能修改父区间身份或边界。
- 只在父区间已确认且仍活动时扫描子区间；候选长度和全部质量门与 V31 相同。
- 子区间起点晚于父区间起点，首次确认晚于父区间首次确认。
- 子 `trade_core` 必须完整位于父区间冻结的 `visual_parent` 内，且至少一侧边界与父 `trade_core` 相差一个 tick。
- 同一时点选择最长合法子候选；一个父区间同一时刻最多保留一个活动子区间。
- 父来源优先；父区间发生突破、弱离区、内部冲击重置或被替换时，子区间及其待回踩来源结束。
- 子突破使用自己的核心边界、高度、突破棒、目标和止损；成本仍为入场 maker `2 bps` + 滑点 `1 bps`、出场 taker `5 bps` + 滑点 `1 bps`。

## 四层判断

### 已知的已知

- 单活动父区间确实会遮蔽一批结构上合法的局部盘整。
- V41 可以无未来数据地恢复这些子结构，并保持原 V31 父信号身份不变。
- 新增子集不是单币或单事件偶然样本，但固定成本后优势接近零。

### 已知的未知

- 尚未进入 OOS、walk-forward、成本压力和 point-in-time 币种池验证，无法判断这 `0.01949R` EV 是否可复现。
- TradingView Pine 已作为识别审计版本保存；L2 停止后不得把其策略测试器结果表述为可晋级或可实盘结果。

### 未知的已知

- “图上应当标记”与“适合交易”是两个合同：局部盘整在视觉上成立，并不自动产生足够的成本后收益。
- 增加信号数量提高了胜率，却没有改善联合风险；单看胜率会掩盖回撤恶化和盈亏额近乎抵消。

### 未知的未知

- 当前冻结成员存在幸存者偏差；真实历史成员、流动性和相关簇容量约束可能进一步削弱这点边际。
- 更差成交、手续费变化或对子区间信号的并发容量限制，可能把微弱正边际变成负值。

## 停止决定

- L1：通过。
- L2：失败，原因是组合最大回撤恶化，且组合与新增子集均远低于职业级晋级门槛。
- 当前状态：`stopped_at_l2_research_only`。
- 已执行：独立 V41 Research-only Pine，用于识别审计；未替换 V31。
- 未执行：Paper/Live 注册、生产策略覆盖或当前交易合同晋级。
