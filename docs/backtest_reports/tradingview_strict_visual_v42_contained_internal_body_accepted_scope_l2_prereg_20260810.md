# V42 区间内大实体豁免：接受宽覆盖后的 L2 补充预注册

## 决策来源

- 本批次开始前，V42 L1 已完成且尚未读取 V42 成交结果。
- 用户明确接受 V42 对横盘生命周期产生广覆盖影响，因此取消原 L1 的“确认来源身份变化不得超过 50%”评价停止条件。
- 该决定只改变研究评价门禁，不改变 V42 策略行为；原 V42 L1 预注册、机器结果和停止结论保留，不回写或覆盖。
- V41 的枚举、slug、策略版本、父内子横盘合同和既有产物必须完整保留。

## 假设卡片

- 当前等级：`L2_MULTI_SYMBOL_DIAGNOSTIC`。
- 基线：`V41NestedChildRange`。
- 候选：`V42ContainedInternalBodyExemption`。
- 唯一变量：活动父区间或子区间内，实体达到区间高度 50% 的完成 K，只有 High 或 Low 穿出对应冻结 `trade_core` 时才触发内部冲击重置；High/Low 均完整包含时继续横盘。
- 因果定义：只读取当前及此前已完成 K、当时冻结的父/子 `trade_core`；不读取后续价格或成交结果决定豁免。
- 已知无标签覆盖：目标 BTC 2026-08-05 11:15 命中；V42 豁免 126 次 V41 重置、覆盖 47 币，确认来源身份变化 580 个；用户已在读取 V42 outcome 前接受该范围。
- 保持不变：冻结币种池、60 天预热、评价窗口、候选离散长度、P90/P10 核心、V41 父子优先级、突破棒门、弱离区、1～5 根首次回踩、75% 保留、止损、目标、冲突、容量与退出合同。
- 成本：入场 maker 2bps + 滑点 1bps；出场 taker 5bps + 滑点 1bps。

## 固定数据与执行

- 只使用本地 `quant_core` 已有且预热、评价窗口完整的成员，不同步或补造 K 线。
- 评价窗口冻结为 `[1784471400000, 1786248900000)`，即北京时间 `[2026-07-19 22:30, 2026-08-09 12:15)`。
- V41 与 V42 必须在当前同一代码、同一行情指纹、同一成员集合和同一成本合同下分别回放。
- 禁止搜索实体比例、包含容差、区间长度、止损、目标或其他相邻参数。

## L2 停止与升级条件

- 若 V42 成本后净 EV `<= 0R` 或 PF `<= 1.0`，立即停止，不创建 Pine。
- 若 V42 相对 V41 的净 EV、PF、净 R 与最大回撤未形成一致的正向联合边际，停止。
- 若改善主要来自 1～2 笔、单一币种或单一方向小时事件簇，停止。
- L2 通过仅允许进入 L3；只有完成 OOS/walk-forward、成本压力、参数邻域、收益集中度和 Pine/Rust parity 后，才创建独立 V42 Pine。
- 无论结果如何，不覆盖或删除 V41，不接入 Paper/Live/worker，不触发真实交易。
