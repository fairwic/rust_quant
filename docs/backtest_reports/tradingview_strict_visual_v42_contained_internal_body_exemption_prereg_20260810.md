# V42 区间内大实体续存 L1/L2 预注册

## 假设卡片

- 当前等级：先执行 `L1_OUTCOME_BLIND_COVERAGE`；只有 L1 通过才允许执行一次冻结成本的 `L2_MULTI_SYMBOL_DIAGNOSTIC`。
- 基线：`V41NestedChildRange`，V41 的父区间、父内局部子区间、父优先与完整交易合同保持不变。
- 唯一变量：把 V41 的“实体达到冻结区间高度 50% 即内部冲击”改为“实体达到 50%，且该完成棒的 High 或 Low 至少一端穿出同一冻结 `trade_core`，才是内部冲击”。
- 可证伪假设：完整位于冻结核心边界内的大实体仍属于区间内部换手，不应结束横盘；只有大实体同时刺穿核心边界才提供足够的结构离开证据。
- 保持不变：离散候选长度、P90/P10 `trade_core`、`visual_parent`、其余横盘质量门、父内单活动子区间、父来源优先、50% 实体 / 15 bps 突破棒门、弱离区一棒观察、1～5 根首次回踩、75% 越界保留、突破棒极值止损、最小 1 ATR 风险、量度目标、保本、手续费、滑点、持仓容量与退出合同。

## 冻结因果定义

对任一候选或活动横盘，使用当时已冻结的核心边界 `core_upper/core_lower` 与核心高度 `H = core_upper - core_lower`：

```text
large_body = abs(close - open) / H >= 0.50
fully_contained = high <= core_upper AND low >= core_lower
internal_impulse_v42 = large_body AND NOT fully_contained
```

- 边界相等视为仍被包含；不增加 tick 容差，也不读取下一根 K 线。
- `large_body && fully_contained`：保留活动横盘并继续原状态机；该棒也可作为之后新候选窗口的一部分。
- `large_body && !fully_contained`：保持 V41 原内部冲击重置行为。
- 小实体、强/弱突破、扫高扫低、回踩和接受判断均不改变。
- 同一判据必须用于父候选、活动父区间、子候选和活动子区间，避免图层与交易来源生命周期分叉。

- 目标完成棒：北京时间 `2026-08-05 11:15`，Unix 毫秒 `1785899700000`。
- 当时冻结父核心：起点 `1785854700000`，边界确认 `1785897000000`，长度 48 根，上沿 `64459.0`、下沿 `63891.0`。
- 目标 K：`O=64323.4, H=64329.7, L=64033.4, C=64033.5`；实体/核心高度 `0.5103873239`，且 `H <= 64459.0`、`L >= 63891.0`。

## L1 无结果标签门禁

- 固定使用本地已有、满足 60 天预热与评价窗口完整性的成员；不补同步 K 线。
- 机器账本只允许信号时可见的 K 线、区间、重置和确认来源身份；禁止读取成交后价格、MFE、MAE、退出、最终 R、盈亏或胜负。
- BTC 目标必须满足上述 V41 重置、V42 续存与完整包含证据；否则立即停止。
- V42 相对 V41 至少豁免 5 次完整包含的大实体重置，覆盖至少 3 个币种；所有豁免必须满足 `large_body && fully_contained`。
- V42 仍至少保留 3 次边界穿出型内部冲击，且所有保留重置必须满足 `large_body && !fully_contained`。
- 确认来源身份变化至少 3 个，且不超过 V41 确认来源的 50%；低于下限视为只修个例，高于上限视为改变策略家族。
- 候选与活动区间判据不一致、未来数据、父子优先级或 V41 身份被原地覆盖任一违例非零，立即停止。

## 条件 L2 固定回放

- 只有 L1 全部门禁通过才执行；不搜索 50% 阈值、边界容差、候选长度或任何相邻参数。
- 固定评价窗口为北京时间 `[2026-07-19 22:30, 2026-08-09 12:15)`；V41/V42 使用相同完整成员、行情指纹和 60 天预热。
- 成本固定为：入场 maker `2 bps` + 滑点 `1 bps`，出场 taker `5 bps` + 滑点 `1 bps`。
- 止损、目标、冲突、单持仓、资金路径和执行时序保持 V41，不允许用结果反向改变续存定义。
- L2 停止条件：新增/替换成交子集成本后净 EV `<= 0R`、PF `<= 1.0`、收益集中于 1～2 笔或单一事件簇，或 V42 组合相对 V41 的净 EV、PF、最大回撤没有联合正向边际。
- L2 通过只允许创建独立 `V42 Research-only` Pine 并进入 L3 候选；未完成 point-in-time 币种池、OOS/walk-forward、成本压力、参数邻域、收益集中度和统一资金曲线前不得晋级或接入 Paper/Live。
