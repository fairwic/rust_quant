# 严格视觉横盘 V43 父区间升级纵向均衡预注册

## 研究等级与目标

- 当前先执行 L1 无结果字段结构研究；仅在 L1 通过后进入 L2 多币种交易诊断。
- 目标样本：`ETH-USDT-SWAP` 15m，北京时间 `2026-08-05 20:00` 至 `2026-08-07 21:00` 的截图区间。
- 要解决的问题：允许父区间向左升级，但拒绝升级后绝大多数 K 线实体集中在视觉父区间同一半侧、另一半长期空置的伪横盘。

## 唯一变量

V43 完整继承 V42，只为“起点向左移动的父区间升级候选”增加纵向占用均衡门禁：

1. 仍按 V42 生成 `trade_core` 和“全部实体包络 + 约 90% 影线”的 `visual_parent`。
2. 以每根 K 线实体中心 `(open + close) / 2` 判断其位于 `visual_parent` 中线的上半侧或下半侧。
3. `dominant_half_ratio = max(上半侧根数, 下半侧根数) / 窗口总根数`。
4. 只有 `dominant_half_ratio <= 0.75` 才允许父区间向左升级，即上下两半各至少承载约 25% 的 K 线实体中心。

该变量不禁止向左升级，也不改变首次确认候选；它只拒绝纵向价格主体明显挤在一侧的后续升级。

以下全部保持不变：

- 离散候选长度、P90/P10 `trade_core`、`visual_parent` 包络算法；
- V42 的“整根 K 线仍在核心内时，大实体不重置横盘”豁免；
- 父内局部子区间、触碰、突破、弱离区、1～5 根回踩、开仓、止损、目标与冲突处理；
- 评价窗口、币种池、60 天预热、手续费与滑点。

## L1 因果门禁

L1 只读取当时已完成 K 线和结构事件，不读取 MFE、MAE、退出、R 或胜负。

通过条件：

1. 目标 ETH 窗口中，V42 存在至少一次 `dominant_half_ratio > 0.75` 的向左升级；V43 拒绝同一升级。
2. V43 仍保留至少一个 `dominant_half_ratio <= 0.75` 的向左升级，证明不是整体禁用升级。
3. 全成员至少拒绝 5 次、覆盖至少 3 个币种的一侧拥挤升级。
4. 不得出现未来数据读取或首次确认索引早于候选完成时点的时序违规。

停止条件：目标样本不满足定义、覆盖不足，或出现任何时序违规。停止时不查看交易结果，也不调整 0.75 门槛。

## 条件式 L2 合同

L1 通过后，使用同一批本地已确认 K 线比较 V42 与 V43：

- 评价窗口：`[1784471400000, 1786248900000)`；
- 入场 maker `2 bps`、入场滑点 `1 bps`、出场 taker `5 bps`、出场滑点 `1 bps`；
- 不同步或补造 K 线，不改变币种成员，不搜索相邻阈值；
- 对比成交数、净 EV、净 PF、最大顺序 R 回撤、收益集中度和交易身份变化。

交易晋级条件：V43 成本后净 EV 与 PF 均为正，并且联合质量不劣于同数据 V42。若变差或仍为负，则停止交易晋级，但保留 V43 作为独立的 Research-only 横盘识别版本，不覆盖 V41/V42。
