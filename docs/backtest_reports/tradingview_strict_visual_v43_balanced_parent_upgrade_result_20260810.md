# 严格视觉横盘 V43 父区间升级纵向均衡结论

## 结论

V43 修正了目标 ETH 图中的横盘识别，但在冻结的 V42 开仓与退出合同下，交易结果小幅变差。

- 识别结论：保留 V43 为独立 `Research-only` 版本，不覆盖 V41/V42。
- 交易结论：停止在 L2，不晋级 L3，不接 Paper/Live/worker，也不替换现有交易版本。
- TradingView：本轮未创建或覆盖 Pine；先保留 Rust 识别证据，避免把负向交易结果静默发布为新交易版本。

## 唯一改动

V43 完整继承 V42。首次确认不变，父区间仍允许向左升级；只有“起点更早”的升级候选增加以下门禁：

```text
实体中心 = (open + close) / 2
dominant_half_ratio = max(视觉父区间上半侧根数, 下半侧根数) / 总根数
允许升级条件 = dominant_half_ratio <= 0.75
```

因此上下两半都必须承载约 25% 的 K 线实体中心。该规则不改变 P90/P10 `trade_core`、实体全包加约 90% 影线的 `visual_parent`、V42 大实体包含豁免、局部子区间、突破、回踩、止损或目标。

## L1 无结果字段验证

- 请求 61 币，53 币具备完整 60 天预热与评价窗口，8 币因覆盖不足隔离。
- V42 父升级 1437 次，其中单侧占比超过 75% 的升级 165 次，覆盖 49 币。
- V43 接受 1329 次升级，所有接受升级的单侧占比均不超过 75%；时序违规 0。
- V43 拒绝全部 165 个原 V42 单侧拥挤身份，但因状态路径改变，最终升级总数只净减少 108 次。

目标 ETH 命中两次。最关键的一次发生在北京时间 2026-08-06 22:15：

- 96 根候选起点：2026-08-05 22:30；
- `trade_core`：1920.00 / 1889.38；
- `visual_parent`：1923.33 / 1871.00；
- 上半侧 80 根、下半侧 16 根；
- `dominant_half_ratio = 83.33%`，V43 正确拒绝升级。

这与截图问题一致：不是“不能向左升级”，而是少数低位过渡实体把父外壳向下拉宽，随后绝大多数实体长期集中在上半区。

## 为什么识别更合理但回测变差

交易身份分解揭示了状态机的二阶效应：

- 共同 619 笔反而改善：净值从 -94.82966R 提升到 -91.03653R，PF 从 0.73548 提升到 0.74446。
- 被移除 9 笔本身较差：2 胜 7 负，净 -2.99473R、EV -0.33275R、PF 0.56649；删除它们有利。
- 但 V43 新增 17 笔更差：5 胜 12 负，净 -11.37569R、EV -0.66916R、PF 0.18300。

拒绝宽而单侧的父升级后，状态机没有简单地“少开仓”，而是继续保留更短或更晚的活动区间。这些替代区间随后产生了 17 个新突破/回踩交易，负贡献超过了被删除交易和共同路径的改善，最终使总结果恶化。

## 四层认知框架

### 已知的已知

- 截图目标确实是单侧纵向占用失衡，V43 已按因果数据修复。
- 修复在 49 个币上都有覆盖，不是单图特例。
- 当前 V42 交易合同整体为负，V43 在同合同下进一步小幅变差。

### 已知的未知

- 17 笔新增交易是否应由“父升级被拒绝后的替代区间冷却期”单独约束，尚未研究。
- 识别版本与交易来源版本是否需要显式分层，尚未形成新合同。

### 未知的已知

- 横盘几何改动会改变后续状态路径，而不只是过滤当前一个候选；只统计被拒绝升级会低估交易影响。
- 胜率略升不代表质量改善，本轮 PF、EV 和回撤同时变差。

### 未知的未知

- 在样本外或 walk-forward 窗口中，替代短区间的新增交易是否仍集中亏损。
- 如果未来让 V43 只负责视觉识别、交易继续冻结 V42/V31 来源，是否能保留视觉正确性而不产生二阶交易重排。
