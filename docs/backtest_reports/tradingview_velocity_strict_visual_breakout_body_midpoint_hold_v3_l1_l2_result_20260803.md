# TradingView Velocity 严格视觉横盘突破实体中点守稳 V3 L1/L2 结论

## 最终决策

- 状态：`stopped_at_l2_keep_research_only`。
- V3 的唯一变量有一定筛选能力，但严格横盘突破家族在零成本和成本后均仍为负期望，未通过
  预注册的 `EV > 0 && PF > 1` L2 门禁。
- 不创建 Pine，不接 Paper、ReadOnly、Live、策略注册、调度或生产执行。
- 不启动“按横盘长度调整止盈”批次。该想法属于新的退出变量，只能另开预注册研究，不能在
  看过 V3 outcome 后叠加到本轮以修饰结果。

## 本轮唯一变量

基线 V2 首次满足回踩接受条件的完成 K 线，原本只要求触及冻结上沿附近并收在上沿之上。V3
在同一根确认 K 上额外要求：

```text
confirmation_close >= (breakout_open + breakout_close) / 2
```

确认收盘不满足时立即消费突破来源，不等待第 2 或第 3 根补开。横盘定义、三棒窗口、冻结上沿、
下一根开盘成交、1.5 ATR 止损、量能 2.7/3.6/4.5 ATR 目标、成本和冲突路径全部保持不变。

## L2 同身份成本后对照

V2 与 V3 使用相同当前 Release 可执行文件、相同行情、币池、窗口和回放合同。评价窗口为北京时间
`2025-07-01 08:00` 至 `2026-07-19 22:15`；冻结 Top60 中本地完整成员为 43/60，因此结论仅是
部分成员诊断，不是正式全市场或 L3 结论。

### 过滤器实际删掉了什么

- V2 中有 106 笔已执行交易因实体中点门禁被删除：成本后 `-45.752R`、每笔
  `-0.431622R`、PF `0.529463`。这组明显差于 V2 全体，说明该门禁具有弱正向选择能力。
- V2/V3 共同执行的 444 笔逐笔 outcome 完全一致，但仍为 `-121.336R`、每笔
  `-0.273279R`、PF `0.677511`，证明保留队列本身仍没有正边际。
- 删除旧交易后释放同币种持仓路径，使一笔原本被冲突阻塞、但本来就属于 V3 原始候选集的
  RENDER 交易得以执行并获得 `+2.729723R`。因此 L2 已执行数净减少 105，而不是 L1 原始信号
  减少的 143；这不是 V3 新造信号。

### 为什么仍然亏损

1. V3 成本后只有 130 胜、315 负，胜率 29.21%；平均赢家约 `+1.982R`，平均非赢家约
   `-1.194R`，对应盈亏平衡胜率约 37.6%，实际差约 8.4 个百分点。
2. 445 笔中 311 笔以初始止损退出，占 69.89%。实体中点门禁减少了弱确认，但没有解决大量
   突破随后完全失败的问题。
3. 43 个币中只有 11 个成本后净正，13 个月中只有 2026-01 为正；32 个币和其余 12 个月均
   不为正。负边际是广泛分布，不是移除一两笔异常亏损就能解决。
4. Candidate V20 总回放也未被救活：成本后 PF 从 V2 的 `0.847141` 降到 V3 的
   `0.830419`，顺序权益最大回撤从 `13,357.10` 增至 `13,728.76` 固定价格单位。删除某些
   严格横盘交易会释放其他家族的冲突路径，因此总体资金结果不能只按家族净 R 线性相减。

## ADA 2026-07-18 08:15 的 1R 核验

- V3 信号保留，下一根开盘 `0.1673` 入场，初始止损 `0.1659`，所以 1R 价格为 `0.1687`。
- 入场后在北京时间 `10:30` 的 K 线最高价首次达到 1R；止损前最高价为 `0.1692`，但最高完成
  收盘只有 `0.1686`。
- 本轮冻结目标仍为 `0.1714`，没有 1R 止盈、保本或部分止盈；最终在 `0.1659` 止损，成本后
  为 `-1.1904R`。

因此用户关于“它盘中已经达到 1R”的判断是对的；亏损来自当前退出合同并未在 1R 成交，而不是
回测漏看了最高价。这一事实支持另开“横盘长度与 1R 退出”的 L0 假设，但不能改变 V3 本轮的
L2 停止结论。

  32/48/64 根阈值、1R/部分止盈/保本和新的入场过滤器。
