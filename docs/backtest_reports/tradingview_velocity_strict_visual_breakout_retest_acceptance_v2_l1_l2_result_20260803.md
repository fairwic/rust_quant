# TradingView Velocity 严格视觉横盘上破回踩接受 V2：L1/L2 结论

## 最终结论

- V2 独立版本
  `volume_strict_visual_consolidation_breakout_retest_acceptance_long_15m_research_v2`
  已完成 L1 无标签覆盖和 L2 多币种诊断；V20、直接上破 V1 与 V29 均未被覆盖。
- L1 门禁通过：1,969 个合格突破源中，770 个在第 1～3 根完成回踩接受，保留率 39.11%。
- L2 门禁失败：V2 家族零成本已为 `-0.0910R/笔、PF 0.872`；成本后为
  `-0.3038R/笔、PF 0.647`，比直接上破 V1 家族自身更差。
- 回踩让配对交易的平均入场价改善 `0.1806` 个源棒 ATR，但没有改善结果；真正问题不是
  “追得太高”，而是该回踩形态筛中了质量更差的突破源。
- 状态固定为 `stopped_at_l2_keep_research_only`：保留研究代码与机器证据，不创建 Pine 策略，
  不接 Paper、ReadOnly、Live、生产注册、调度或实盘执行。

## 冻结单变量合同

基线严格沿用 V1 的区间识别、突破源、风险、目标、冲突与资金路径；唯一改变是入场时点：

1. V1 合格突破源仍须是：已经确认的严格视觉横盘，第一根完成收盘上破冻结 P90 上沿，突破棒
   为阳线、满足既有 `volume_event`，且存在量能目标档位。
2. 突破完成时冻结源棒索引、区间上沿、源棒 ATR、源棒量比与源棒目标 ATR 档位。
3. 只观察突破后第 1～3 根完成 K 线；第一根同时满足下列条件的 K 线成为确认棒：
   - `low <= 冻结上沿 + max(冻结上沿 × 0.001, 源棒 ATR × 0.25)`；
   - `close > 冻结上沿`。
4. 确认棒不额外要求阳线、放量、EMA、RSI 或高于突破棒收盘。
5. 等待期间任何一根 `close <= 冻结上沿` 立即失效；第 3 根仍未接受则过期。
6. 在接受棒收盘生成信号，下一根连续 15 分钟 K 线开盘成交。
7. 止损、目标和展示量比继续使用突破源棒冻结的 ATR、量能档位与量比；主策略既有逆势结构
   目标、持仓冲突和反手路径不变。

该状态机没有未来函数：突破源、上沿和风险参数在源棒完成时冻结；确认只读取其后逐根已经完成
的 K 线，不读取下一根开盘或后续 outcome 来决定当前是否接受。

## 配对因果诊断：为什么回踩没有改善

- 770 个接受源中，V1 主回放形成 532 笔已平仓交易，成本后为
  `-155.295R / -0.2919R每笔`。
- 未被 V2 接受的 V1 队列有 845 笔已平仓交易，成本后为
  `-185.435R / -0.2195R每笔`。
- 即使按同一突破源比较，V2 接受条件选择的 V1 原始队列已经更差：`-0.2919R/笔` 对
  `-0.2195R/笔`。因此该几何不是有效质量门禁，而是反向选择。
- V1/V2 同时有已平仓结果的 511 个源中，V1 为 `-150.670R`，V2 为 `-154.896R`，
  延迟确认再损失 `4.226R`。V2 入场平均比 V1 低 `0.1806` 个源 ATR，却仍稍差。
- 结论：更低的成交价无法补偿这类“轻触上沿后仍收在上方”所代表的弱势源结构。

## 四层判断与停止条件

- **已知的已知**：V2 完全因果、覆盖充足，也确实获得了更低的平均入场价；但家族零成本和
  成本后均为负，且月度、币种与确认年龄都没有稳定性。
- **已知的未知**：当前没有验证箱体结构止损或完全不同的趋势/市场状态假设；它们必须作为
  新的单变量假设重新预注册，不能加入本批次。
- **未知的已知**：视觉上合理的横盘、有效突破检测和可交易入场是三个不同问题；V2 证明
  “回踩后仍在上沿之上”没有提供正向选择能力。
- **未知的未知**：缺失 17 个成员、当前池的幸存者偏差、真实盘口冲击、资金费和组合相关性
  仍未纳入，正式 OOS 只可能增加不确定性，不能用来挽救已经为负的 L2 边际。

当前最关键判断是停止优化这个回踩窗口；最大风险是看到 V2 聚合亏损小于 V1，就误判它已经
有效。下一步最值得做的不是继续调 1～3 根或距离阈值，而是结束“严格视觉横盘直接/回踩上破”
作为独立做多入场家族；若仍要研究，必须回到新 L0，提出与本轮不同的可证伪单变量。
