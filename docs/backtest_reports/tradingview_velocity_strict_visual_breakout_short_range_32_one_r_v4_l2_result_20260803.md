# TradingView Velocity 严格视觉横盘短区间 1R 目标 V4 L2 结论

## 最终决策

- 状态：`stopped_at_l2_keep_research_only`。
- V4 提高了胜率并小幅改善净 R，但严格视觉横盘家族在零成本和成本后仍为负期望，成本后
  Profit Factor 还低于 V3，未通过预注册的 `EV > 0 && PF > 1` 联合门禁。
- 用户指出的 ADA 2026-07-18 08:15 个案确实被 1R 目标从止损修复为盈利；单笔判断成立，但
  不能外推为所有不超过 32 根横盘都适合固定 1R。
- 不创建 Pine，不接 Paper、ReadOnly、Live、策略注册、调度或生产执行。

## 本轮唯一变量

V4 完整保留 V3 的严格视觉横盘、三棒回踩接受、突破实体中点守稳、下一根开盘、1.5 ATR
初始止损、成本、冲突和反手合同，只修改既有 `ExitPolicy::Fixed` 的目标：

```text
冻结横盘长度 <= 32 根：target_ticks = initial_stop_ticks（1R）
冻结横盘长度 > 32 根：继续使用突破源棒量能对应的 2.7/3.6/4.5 ATR 目标
```

横盘长度与 V4 分支均在突破源完成时冻结，确认等待期间不增长。Bollinger、EMA596、三棒吞没、
逆势结构等更高优先级特殊退出不被 V4 覆盖。

## 已知、未知与下一步边界

### 已知的已知

- V4 没有未来函数：分支只读取突破前已经完成并在突破棒冻结的横盘长度。
- ADA 个案被正确修复，但统一 1R 的全样本仍为负。
- “横盘越短，目标越短”的单调假设被 8 根与 24 根队列否定。

### 已知的未知

- 当前只有 43/60 个本地完整成员，存在缺失成员与冻结币池幸存者偏差。
- 15 分钟 OHLC 不能证明真实盘口在同一根内的逐笔成交顺序，也未纳入资金费和动态点差。

### 容易忽略的事实

- 1R 名义盈亏比并非成本后 1:1：本批次实际平均赢/亏约为 `0.793R/1.206R`。
- 提前退出会释放其他家族的持仓冲突，因此必须完整回放，不能只改原交易的目标价格。

### 下一步

V4 到此停止，不在同一 outcome 窗口继续挑长度或目标。若新开研究，较可证伪的 L0 假设是：
“V3 Fixed 交易首次触及 1R 后只把保护位移到入场附近，原量能目标保持不变”，用以检验能否
保留 92 笔大赢家同时减少随后回撤止损；这必须使用新的预注册与未被本轮查看过的前向/OOS
数据，不能直接在当前窗口上晋级。
