# V19 EMA 趋势多：回踩接受 K 必须为阳线的单变量验证

## 结论

本轮变量应淘汰，不进入 Pine、主策略、Paper、ReadOnly 或 Live。

冻结 `P80 + 量比 2.5 + 实体 0.3% + 突破深度 0.30 ATR + 距 EMA12
不超过 1.25 ATR` 后，只要求补充来源的 V10 回踩接受 K 收阳，结果：

- 全策略净 R 从 `-49.1495R` 恶化到 `-50.1726R`；
- 全策略 `PF_R` 从 `0.9680` 降到 `0.9673`；
- EMA 趋势多家族从 `+3.9094R / PF_R 1.2607` 降到
  `+2.8864R / PF_R 1.2081`；
- EMA 趋势多 4 根内亏损仍为 `7` 笔，没有减少；
- 完成交易最大回撤虽从 `221.3811R` 降到 `220.2535R`，但不足以抵消期望退化。

阳线颜色本身不是可靠的突破接受证据。它既删除了一笔坏交易，也删除了一笔更大的
好交易；另外两笔赢家只是延后一根入场，并没有获得更好的风险收益。

## 冻结研究合同

- 基线版本：
  `tradingview_velocity_v19_ema_long_body003_break_depth_0_30_atr_v1`。
- 研究版本：
  `tradingview_velocity_v19_ema_long_body003_break_depth_0_30_atr_bullish_acceptance_v1`。
- 数据：冻结 Top60 中本地连续且具备 60 天预热的 43 个 OKX USDT 永续。
- 周期：15m。
- 成本：每边手续费 5 bps，加每边滑点压力 3 bps。
- 唯一变量：只对本轮补充来源冻结
  `acceptance.close > acceptance.open`。
- 原 V19 来源、来源量能、突破深度、EMA12 距离、三根接受窗口、止损、止盈和
  其他信号家族保持不变。

阳线要求在来源 K 收盘时写入待确认 setup；后续调用不能改变该 setup 的合同。
这避免了用接受 K 当时的新配置反向修改历史来源资格。

- 标准化 SHA256：
  `3243f042fb32e3db912b27236b7fc5b0abed3613b85e29631bc274c0a5205833`；
- 逐交易 identity SHA256：
  `592e4ccbc8c97a51ac4378ea7f03d4a3ce2eef38c468c1d640a65118adb6cc32`。

因此本轮差异只来自新阳线门禁，不是状态字段或回放环境漂移。

## 四层认知框架

### 已知的已知

- 研究门禁准确作用于补充来源，没有改变原 V19 来源。
- 纯阳线确认降低了净 R、平均 R 和 PF_R。
- 快速止损没有改善，变化只集中在 4 笔旧成交与 2 笔替代成交。

### 已知的未知

- “突破线获得接受”应使用收盘位置、微结构高点突破还是限时 stop-entry，仍需新的
  预注册实验回答。
- 23 笔 EMA 趋势多不足以证明不同市场制度下的稳定性。

### 未知的已知

- K 线颜色只比较开收盘，不表达是否守住结构、是否吸收卖压或是否重新突破局部高点。
- 延后一根入场会改变价格和持仓路径；它不是无成本的过滤器。
- 原始币价 PnL 与规范化 R 给出相反方向，说明跨币比较必须以 R 为主。

### 未知的未知

- 缺失的 17 个冻结成员、当前币池幸存者偏差和同步市场事件可能改变正式组合结果。
- 若改用接受高点上方 stop-entry，成交滑点、未成交率和事件相关性可能成为新的主要
  风险，不能从本轮结果外推。

## 决策与下一步

- 淘汰“接受 K 必须为阳线”的全局门禁。
- 保留冻结基线的方向无关回踩接受，不修改 Pine 或运行策略。
- 不在当前窗口继续调阳线实体大小、收盘分位或影线比例，避免围绕 4 笔边际样本过拟合。
- 若继续研究，优先在未见窗口预注册标准的两阶段右侧触发：
  回踩先守住冻结线，再由后续价格突破回踩 K 高点触发 stop-entry；一次只验证这一项，
  并显式统计未成交率、滑点、快速止损与被延迟赢家。
