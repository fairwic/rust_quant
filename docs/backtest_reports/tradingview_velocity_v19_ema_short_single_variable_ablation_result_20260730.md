# EMA 空头趋势单变量消融结果（15m V19）

## 结论

本轮在同一 V19、同一行情窗口、同一 43 个完整冻结成员、同一成交成本下，
依次只改变一个 `ema_trend_short` 入场条件。结果表明：

1. 原来的“量能 + 静态 EMA 空头排列 + 大阴线”不能可靠代表趋势延续；
   它把箱体内、箱体底部和尚未获得价格接受的下跌也识别成空头趋势。
2. `structure_break`（信号收盘严格跌破前 20 根已完成 K 线最低价）是唯一具有
   明显经济改善的变量：EMA 空头家族由 `-19.38R` 改善为 `+38.90R`，
   全策略由 `-51.65R` 改善为 `+18.90R`。
3. 该结果只能晋级为下一轮 Research 候选，不能直接合入 TradingView 主策略：
   家族成本后 `0.047R/笔、PF_R 1.065`，仍远低于职业级候选目标
   `0.6R/笔、PF >= 2.2`；BTC 仍为负，ETH 不在本轮 43 个完整冻结成员内，
   且每边总成本升至 12 bps 时重新转负。
4. 本轮不修改 Pine V19，不替换默认、Paper 或 Live 策略。

## 冻结口径

- 评价窗口：`2025-07-01 00:00 UTC` 至 `2026-07-19 14:15 UTC`
- 周期：15 分钟；信号 K 线收盘确认，下一根开盘成交
- 预热：60 天
- 冻结币种池：60 个成员；本地完整成员 43 个参与，17 个不完整或退市成员跳过
- 成交量：本地 `quant_core` 完成 K 线的 `vol_ccy`
- 压力成本：每边 5 bps 手续费 + 3 bps 滑点
- 初始风险 `R`：入场价格至冻结初始止损的距离
- 本表成本后 R：
  `(gross_pnl - (entry_price + exit_price) * 0.0008) / initial_risk`
- 退出、仓位、币种池、窗口和其他信号家族均保持 V19 不变

| C 1～3 根 EMA12 回抽失败 | 16.15% | 23.08% | 两项恶化 |
| D 距 EMA12 不超过 0.8 ATR | 13.28% | 25.78% | 两项恶化 |
| E 量比 >= 10 倍必须结构破位 | 9.71% | 20.54% | 仅轻微改善 |

这说明问题不只是止损距离。若只是止损太窄，加入结构破位不应同时降低
同棒止损、1 根内止损并提高净 R。当前证据更支持“原始入场定义过宽”：
静态 EMA 排列是滞后状态，价格是否真正离开旧结构才是缺失的确认。

## `structure_break` 深入审计

### 被删除与路径新增

- 与基线同一信号时刻仍保留的 794 笔 EMA 空单：`+49.77R / PF_R 1.086`
- 被结构条件删除的 507 笔：`-69.15R / -0.136R 每笔 / PF_R 0.825`
- 因前序交易被删、仓位释放后新出现的 27 笔：`-10.87R / -0.403R 每笔 / PF_R 0.530`

结构过滤确实删除了一个强负期望群体；但路径释放后新增的 27 笔交易又损失了
约 10.87R。这是组合策略中容易被忽略的状态路径效应，下一轮不能只对“共同交易”
做静态筛选。

### 跨币种与月份

- 43 个完整成员中：20 个盈利、23 个亏损
- 13 个评价月份中：8 个盈利、5 个亏损
- 前 3 个盈利币种贡献正收益的 31.47%，没有由单一币种完全主导
- 最大正贡献币种：`TURBO-USDT-SWAP +18.55R`
- 最差月份：`2025-09 -64.19R`
- 最好月份：`2026-06 +46.32R`
- `2025-08` 与 `2025-09` 合计约 `-124.69R`，市场状态稳定性仍不足

BTC 在本轮结构版本只有 4 笔，结果为
`-1.84R / -0.460R 每笔 / PF_R 0.479 / 25% 胜率`。相较基线 BTC 的
`6 笔 / -4.32R / PF_R 0.281` 有改善，但仍不能称为 BTC 正向策略。
ETH 不属于当前 43 个完整冻结成员，因此本轮没有 ETH 同口径证据。

## 对预注册门槛的审计

- A：改善收益，但快速止损率上升，未通过。
- B：收益、保留率、快速止损和贡献分布均改善，通过本轮最低门槛。
- C：仅保留 9.99%，且快速止损率上升，未通过。
- D：保留率不足且收益恶化，未通过。
- E：按原清单字面确实满足“比基线改善、保留率足够、快速止损略降”；
  但清单遗漏了“候选自身必须转为正期望”的绝对门槛。它仍为 `-15.75R`，
  改善幅度也很小，因此不应晋级。该遗漏不能在看完结果后偷偷改写原清单，
  只在下一轮清单中补上绝对门槛。

## 四层认知框架

### 已知的已知

- 原始静态 EMA 空头定义在成本后为负期望。
- 单纯增加 EMA 斜率、等待回抽或限制离 EMA12 距离，没有解决追空问题。
- 收盘跌破已冻结的前 20 根结构低点，能明显改善入场质量和快速止损率。

### 已知的未知

- `2025-08/09` 为什么仍显著失效，尚未完成逐笔市场状态归因。
- ETH 与缺失的 17 个冻结成员没有同源完整数据结论。
- 结构破位深度、破位后接受程度是否存在稳定参数邻域，尚未验证。

### 未知的已知

- 过滤入场会改变持仓占用，继而改变后续可交易路径；本轮已观察到 27 笔新增亏损。
- 12 bps 每边成本会吃掉全部优势，说明当前边际不足以承受较差成交。
- “EMA 空头排列”更多是背景状态，不是独立入场触发器；价格结构才提供实际接受证据。

### 未知的未知

- 实盘点差、排队、延迟、资金费与相关币种同时触发后的容量竞争，可能进一步降低收益。
- 当前研究窗口经历过多轮策略观察，仍存在研究者过拟合和选择偏差。
- 不同市场制度下固定 20 根结构窗口是否失效，需要未见样本与 walk-forward 才能回答。

## 决策与下一步

1. 冻结 V19 与 TradingView 当前 Pine，不直接合并任何变量。
2. 只保留 `structure_break` 作为独立 Research 候选；A、C、D、E 淘汰。
3. 下一轮仍做单变量，不同时叠加多个过滤器：
   - 基线改为本轮 `structure_break`；
   - 首先验证“结构破位深度”一个变量，例如相对前低至少
     `0 / 0.10 / 0.20 ATR`，并先冻结参数邻域与绝对晋级门槛；
   - 绝对门槛至少要求家族和全策略成本后均为正、PF_R 明显高于 1，
     同时保留本轮交易数、快速止损和贡献分布门槛；
   - 单独审计路径释放后新增的 27 笔，不允许用未来 K 线反向决定是否入场。
4. 完成未见时间窗口、BTC/ETH 与更完整币种覆盖前，不进入 Pine、Paper 或 Live。
