# TradingView Velocity V27 突破实体完全否定 L1/L2 结论

## 结论

V27 明显改善了 V26，但仍未通过成本门禁，必须停止在 L2。

V27 只增加一个信号时条件：第 1 或第 2 根确认棒在满足 V26 全部失败接受条件后，收盘还必须不高于已完成突破棒开盘价，即完整否定突破棒上涨实体。父横盘、放量、确认窗口、止损、目标、成交、冲突和退出政策全部保持 V26 不变。

在本地 43/60 个完整成员中，V27 从 V26 的 203 个候选中保留 65 个。零成本从 V26 的负期望改善为 `+11.298R`，但每边 `5 bps` 手续费与 `3 bps` 滑点使结果降为 `-2.107R`、每笔 `-0.032R`、PF `0.957`。这不是可晋级的小幅正边际，因此 V27 只保留为 Research 证据，不创建 Pine，不接入 Paper、ReadOnly、Live 或生产调度。

## 单变量合同

基线：`volume_active_parent_horizontal_first_break_close_back_short_15m_research_v26`

候选：`volume_active_parent_horizontal_breakout_body_rejection_short_15m_research_v27`

唯一新增门禁：

```text
confirmation_close <= frozen_breakout_open
```

该条件只读取已经完成的突破棒开盘价与第 1～2 根确认棒收盘价。确认棒不需要再次扫过突破棒高点，也没有增加连续两根确认、ATR 深度阈值、止损调整或目标调整。

账本为 V27 记录：

- 最长有效父横盘起止时间、长度、上下沿和方向效率；
- 突破棒时间、开盘、收盘和突破 tick 数；
- 确认棒收盘与低于突破棒开盘的 tick 数；
- 冻结止损、目标、下一根实际成交及后续成本前/成本后结果。

## 四层判断

### 已知的已知

- “完全否定突破实体”确实过滤了大量浅回踩，并把零成本表现从负值修复为正值。
- 规则覆盖 36 个币和 62 个事件簇，不属于只影响 1～2 笔的偶然过滤。
- 冻结成本后净期望和 PF 仍为负，已经触发预注册停止条件。

### 已知的未知

- 本轮没有 tick/盘口级实际滑点，`3 bps` 仍是统一压力假设；真实币种间成本可能更高或更低。
- 43/60 是本地部分成员诊断，不能称为正式 Top60 或全市场结论。

### 未知的已知

- V27 已非常接近成本盈亏平衡，但“接近”不能替代正边际，更不能满足最终 `>=0.6R` 与 PF `>=2.2` 的职业门槛。
- 最大实体否定深度跨币种不可直接横比；若未来研究深度，必须改用父横盘高度或 ATR 归一化并另开预注册版本，不能从本轮 tick 分布事后挑阈值。

### 未知的未知

- 市场状态、相关簇容量、资金费和实际成交质量仍可能进一步恶化结果。
- 继续叠加 RSI、确认深度、第二根确认、止损和目标会形成多变量过拟合；本轮证据不授权这样做。

## 最终决定

- L0 因果定义：通过。
- L1 无标签覆盖：通过。
- L2 多币种成本诊断：失败。
- L3：未开始。
- V27：保留 Research-only 证据，不 promote。

下一轮若继续，只能另开一个新版本并预注册一个变量。最值得研究的方向不是从 V27 逐笔结果里挑 tick 阈值，而是把“实体否定深度”转换为父横盘高度占比，先做无标签覆盖；在看盈亏前冻结唯一比例阈值。
