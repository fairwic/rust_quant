- 当前从 L0 进入 L1；先使用 V27 既有账本的信号时字段做无标签覆盖，L1 通过后才允许实现并进入 L2。

## 认知框架

### 已知的已知

1. V27 的父横盘、首次放量收盘突破和完整实体否定语义已经稳定，65 个候选中零成本为正、成本后接近盈亏平衡。
2. V28 证明“确认跌得更深”不是更好的空头质量门禁；V29 不能继续搜索确认深度比例。
3. V27 账本已经冻结父横盘上下沿与突破棒收盘，因此可以在不读取 outcome 的情况下计算跨币种可比的突破幅度。
4. 当前突破条件只有 `breakout_close > anchor_upper`，没有区分刚越过边界与明显脱离横盘的趋势突破。

### 已知的未知

1. 突破收盘超出父横盘上沿不超过区间高度 10% 会保留多少 V27 候选、币种、月份和事件簇。
2. 浅突破队列的成本后平均 R 与 PF 是否为正。
3. 浅突破结果是否集中于少数币种、月份或单一事件簇。

### 未知的已知

1. `breakout_close`、`anchor_upper`、`anchor_lower` 都在突破棒完成时可见；该变量比确认棒更早冻结，不依赖后续走势。
2. 父横盘现有边界触碰容差使用区间高度的 10%；沿用同一结构尺度，可以把“越界不超过 10%”解释为边界探测，而不是 tick 或价格百分比的跨币种混用。
3. 使用突破收盘而非突破最高价，保持与“首次完成收盘突破”的现有定义一致；本轮不恢复扫高门槛。

### 未知的未知

1. 浅突破可能只是微小噪声，未必代表有效的失败拍卖；放量与完整实体否定能否补足这一点仍需验证。
2. 强突破后的快速实体否定也可能是更有价值的衰竭反转，10% 上限可能错误删除这类交易。
3. 43/60 部分成员、current-live Top60 幸存者偏差、统一滑点和事件相关性仍限制结论外推。

## 可证伪定义

1. V27 的全部条件必须成立，V29 只做严格过滤，不重新定义父横盘或失败确认。
2. 父横盘高度为突破发生时冻结的 `anchor_upper - anchor_lower`，必须大于 0。
3. 突破收盘超幅为 `breakout_close - anchor_upper`；现有首次收盘突破保证该值严格大于 0。
4. V29 唯一新增门禁为 `normalized_breakout_excess <= 0.10`，等号纳入。
5. 不使用突破棒最高价、确认棒深度、ATR、RSI、后续成交或最终盈亏。
6. V29 账本额外记录归一化突破幅度；V27/V28 原证据和序列化保持不变。
