# TradingView Velocity V7 反向长影与 ATOM 阻力退出审计

## 结论

- ATOM 用户口述的 `07-28 05:45` 不是截图信号；实际信号为
  `07:45 Asia/Shanghai`。
- 该棒虽然满足实体看涨吞没，但上影占振幅 `72.73%`，属于明显上方拒绝。
- V7 的 60% 对称反向长影门禁可过滤该个例，且 Pine/Rust 边界一致。
- sealed 60/60 显示 V7 删除 20 笔，但这些交易零成本合计 `+7.5791R`，
  压力成本后仍约 `+2.9329R`，所以 V7 未通过预注册净期望门槛。
- 主 Research Pine 恢复为 V5 `a36f0e19`；V7 只保留为被拒绝研究候选。
- ATOM 7 月 17 日三棒多单未在 `1.526` 全平，不是执行漏单，而是固定目标
  原本为 `1.529`；现有退出合同没有把历史阻力设为目标。

## 1. 认知框架

### 1.1 已知的已知

- `05:45` 为阴线：`1.335 / 1.337 / 1.334 / 1.334`。
- 截图 `1.298` 信号对应 `07:45`：
  `1.295 / 1.306 / 1.295 / 1.298`。
- 当前吞没只比较实体，所以几何吞没为真。
- `07:45` 上影为 `0.008`，总振幅为 `0.011`，上影占 `72.73%`。
- 7 月 17 日正式信号、成交、退出分别为 `21:15`、`21:30 @ 1.502`、
  `07-18 06:15 @ 1.502`。

### 1.2 已知的未知

- 15m OHLC 无法还原影线形成的棒内先后顺序。
- 单个 ATOM 已见坏样本能否代表跨币种的稳定负期望。
- `1.526` 历史供应区若用于三棒退出，跨币种是否优于固定 1.5R。

### 1.3 未知的已知

- 现有长影标准已经冻结为 `>=60%`，不需要为单例发明 25% 或 50% 新阈值。
- 三棒强势反包已有收盘位于振幅顶部 90% 的独立质量门禁，不属于普通 RSI
  单棒形态。
- 当前 48 根横盘扫描只能识别 `1.497～1.506` 的近端微型横盘；若直接复用，
  会在约 `0.24R` 过早退出，不能解决用户指出的 `1.526` 阻力问题。

### 1.4 未知的未知

- 更远的 48～96 根阻力可能已经陈旧，需要独立触碰次数、目标最小 R 和时间
  衰减验证。
- 统一长影门禁可能过滤“先扫低再强收回”或“先扫高再强回落”的有效背离；
  60/60 结果已经证明该风险真实存在。

## 2. V7 规则与固定测试

V7 继承 V5，只增加：

```text
看涨吞没或底背离多：拒绝 long_upper_shadow
看跌吞没或顶背离空：拒绝 long_lower_shadow

long_shadow =
    candle_valid
    && !is_doji
    && shadow / candle_range >= 60%
    && shadow > opposite_shadow
```

固定测试覆盖：

1. ATOM 07:45 原始实体吞没为真、可交易吞没为假；
2. 镜像看跌吞没带 72.73% 长下影时拒绝；
3. 恰好 60% 时拒绝；
4. 低于 60% 时保留。

Pine 编译为 0 错误；Rust parity focused tests 全部通过。

## 4. ATOM 7 月 17 日退出路径

正式 V5 交易：

| 事件 | 时间与价格 |
|---|---|
| 信号 | `07-17 21:15`，收盘 `1.503` |
| 成交 | `21:30 @ 1.502` |
| 初始止损 | `1.485` |
| 1.5R 目标 | `1.529` |
| 持仓最高 | `07-18 01:00 @ 1.527` |
| 退出 | `07-18 06:15 @ 1.502`，`engulfing_break_even` |

`1.526` 相对成交价约为 `1.41R`，确实触达并拒绝；但三棒分支只执行 1R
保护和 1.5R 固定目标，且明确绕过普通逆势横盘结构目标。历史阻力主要位于
信号前 60～96 根，超出当前 48 根扫描范围。因此结论是“目标定义缺口”，
不是“目标已触达但策略或 broker emulator 没有执行”。

## 5. 后续最值得验证的独立假设

不要把退出改动混入已拒绝的 V7。若继续，应预注册独立三棒退出版本：

```text
volume_three_bear_bullish_engulfing_reversal_long_15m_v2

冻结窗口：信号前 48～96 根已完成 K 线
阻力条件：至少两组独立触碰
近端排除：预期不足 1.0～1.1R 的结构不用
最终目标：min(固定 1.5R, 冻结历史阻力)
入场后：不得重新识别或移动目标
```

本例预期冻结约 `1.526`，首次触达平掉 100%。该规则必须重新做 Pine/Rust
parity、同棒触价顺序和 sealed 跨币种消融，不能凭本例直接晋级。
