## 严格因果定义

1. 来源长影外轨 K 只建立 `setup`，不再直接视为最终入场信号。
2. 从 setup 后第 `1..=12` 根完整 15m K 中寻找首次方向极值重测：做空为 `high >= setup high`，做多为 `low <= setup low`。
3. 首次重测 K 收盘后，用包含该收盘在内的最近 20 个 close 计算总体标准差 `Bollinger(20,2.5)`。
4. 做空仅当 `retest close <= current upper` 时确认；做多镜像为 `retest close >= current lower`。边界相等视为带内。
5. 确认信号时间是首次重测 K 的收盘，最早入场时间是下一根 15m K 开始；L1 不读取下一根开盘价。
6. 首次重测若收在方向外轨之外，候选立即失效；不得等待后续更有利的第二次重测。
7. 若旧候选尚未重测且出现新的来源 setup，保持既有顺序：本根盘中先检查旧极值触及，未触及时才在收盘替换。
8. `close` 是否越过来源极值可以记录为无标签诊断字段，但不参与本轮筛选，避免叠加第二变量。
