## 因果状态机

记 `F=EMA144(close)`、`S=EMA576(close)`、`A=ATR14`。

### 做多

1. 连续 144 根满足 `F < S` 后，当前空头均线阶段只武装一次。
2. 首次有效突破必须满足：`close[t-2] <= S[t-2]`，随后 `close[t-1] > S[t-1]` 且 `close[t] > S[t]`。
3. 突破确认后 24 根内至少一根收盘满足 `close-S >= 0.75A`；否则本次突破不算有效离开，可等待下一次完整突破。
4. 有效离开后 96 根内，只检查第一次进入 EMA144 回踩区的 K：`low <= F+0.25A`。
5. 首次回踩只有同时满足 `low >= F-0.50A` 且 `close >= F` 才形成候选；失败后本均线阶段不等待第二次回踩。
6. 候选只在回踩 K 收盘后成立，任何订单最早只能从下一根 K 开始。
7. 触发时 `F<=S` 标记为 `pre_cross_retest`，`F>S` 标记为 `post_cross_retest`；该标签只分组，不改变候选资格。

### 做空镜像

1. 连续 144 根满足 `F > S`。
2. `close[t-2] >= S[t-2]`，随后连续两根收盘低于 `S`。
3. 24 根内至少一根满足 `S-close >= 0.75A`。
4. 96 根内第一次满足 `high >= F-0.25A` 时检查反抽。
5. 只有 `high <= F+0.50A` 且 `close <= F` 才形成做空候选。

EMA576 使用前 576 根收盘价 SMA 作为首值，之后按 `alpha=2/(576+1)` 递推。任何 EMA/ATR 缺失、非有限或非正值都失败关闭。
