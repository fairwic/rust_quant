# EMA576 首笔真实成交限制 V12 预注册

## 研究卡片

- 研究等级：L2 本地多币种诊断。V11 信号定义、无标签覆盖和候选账本已经冻结；本变量涉及真实持仓冲突，必须由 broker replay 判断。
- 唯一变量：同一 `symbol × direction × setup_ts` 只允许第一笔真实成交。第一笔成交后，该 setup 的后续信号保留审计记录但禁止再次开仓。
- 因果定义：候选信号收盘后，只尝试下一根连续 15m 开盘；成功解析、未被同币种持仓锁阻塞并进入退出回放时才算真实成交并消费 setup。缺 K 或持仓冲突不消费 setup，也不补偿成交。
- 基线版本：`market_momentum_ema576_post_signal_cross_timeout_15m_v11`；冻结 V11 L1 SHA-256 为 `ebc2b886d1a64e6900e81900bc59a5b0a93c245437d8537642dbfe4f9b64e1e6`。
- 目标样本：LAYER 2026-07-19 北京时间 10:15 首信号允许在 10:30 入场；同一 `setup_ts=1784319300000` 的 11:45 后续信号不得在 12:00 再次入场。
- 预计影响：V11 存在大量同 setup 重复候选；预计删除实际成交的 50%～90%，但不删除任何 L1 信号。
- 停止条件：LAYER 第二笔仍成交；只影响 1～2 笔；成本后 EV/PF 不为正；任一方向成本后不为正；结果依赖少数币种或单一事件簇。
- 保持不变：44 个完整成员、2025-07 至 2026-07 窗口、V11 信号、下一根开盘、固定 4% 止损、0.52R 目标、24 小时持仓、同 K 止损优先、8 bps/side 成本、同币种持仓锁和事件簇规则。
- 运行边界：Research-only；不接入 Paper、ReadOnly、Live、compose 或生产策略注册。

## 认知边界

- 已知的已知：V11 允许持仓退出后对同一长期资格 setup 再次开仓；LAYER 的第二笔亏损来自该行为。
- 已知的未知：禁止重复成交后，全样本交易数、成本后边际和多空分项是否改善。
- 未知的已知：V11 L1 已保存 `setup_ts_ms`，无需使用任何未来结果即可给成交建立稳定 setup 身份。
- 未知的未知：首笔限制可能保留较差的早期成交、删除后续较好成交；只能由预注册 L2 结果判断，不能按个案胜负改成“保留最好一笔”。
