# 严格视觉横盘突破棒极值止损 V1 预注册

## 假设卡片

- 研究等级：L1；通过无标签有效性门禁后只运行一个 L2 主候选。
- 独立策略身份：`strict_visual_consolidation_symmetric_breakout_candle_extreme_stop_15m_research_v1`。
- 基线版本：`strict_visual_consolidation_symmetric_retained_breakout_15m_research_v1`（严格视觉 V10）。
- 唯一变量：严格视觉突破交易的初始止损，由成交后 `1.5 × 突破来源 ATR14` 改为突破棒整根极值外一档最小价格单位。
- 多头止损：突破棒最低价减一 tick，再向下按 tick 对齐。
- 空头止损：突破棒最高价加一 tick，再向上按 tick 对齐。
- 冻结时点：突破棒完成时；后续第 1～5 根接受确认不得重算该止损。
- 下一开盘若已位于保护止损错误一侧，则候选失败关闭，不反转止损方向、不补造入场。
- 因果定义：突破棒高低点、tick size、来源 ATR、横盘边界和目标均在信号完成前可见；成交、止损和退出只由其后的真实 K 线推进。

## 保持不变

- 横盘扫描长度、视觉横盘质量、弱离区一棒观察期。
- 突破棒 `实体/整根 >= 50%`、方向实体涨跌幅 `>= 0.15%`。
- 无成交量入场门禁；成交量只作诊断。
- 突破后第 1～5 根首次合法回踩和 25% 越界保留规则。
- 多空镜像、下一根实际开盘成交、仓位冲突与反手顺序。
- 目标仍为冻结边界外一个横盘高度，不随实际开盘平移。
- 成本压力仍为每边 `5 bps` 手续费加 `3 bps` 滑点等价成本。
- 冻结币池、15 分钟周期、窗口 `1751328000000..=1784470500000`、缺失成员跳过规则和 60 天预热要求。

## L1 门禁

- V11 与 V10 的方向、突破时间、确认时间、边界、目标和候选数量必须完全一致。
- 每个 V11 候选必须冻结有限结构止损；多头止损严格低于突破棒最低价，空头严格高于突破棒最高价。
- 不读取下一开盘、MFE、MAE、退出时间、最终 R 或胜负来选择候选。
- 若候选身份漂移、止损未冻结或方向不合法，立即停止，不进入 L2。

## L2 比较与停止条件

- 只完整回放 V11，并与同一行情身份的 V10 机器结果比较严格视觉多头、空头家族。
- 主判断使用每边 `5+3 bps` 成本后的交易级 EV 与 PF；同时报告零成本结果、成交/阻塞数、实际初始风险相对来源 ATR 的分布和止盈目标消耗问题。
- 成本后 EV `<= 0` 或 PF `<= 1`：停止在 L2，不创建 Pine、不进入 Paper/ReadOnly/Live。
- 即使结果为正，本轮 43/60 仅是 partial diagnostic；不得表述为正式 Top60、OOS 或可上线结论。

## 预期影响

- 信号候选覆盖预期为 V10 的 100%；变化只允许发生在冻结止损、下一开盘止损有效性、退出路径和以实际初始止损为分母的风险 R。
- 结构止损可能比 1.5 ATR 更宽或更窄；本轮不同时增加最大止损宽度、最小剩余奖励或 ATR-R 门禁。
