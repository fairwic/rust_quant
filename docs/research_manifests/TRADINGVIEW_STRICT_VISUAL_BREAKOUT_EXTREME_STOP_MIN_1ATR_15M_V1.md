# 严格视觉横盘突破棒极值止损最小 1ATR V1 预注册

## 假设卡片

- 研究等级：L1；通过无标签身份与合同门禁后，只运行一个 L2 主候选。
- 独立策略身份：`strict_visual_consolidation_symmetric_breakout_candle_extreme_stop_min_1atr_15m_research_v1`。
- 基线版本：`strict_visual_consolidation_symmetric_breakout_candle_extreme_stop_15m_research_v1`（严格视觉 V11）。
- 唯一变量：实际下一开盘成交后，最终初始止损必须同时满足突破棒结构极值和至少 `1.0 × 确认信号 ATR14` 的风险距离。
- 多头最终止损：`min(突破棒最低价外一 tick, 实际入场价 - 向外取整后的 1.0 ATR)`。
- 空头最终止损：`max(突破棒最高价外一 tick, 实际入场价 + 向外取整后的 1.0 ATR)`。
- 结构失效优先：下一开盘若已越过突破棒冻结的结构止损，仍拒绝入场；不得用 ATR 下限复活已经失效的突破。
- 因果定义：结构止损与 ATR 在确认收盘时已冻结；实际开盘是生产成交时可见字段，最终止损在下单前一次性确定，入场后不得放宽。

## 已知事实与待验证问题

- 已知：V11 的 15,260 笔已平仓严格视觉交易中，5,254 笔实际风险低于 `1 ATR`，722 笔低于 `0.5 ATR`；后者平均成本侵蚀 `0.9169R`。
- 已知：V11 零成本多空合计略正，但 8 bps/边成本后 EV `-0.29854R`、PF `0.62703`。
- 待验证：把病态窄风险统一扩到至少 `1 ATR` 后，成本 R 是否恢复，同时是否因目标 R 被压缩而抵消改善。
- 风险：本轮只修复风险尺度，不假设能修复原始入场边际；V11 中 `1.0～1.5 ATR` 和 `>=1.5 ATR` 分桶成本后仍为负。

## 保持不变

- V11 的视觉横盘、弱离区一棒观察期、50% 实体占比和 15 bps 方向实体门禁。
- 第 1～5 根首次合法接受、25% 越界保留、无成交量入场门禁、多空镜像。
- 突破棒极值外一 tick 的结构止损；本轮只允许在实际开盘时向更远方向扩展，绝不收紧到结构内。
- 下一根实际开盘、结构失效阻塞、仓位冲突、反手顺序和固定一个单位回放。
- 目标仍为冻结边界外一个横盘高度，不随 ATR 风险下限改变。
- 成本仍为每边 `5 bps` 手续费加 `3 bps` 滑点等价成本。
- 冻结币池、15 分钟周期、窗口 `1751328000000..=1784470500000`、缺失成员跳过和 60 天预热合同。

## 预期影响

- L1 原始候选身份预期保持 V11 的 100%，即 15,998 笔；唯一新增的信号时字段为最小止损 ATR 倍数 `1.0`。
- 根据冻结 V11 outcome 形成的新假设，预计约 30%～40% 的已成交交易会在实际开盘时把止损向外扩展；该比例只用于预期，不参与 L1 候选选择。
- 结构失效阻塞身份预期与 V11 一致；ATR 下限不得减少这类阻塞。

## L1 门禁

- V12 与 V11 的方向、突破时间、确认时间、边界、结构止损、目标和候选数量必须完全一致。
- 每个 V12 候选必须在信号时冻结有限正 ATR，并声明最小止损距离恰为 `1.0 ATR`。
- L1 不读取实际下一开盘、最终止损、MFE、MAE、退出时间、最终 R 或胜负来选择候选。
- 候选身份漂移、结构止损漂移、ATR 缺失或倍数不等于 1.0 时立即停止，不进入 L2。

## L2 比较与停止条件

- 只完整回放 V12，并与相同行情身份的 V10、V11 机器结果比较严格视觉多头、空头和合计家族。
- 主判断使用每边 `5+3 bps` 成本后的交易级 EV 与 PF；同时报告零成本结果、风险/ATR 分布、止损实际扩展数、结构失效阻塞和目标奖励 R 分布。
- 最终止损风险低于 `1 ATR`、小于结构风险、非法方向或非有限值：实现合同失败，停止并修复实现，不解封 outcome 选新阈值。
- 成本后 EV `<= 0` 或 PF `<= 1`：停止在 L2，不搜索 0.5/1.5/2.0 ATR，不创建 Pine，不进入 Paper/ReadOnly/Live。
- 即使结果为正，本轮 43/60 仍只是 partial diagnostic，不得表述为正式 Top60、OOS 或可上线结论。
