## 四层认知框架

1. V6 已要求突破源实体占振幅至少 60%、方向实体涨幅至少 0.25%，并等待首次上沿回踩接受。
2. V3 实体中点门禁只能保证确认收盘没有回吐突破棒一半实体，但没有衡量确认收盘高出冻结上沿多少。
3. 确认收盘、冻结横盘上沿和突破源 ATR 都在信号完成时已知，不依赖入场后的 K 线。

### 已知的未知

3. 完整 broker 回放后，过滤是否真正改善成本后边际，还是只释放了另一批低质量信号。

### 未知的已知

1. `source_atr` 是突破棒冻结的 ATR14，也是 V6 后续止损与目标距离的风险尺度；确认阶段不能重算。

### 未知的未知

2. 本地冻结窗口之后的数据最长只暂查到约 8 天，且 ETH 没有同口径前向数据，尚不足以作为正式 OOS。
3. 接受余量可能只是波动状态代理；即使样本内正向，也不能直接解释为稳定因果边际。

## 唯一变量

对 V6 首次满足回踩接受且已通过突破实体中点的完成棒，计算：

```text
acceptance_margin_atr = (confirmation_close - frozen_range_upper) / frozen_source_atr
```

V7 只新增：

```text
acceptance_margin_atr >= selected_min_margin_atr
```

若不足阈值，该首次确认棒记录为 `acceptance_margin_rejected`，立即消费冻结突破来源，不得继续等待、
补开或改变横盘生命周期。

## L1 预注册阈值与选择规则

同一变量只扫描以下事前网格：

```text
0.05 ATR
0.10 ATR
0.15 ATR
0.20 ATR
```

每个阈值只读取 `signal_close`、`upper`、`source_atr`、symbol、上海月份和预冻结 60 分钟事件簇；
禁止读取成交、退出、MFE、MAE、R、PnL、胜负或后续 K 线。

合格阈值必须同时满足：

1. 拒绝 V6 候选的 `15%～50%`，预计影响足够但不删除大多数机会；
2. 保留至少 `150` 个候选、`25` 个币、`8` 个上海月份和 `100` 个 60 分钟事件簇；
3. 拒绝至少 `30` 个候选、`10` 个币、`6` 个上海月份和 `20` 个事件簇；
4. 所有候选的 `source_atr > 0`，且余量有限可重建；
5. 不依赖任何用户事后指定赢家或亏家才能成立。

若多个阈值合格，选择“拒绝比例最接近 30%”的阈值；绝对距离相同时选择较低阈值。若没有阈值
合格，立即停止在 L1，不实现 V7、不运行 L2。

## L2 停止与升级条件

只有 L1 通过后，才允许为唯一选中阈值实现独立 V7 Research 变体并运行一次完整回放。每边
`8 bps` 下必须同时满足：

1. V7 严格视觉家族净 R、平均 R、PF 均优于 V6；
2. V7 严格视觉家族净 R 与平均 R 为正，PF 大于 1；
3. 完整回放实际删除或重排至少 20 笔严格家族成交，覆盖 10 个币、6 个月和 15 个事件；
4. 改善至少覆盖 3 个币、3 个月和 3 个事件，且不是由 1～2 笔头部交易贡献；
5. Candidate V20 全家族总成本后净 PnL 与 PF 不得同时恶化；
6. V6 共同信号的冻结上沿、source ATR、止损、目标和下一根入场合同没有漂移。

任一条件失败即停止在 L2，不创建或修改 Pine，不接 Paper、ReadOnly、Live 或生产。即使全部通过，
本轮仍是根据旧窗口归因提出的自适应样本内候选；在足量的新前向窗口和 point-in-time universe
完成验证前，不得进入 L3。

## 因果与实现测试

1. 低于阈值的首次确认棒被消费，下一根更高确认不得补开。
2. 等于阈值时保留，使用 `>=` 边界。
3. 分母始终使用突破棒冻结的 `source_atr`，不得使用确认棒或未来 ATR。
4. 过滤不改变弱离区生命周期、强突破来源、实体中点拒绝或其他信号家族。
5. L1 报告的标签边界必须明确为无成交后字段。
