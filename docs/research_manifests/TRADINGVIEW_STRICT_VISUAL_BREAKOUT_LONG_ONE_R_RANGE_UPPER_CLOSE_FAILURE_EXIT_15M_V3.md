## 唯一变量

V2 在完成棒收盘达到 1R 后，把全仓止损移动到覆盖成本的开仓价；V3 只替换该保护退出语义：

```text
V2：完成收盘达到 1R → 下一棒起启用成本净保本止损
V3：完成收盘达到 1R → 只有更晚完成棒收盘跌破冻结横盘上沿，才在下一棒开盘退出
```

不同时搜索横盘上沿缓冲、连续确认根数、1R 阈值、分批比例、目标、初始止损或其他过滤条件。

## 因果定义

只处理同时满足以下条件的 V6 基线成交：

- `families` 包含 `strict_visual_consolidation_break_long`；
- 方向为多单；
- `exit_policy = Fixed`；
- 信号时 `candidate_ledger.time_visible_features.breakout_line` 已冻结且有限；
- 入场价、初始止损、冻结目标与初始风险有效。

定义：

```text
initial_risk = entry_price - initial_stop
activation_price = entry_price + 1.0 * initial_risk
frozen_range_upper = signal-time breakout_line
```

执行顺序：

1. 只有已完成 15m K 线的 `close >= activation_price` 才激活结构观察；激活棒自身不能同时失效。
2. 从激活后的下一根完成棒开始，原初始止损与冻结目标继续按原 OHLC broker 路径生效。
3. 若该棒尚未触发原止损或目标，且完成收盘严格满足 `close < frozen_range_upper`，冻结结构失效。
4. 结构失效最早在下一根 K 线开盘按真实开盘价全仓退出；不假设成交在横盘上沿或开仓价。
5. 若下一根同时会触及原止损或目标，结构退出发生在开盘，早于该棒盘中路径。
6. `R` 始终使用入场时初始风险；手续费与滑点只进入最终成本后 R，不改写失效边界。

等于横盘上沿不算跌破；本轮不增加 tick/ATR 缓冲，也不要求第二根确认。

## 保持不变

- V6 横盘识别、强突破源、1～3 根接受确认和下一根开盘入场；
- 初始止损、冻结目标、信号优先级、反手和其他信号家族；
- `CounterTrendStructureV4` 等非固定退出保持原样；
- 币种池、评价窗口、双边每边 `8 bps` 成本和交易身份；
- 不增加分批止盈、移动净保本、追踪止损、时间退出或新的入场过滤。

本轮仍使用冻结交易清单上的隔离退出反事实。提前退出不得释放容量或制造后续交易；只有 L2 正向后，
后续 L3 才允许重算完整组合资金路径。

## L2 停止与升级条件

V3 只与同一 V6 无结构保护基线比较；V1/V2 仅作归因参考，不参与规则选择。只有 V3 同时满足：

1. 每边 `8 bps` 下净 R、平均 R 和 PF 均高于 V6；
2. 成本后净 R 为正且 PF 大于 `1`；
3. 至少形成 `20` 笔结构失效退出并覆盖 `15` 个 60 分钟事件簇；
4. 正向改善至少分布于 `3` 笔、`3` 个币、`3` 个上海月份和 `3` 个事件簇；
5. 交易身份完全不变，只有退出时间、价格和原因允许改变；
6. 激活棒不得自失效、收盘失效下一棒开盘退出、原止损/目标优先和实际跳空开盘测试全部通过。

任一条件不满足即停止在 L2：不创建或修改 Pine、不接 Paper/ReadOnly/Live、不覆盖 V6、V1、V2
或主策略。即使全部通过，也只保留为自适应样本内候选，下一步必须使用新窗口 OOS。
