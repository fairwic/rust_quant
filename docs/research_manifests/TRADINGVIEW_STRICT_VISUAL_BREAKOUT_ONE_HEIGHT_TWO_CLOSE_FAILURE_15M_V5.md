# 严格视觉横盘突破：1H 后两次连续失守上沿再启用净保本 V5 预注册

- 研究版本：`strict_visual_breakout_one_height_two_close_range_upper_failure_15m_research_v5`。
- 冻结入场基线：`volume_strict_visual_consolidation_stronger_acceptance_margin_0_40_atr_long_15m_research_v8`。

## L0 判断

- 已知事实：V4 在 1H 后立即启用净保本，保护 9 笔原止损，却截断 11 笔原止盈，净恶化 `13.7561R`。
- 已知事实：旧 V3 在 1R 后出现一次收盘跌回冻结上沿就退出，也因两笔后续止盈被截断而净恶化 `2.0407R`。
- 当前假设：单根收盘跌回上沿仍可能是正常回踩；连续两根完成 K 都收在冻结上沿下方，才代表首次回踩没有快速收复突破结构。
- 最大不确定性：两次失守可能已经太晚，只能减少少量止损；也可能仍会截断慢速重新吸收后的成功趋势。

## 假设卡片

- 唯一变量：V4 的净保本保护不再在达到 1H 后立即生效，而是增加固定的“两根连续完成收盘严格失守冻结上沿”激活门禁。
- 因果定义：
  1. `H = visual_upper - visual_lower`，边界来自信号时已经冻结的横盘；
  2. 多单先由一根完成 K 的 `high >= max(entry + H, long_net_break_even)` 进入 armed 状态；
  3. 只从更晚的 K 线开始计数，`close < visual_upper` 记一次失守，下一根连续完成 K 仍满足才确认；中间任何 `close >= visual_upper` 都把计数清零；
  4. 第二次连续失守收盘后冻结净保本保护，保护从下一根 K 线开始生效；若开盘已经低于保护价，按真实开盘成交；
  5. 空单镜像为完成 K 的 `low <= min(entry - H, short_net_break_even)` 后，两根连续收盘严格高于 `visual_lower`。
- 单变量理由：1H、冻结边界、成本保本价、原止损、原目标和 next-candle 生效时序全部继承 V4；本轮只增加一个持久失守门禁，不搜索 0.8H/1.2H、深度阈值或第三根确认。
- 预计影响：预计 V4 已 armed 的交易中有 `15%～45%` 在原冻结止损/目标前形成两次连续失守决策事件。

## 保持不变

- V8 的信号、下一根成交、原始止损、原始止盈、冲突与持仓路径保持不变。
- 单边成本基准继续为 `5bps` 手续费加 `3bps` 滑点，另报告 10bps、12bps 压力。
- 仅作用于 `families == [strict_visual_consolidation_break_long] && exit_policy == Fixed` 的纯严格视觉横盘交易。
- 激活或失守确认棒内若原止损/目标已经按冻结 broker path 成交，原退出优先；不得用收盘后的信息改写该棒成交。
- 提前退出不释放容量，不补造后续入场；60 分钟链式同方向聚类只用于集中度诊断。
- 不修改 V8、V3、V4、Pine、Paper、ReadOnly、Live 或生产默认版本，不触发真实下单。

## L1 无标签决策事件闸门

本轮属于退出策略研究。L1 的“可见时点”是第二次连续失守完成收盘；扫描器可以读取该时点及以前的完成 K、信号时冻结边界/风险，并在隔离路径中只以冻结止损或目标判断仓位是否仍存在。L1 不读取真实最终退出时间/原因/价格、MFE、MAE、最终 R 或胜负，也不在这一阶段处理反手、容量和提前退出释放；这些执行冲突只允许在 L2 的冻结回放中恢复。

通过条件：

1. 纯家族 Fixed 交易都能唯一匹配冻结 `upper/lower/H`，且交易身份漂移为零；
2. 1H armed 交易不少于 30 笔、20 个 60 分钟事件；
3. 两次连续失守决策事件不少于 8 笔、8 个事件、6 个币种和 4 个上海月份；
4. 决策事件占 armed 交易比例落在预注册的 `15%～45%`；
5. 不需要加入第二个价格深度、成交量、EMA、RSI 或第三根确认才能计算。

任一条件失败即停止，不读取决策后的 outcome，也不进入 L2。

## L2 本地诊断闸门

L1 通过后，只运行上述一个 V5 候选。L2 必须同时满足：

1. 交易身份、入场、原始止损和原始目标与 V8 完全一致；
2. 8bps 单边成本下净 R、平均净 R 与 Profit Factor 均优于同交易集合基线；
3. 8bps 单边成本下候选净 R大于零且 Profit Factor 大于 1；
4. 实际改变退出不少于 8 笔、8 个事件；
5. 改善至少分布于 3 笔交易、3 个币种、3 个上海月份和 3 个事件，而非由少数样本贡献。

任一条件失败则停在 L2并淘汰该退出变体；全部通过也只允许进入 L3，不能直接合并主策略。

## 已知风险

- 本假设是在已知 V3/V4 失败形态后提出，属于开发样本启发；即使 L2 正向，也必须使用未参与本轮发现的新窗口做 forward OOS，不能直接晋级生产。
- 当前严格视觉家族只有多单经验样本；空单镜像只能先固定合同，不能冒充经验验证。
- OHLC 只能按冻结 broker path 近似同棒顺序；没有 tick/盘口级证据时，不宣称真实成交顺序完全一致。
