# TradingView Velocity D0 EMA 空头结构破位失败回抽净保本研究清单 V1

## 1. 最小假设

D0 EMA 空头在完成棒确认至少 `+1R` 后，如果价格继续形成新的 20 根结构破位，并在后续
完成 K 线中回抽该冻结破位线失败，那么从下一根启用成本后净保本，能够减少失败延续交易的
利润回吐，同时保留没有出现失败回抽的健康趋势赢家。

## 2. 冻结基线

- 策略：`candidate-v19`
- EMA 空头入场：`structure-break`
- 数据、币池、评价窗口、60 天预热、tick size、`vol_ccy` 和成交时序与上一轮
  `TRADINGVIEW_VELOCITY_D0_EMA_SHORT_COMPLETED_CLOSE_1R_NET_BE_15M_V1` 完全一致
- 成本：主口径单边 5 bps 手续费 + 3 bps 滑点
- D0 入场、初始止损、固定目标和其他信号家族全部冻结

## 3. 唯一变量

只对同时满足以下条件的实际成交研究：

- `families` 包含 `ema_trend_short`
- `exit_policy = Fixed`
- 方向为做空
- `initial_risk > 0`

保护必须依次完成三个只读取已完成 K 线的阶段。

### 3.1 完成棒确认 1R

```text
close[t1] <= entry_price - initial_risk
```

盘中最低价触及 1R 不确认。结构破位最早从 `t1 + 1` 开始检查。

### 3.2 新结构破位

对 `t1` 之后的第一根满足以下条件的完成 K 线 `tb`：

```text
structure_line = min(low[tb-20], ..., low[tb-1])
close[tb] < structure_line
```

冻结第一次合格的 `structure_line`。后续即使形成更低破位，也不得替换该线或向后搜索更有利
锚点。20 根与 D0 原入场结构口径保持一致，本轮不研究其他 lookback。

### 3.3 失败回抽

只从 `tb + 1` 开始，对第一根满足以下条件的完成 K 线 `tr` 确认失败回抽：

```text
high[tr] >= structure_line
close[tr] < structure_line
```

不增加 ATR 容差、实体方向、量能条件或最长等待窗口。失败回抽完成后才冻结净保本，最早从
`tr + 1` 的开盘和盘中路径生效：

```text
cost_ratio = 8 / 10000
raw_net_be = entry_price * (1 - cost_ratio) / (1 + cost_ratio)
net_be_stop = round_down_to_tick(raw_net_be)
```

## 4. 保持不变

- 信号、下一开盘成交、入场门禁和交易身份
- 初始止损与原固定目标
- 非 `ema_trend_short + Fixed + Short` 交易
- 不分批、不追踪、不改变仓位
- 未出现失败回抽时，完整保留原退出
- 同一根同时触及原目标与净保本时，继续使用 TradingView 默认 OHLC 路径
- 下一根若跳空越过保护价，按实际开盘成交，不回填挂单价
- 只做逐笔隔离退出反事实，不因提前平仓释放共享 broker 仓位或补造后续交易

## 5. 对照与报告

同一轮同时保留：

- D0 原固定退出
- 上一轮无条件完成棒 1R 净保本，作为负对照
- 本轮 `structure_break_failed_retest_net_be`

本轮报告至少包含：

- 全部 43/60 完整成员
- 2025 年 8～9 月与其他月份
- BTC 与非 BTC
- 8/10/12 bps 每边成本
- 交易数、净 R、平均 R、PF_R、胜率和闭仓 R 曲线最大回撤
- 1R 确认、结构破位、失败回抽、实际净保本退出数量
- 原赢家被截断与原亏损被保护的数量和 R 影响
- 单币贡献和 60 分钟链式有效事件
- 全策略交易 identity 哈希与 D0 逐笔身份变化数

## 6. 晋级门槛

必须同时满足：

1. 全部 D0 在 8 bps 下的净 R、平均 R、PF_R 均严格高于原固定退出
2. 2025 年 8～9 月净亏损至少减少 25%，且 PF_R 不低于原固定退出
3. 其他月份净 R 下降不超过 10%
4. 每边 10 bps 下本轮变体净 R 仍为正
5. 至少 30 笔交易完成失败回抽激活，且覆盖至少 20 个 60 分钟链式事件
6. 交易数、信号和入场身份完全不变
7. 1R、结构破位、失败回抽、下一棒生效、跳空和同棒路径测试通过

BTC 只有 4 笔，继续只报告，不作为硬门槛。任一门槛失败即淘汰；不得在本评价窗口继续尝试
8/12/16 根结构、ATR 容差、最长回抽窗口或 1.2R/1.5R 激活阈值。
