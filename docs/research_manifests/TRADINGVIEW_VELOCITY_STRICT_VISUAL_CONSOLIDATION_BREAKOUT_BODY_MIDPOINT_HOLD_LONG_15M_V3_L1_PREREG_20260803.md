- 基线版本：

## 冻结的 V3 严格子集合同

1. V2 的横盘识别、合格放量阳线上破、冻结字段、三棒接受窗口、收盘失效和过期条件全部不变。
2. 突破棒完成时额外冻结：
   `breakout_body_midpoint = (breakout_open + breakout_close) / 2`。
3. 当某根完成 K 线首次满足 V2 原接受条件时，在同一根上增加：
   `confirmation_close >= breakout_body_midpoint`。
4. 满足中点门禁才生成 V3 信号；不满足则记录 `body_midpoint_rejected` 并永久消费来源，
   不允许在第 2 或第 3 根等待补开。
5. V3 保留的信号必须与 V2 具有相同 symbol、突破源、signal time、冻结上沿、ATR、量比、
   目标档位、止损与退出政策；V3 只能删除 V2 信号，不能新增或改变保留信号的风险合同。

## L1 无标签门禁

1. 只读取突破开收盘、冻结实体中点、确认收盘、区间证据、确认年龄、币种、月份和事件簇。
2. L1 禁止读取或输出退出时间、MFE、MAE、胜负、R、PnL、Profit Factor 或后续 K 线。
3. 输出 V2 基线确认数、V3 保留数、中点拒绝数、保留比例及严格子集差异。
4. 明确核对两笔 BNB 被拒绝、ADA 被保留；任一目标样本不符立即停止并回到 L0。
5. 保留候选至少达到 15 笔、8 个币、3 个上海时区月份和 10 个串联 60 分钟事件簇，
   且门禁至少拒绝 3 笔，才允许进入 L2。

## L2 固定口径

1. V2 与 V3 必须由同一当前可执行文件、同一数据指纹、同一评价窗口和同一 Candidate V20
   主回放产生；不得复用身份不完整的旧缓存。
2. 成本固定为每边 5 bps 手续费与 3 bps 滑点；本地缺失成员只记录并跳过，不补造 K 线。
3. 报告家族交易数、成本前后净 R、每笔 R、PF、止损比例、月份/币种/事件集中度，
   以及相对 V2 删除、新增和保留风险漂移。
4. 成本后边际未转正或集中度停止条件触发时，V3 停止在 L2；不得继续叠加横盘长度止盈。
