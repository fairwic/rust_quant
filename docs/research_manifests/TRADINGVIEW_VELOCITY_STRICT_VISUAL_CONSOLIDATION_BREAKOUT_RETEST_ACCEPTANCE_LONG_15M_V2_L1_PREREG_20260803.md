# TradingView Velocity 严格视觉横盘上破回踩接受 V2 L1 预注册

## 研究等级与版本边界

- 本轮从 L0 进入 L1；只有 L1 无标签覆盖门禁通过后，才允许查看 L2 成本后结果。
- 基线是已冻结且停止在 L2 的
  `volume_strict_visual_consolidation_breakout_long_15m_research_v1`。
- 候选身份为
  `volume_strict_visual_consolidation_breakout_retest_acceptance_long_15m_research_v2`。
- V2 只改变入场确认时序，不覆盖 V1、V20 或 V29；仅限 Research，不创建 Pine，不接入
  Paper、ReadOnly、Live、生产注册或调度。

## 四层认知框架

### 已知的已知

1. V1 的严格视觉横盘识别、首次放量阳线收盘上破和因果生命周期已经验证可用。
2. V1 L1 有 1,969 个原始候选；L2 有 1,377 笔该家族平仓交易，零成本每笔
   `-0.0393R`、PF `0.944`，成本后每笔 `-0.2474R`、PF `0.706`。
3. V1 约 69% 的该家族交易触发初始止损；直接追突破没有形成正边际。
4. 主策略已有三根有限接受窗口，以及 `max(上沿 0.1%, 来源 ATR 的 0.25)` 回踩带；本轮复用
   这些既有常量，不根据 V1 盈亏搜索新阈值。

### 已知的未知

1. V1 合格突破中，有多少能在后三根完成 K 线内回踩冻结上沿并收回其上。
2. 确认候选是否仍覆盖足够币种、月份和独立事件，而不是只剩少量特例。
3. 延后确认造成的成交价变化和机会流失，能否被更低的假突破止损率抵消。

### 未知的已知

1. 回踩接受必须冻结 V1 突破时的上沿、ATR、量比和目标档位；确认棒不能重算风险来源。
2. 突破后的任何完成收盘回到或低于冻结上沿，都表示接受失败，不能等待后来再次站回。
3. 确认棒本身只是验证价格接受，不新增 EMA、RSI、量能或阳线门禁，否则不再是单变量实验。

### 未知的未知

1. 延后入场可能降低假突破损失，也可能以更差价格追入真正趋势，净效果只能由 L2 证明。
2. 三根窗口与既有主策略相同但未必是该形态最优；本轮只验证这个预注册合同，不做参数搜索。
3. 当前 43/60 本地完整成员仍有幸存者偏差、缺失成员和固定单位组合限制。

## 冻结的接受确认合同

1. V1 合格突破棒仍须满足：此前已有活动严格横盘；首次完成收盘严格高于冻结上沿；阳线；
   `volume_event=true`；存在主策略量能目标档位。
2. 突破棒只冻结来源，不形成 V2 入场信号。冻结字段为：突破索引、P90 上沿、来源 ATR、
   来源量比、来源量能目标档位。
3. 从突破后的第 1 根到第 3 根完成 K 线寻找第一次接受确认：
   - `low <= 冻结上沿 + max(冻结上沿 × 0.001, 来源 ATR × 0.25)`；
   - `close > 冻结上沿`。
4. 确认棒无需阳线、无需再次放量，也不要求 EMA 排列或收盘高于突破棒；这些均属于第二变量。
5. 任一等待棒 `close <= 冻结上沿` 立即失效；到第 3 根仍未确认则过期。
6. 确认棒只能使用此前冻结的上沿、来源 ATR、来源量比和目标档位；确认棒收盘后形成入场意图，
   下一根开盘成交。
7. V2 不允许在同一来源失效或过期后补开；新机会必须来自离区后重新完成的新横盘与首次突破。

## L1 无标签门禁

1. 先统计 V1 合格突破来源、V2 接受确认、失效、过期、确认年龄及信号时冻结字段。
2. L1 禁止读取或输出退出时间、MFE、MAE、胜负、R、PnL 或 Profit Factor。
3. 接受候选至少达到 15 笔、8 个币、3 个上海时区月份和 10 个串联 60 分钟事件簇。
4. L1 通过后只允许打开这个 V2 主候选的完整回放，并与同可执行文件重跑的 V1 比较。

## L2 固定口径

1. V1 与 V2 必须共享数据指纹、可执行文件、Candidate V20 主回放、成本、冲突和资金路径。
2. 成本固定为每边 5 bps 手续费与 3 bps 滑点；缺失成员只记录并跳过，不补造 K 线。
3. 报告 V1/V2 家族交易数、成本前后净 R、每笔 R、PF、止损比例、月份/币种/事件集中度，
   以及聚合主回放的变化。
4. 成本后边际未转正则停止在 L2；不得在结果上搜索 1/2/4/5 根窗口、回踩带、EMA、RSI、
   确认棒颜色、止损或目标。
