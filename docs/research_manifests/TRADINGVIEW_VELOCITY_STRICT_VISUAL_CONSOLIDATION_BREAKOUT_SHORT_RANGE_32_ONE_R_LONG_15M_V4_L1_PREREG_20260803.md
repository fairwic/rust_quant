# TradingView Velocity 严格视觉横盘短区间 1R 目标 V4 L1 预注册

## 研究等级与版本边界

- 当前等级：`L1`。先用既有 V3 无 outcome 账本验证冻结横盘长度覆盖；只有 L1 门禁通过，
  才允许实现 V4 并运行 L2 完整退出与冲突回放。
- 基线版本：
  `volume_strict_visual_consolidation_breakout_body_midpoint_hold_long_15m_research_v3`。
- 候选版本：
  `volume_strict_visual_consolidation_breakout_body_midpoint_hold_short_range_32_one_r_long_15m_research_v4`。
- V4 只作为 Candidate V20 上的独立 Research 退出版本；不覆盖 V1～V3、V20、V29 或 V30，
  不创建 Pine，不接 Paper、ReadOnly、Live、策略注册、调度或实盘执行。

## 四层认知框架

### 已知的已知

1. V3 相对 V2 有筛选能力，但 43 个本地完整成员上的家族成本后仍为
   `-118.606R / -0.266531R每笔 / PF 0.684766`，只能继续作为 Research 基线。
2. V3 的严格横盘来源在突破时已经冻结 `range.length_bars`；该字段只依赖突破前已完成 K 线，
   不读取入场后的最高价、最低价、退出或收益。
3. 用户在本批次前已经提出“横盘越短，目标越短，例如 1R”；本轮固定使用 32 根分界，禁止
   查看结果后改搜 24、48 或 64 根。
4. ADA-USDT-SWAP `2026-07-18 08:15` 的 V3 冻结横盘长度为 32 根；它只用于核对分支归属，
   已知的后续 1R/止损结果不得参与 L1 覆盖筛选。

### 已知的未知

1. 627 个 V3 候选中，冻结长度不超过 32 根的比例、币种、月份和事件簇覆盖尚未统计。
2. 把短区间目标从量能 2.7/3.6/4.5 ATR 改为初始风险 1R 后，成本后胜率提升能否抵消平均
   赢家缩短。
3. 提前退出会释放多少同币种持仓冲突，以及由此新增或改变哪些后续可执行交易。

### 未知的已知

1. `1R` 必须使用入场时冻结初始止损的 tick 距离；不能把 1.5 ATR 直接当作未经 tick 对齐的
   价格目标，也不能在入场后重算风险。
2. V4 不改变信号身份，因此 L1 可以直接读取 V3 账本；L2 因持仓时长变化必须完整回放，不能
   对旧交易结果做简单事后截断。
3. 与 Bollinger、EMA596、三棒吞没、逆势结构等更高优先级退出家族同棒重合时，继续沿用既有
   退出优先级；V4 只替换严格横盘信号进入原 `Fixed` 分支时的目标。

### 未知的未知

1. 32 根可能只是 ADA 个案的合适边界，不一定能跨币种表达“短平台”。本轮只能接受或淘汰
   这个固定政策，不能依据 outcome 移动阈值。
2. 1R 目标可能把原本少量的大赢家截短，使 PF 进一步下降；也可能通过更短持仓释放更多负期望
   其他家族交易。
3. 当前冻结 Top60 只有 43/60 个本地完整成员，仍有幸存者偏差；L2 只能称为部分成员诊断。

## 冻结的 V4 退出合同

1. V4 完整复用 V3 的横盘识别、首次放量上破、三棒回踩接受、实体中点守稳与来源消费逻辑；
   symbol、breakout time、signal time 和所有入场证据必须与 V3 一致。
2. 分支字段固定为突破来源已经冻结的 `range.length_bars`，不是确认棒后的累计长度，也不因等待
   第 1～3 根确认而增加。
3. 当 `range.length_bars <= 32` 且该信号进入既有 `ExitPolicy::Fixed` 分支时：
   `target_ticks = stop_ticks`。目标价仍在实际下一根开盘确定后按 tick 构造。
4. 当 `range.length_bars > 32` 时，继续使用突破源棒已经冻结的量能档位
   `2.7 / 3.6 / 4.5 ATR` 目标。
5. 更高优先级特殊退出政策保持不变；不得因 V4 覆盖 Bollinger、EMA596、三棒吞没、逆势结构
   或其他既有家族的退出合同。
6. 本批次不加入 1R 部分止盈、1R 后保本、移动止损、时间退出或新的入场过滤。

## L1 无标签门禁

1. 基线账本固定为：
   `target/research/strict_visual_breakout_body_midpoint_hold_v3_l1.json`，SHA-256
   `e6b432952e134c4abe5c62b8836d30bf7797886a98536689695b5b334143e924`。
2. 账本标签边界必须仍为
   `NO_MFE_NO_MAE_NO_EXIT_NO_WIN_LOSS_NO_R_NO_PNL_NO_PROFIT_FACTOR`。
3. L1 只按 `range_length_bars <= 32` 分组，报告两组的候选数、比例、币种、上海月份和串联
   60 分钟事件簇；禁止读取或关联任何 outcome。
4. 短分支必须占全部 V3 候选的 20%～80%，且短、长分支分别至少覆盖 15 笔、8 币、3 月和
   10 个事件簇。
5. ADA `2026-07-18 08:15` 必须以冻结长度 32 进入短分支；任一门禁不符立即停止。

## L2 固定口径与升级条件

1. V3 与 V4 必须使用同一当前 Release 可执行文件、相同行情指纹、币池、评价窗口和 Candidate
   V20 主回放；不复用身份不完整的旧结果。
2. 成本固定为每边 5 bps 手续费与 3 bps 滑点；本地缺失成员只记录并跳过，不补造 K 线。
3. 完整回放下一根开盘、tick 对齐止损/目标、同棒冲突、反手和同币种持仓锁；逐笔审计 V3/V4
   的信号身份、冻结止损、目标变化和由提前退出释放的后续交易。
4. 只有 V4 严格横盘家族成本后 `EV > 0 && PF > 1`、优于 V3，且改善不集中于 1～2 笔、
   单一币种或单一事件簇，才允许进入 L3。
5. L2 未通过时保留 V3/V4 Research 身份并停止；不得继续搜索长度阈值或叠加保本/部分止盈。
