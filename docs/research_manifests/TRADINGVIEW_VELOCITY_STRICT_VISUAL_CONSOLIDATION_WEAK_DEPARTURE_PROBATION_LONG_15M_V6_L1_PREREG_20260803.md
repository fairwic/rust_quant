## 四层认知框架

### 已知的已知

1. V5 本地扫描中有 7,256 次弱上离区和 8,299 次弱下离区，生命周期变量有足够结构样本。
2. 弱离区不能形成锚点；紧邻下一根即使成为强趋势棒，也不能补算旧横盘突破。
3. 无限保留旧横盘会把后续趋势延续棒错误归因于陈旧边界，因此观察窗口只能是一根。

### 已知的未知

1. 弱离区后紧邻下一根回到冻结区间的比例。
2. 保留这些回区横盘后，会新增多少后续强突破来源与最终候选。
3. 新增结构机会是否覆盖多个币、月份和事件簇，而不是只有一两个偶然样本。

### 未知的已知

1. 第一根弱离区时必须冻结原上下沿和离区方向，等待期间不能升级边界。
2. 下一根仍在任一边界外时，旧横盘在第一根弱离区处结束；确认棒无论多强都不能成为旧横盘锚点。
3. 下一根回到包含边界的闭区间 `[lower, upper]` 时，原横盘恢复活动；回区棒本身不能同时升级父区间或形成突破。

### 未知的未知

1. 一根观察期可能保留真正的扫线噪声，也可能短暂保留已经失效的结构；L1 只能检查生命周期分布，不能用后续盈亏挑规则。
2. 当前 43/60 本地成员与冻结当前币池仍有缺失成员和幸存者偏差。
3. TradingView 若在确认棒完成后回画第一根弱离区标签，容易被误解为未来函数；正式 Pine 应在确认棒显示结果，并保留第一根离区索引仅作证据。

## 冻结的 V6 生命周期合同

设活动横盘冻结边界为 `[lower, upper]`，当前完成棒索引为 `d`。

1. 强离区：若离区棒通过 V5 强度门禁，继续按 V5 立即产生强上破/强下破结构事件；只有既有做多量能合同满足时才冻结上破来源。
2. 弱离区：若完成收盘在区间外但未同时通过 `60% + 0.25%`，记录 `departure_index=d`、方向和原边界，进入 pending；不形成锚点、不交易、不升级边界。
3. 紧邻下一根完成棒 `d+1` 收盘位于 `lower <= close <= upper`：取消 pending，恢复同一活动横盘；本棒不同时升级或突破。
4. `d+1` 收盘仍在区间外，包括继续同侧或直接越过另一侧：消费旧横盘，`last_closed_index=d`；`d+1` 无论强弱都不能补算旧横盘锚点。
5. 新横盘只能从 `d` 之后重新积累；若先回区，后续另一根首次强离区可按 V5 正常成为新锚点。
6. 向上、向下生命周期完全镜像；V6 交易分支仍仅做多。

## L1 无标签门禁

1. 输出弱离区 pending 数、下一根回区数、同侧外部确认数、跨越另一边确认数及未决数。
2. 输出 V5/V6 的确认横盘、强上下突破、合格做多来源、最终候选及覆盖差异。
3. 审计任何 outside-confirmation 棒产生旧横盘锚点的数量，必须为 0。
4. 审计 pending 年龄，最大只能为 1 根。
5. V6 最终候选满足最低覆盖，且至少恢复 3 个弱离区横盘，才允许进入 L2。
