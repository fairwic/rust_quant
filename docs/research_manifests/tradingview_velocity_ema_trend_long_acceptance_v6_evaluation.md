# TradingView Velocity EMA 趋势多结构接受 V6 评估清单

## 1. 研究身份与边界

| 字段 | 冻结值 |
| --- | --- |
| 研究版本 | `tradingview_velocity_ema_trend_long_acceptance_v6` |
| 对照版本 | `tradingview_velocity_parity_15m_research_v5@a36f0e19` |
| 周期 | OKX 已确认 15 分钟 K 线 |
| 状态 | `completed / rejected / Research-only / not promoted` |
| 唯一实验对象 | `ema_trend_long` |
| 生产边界 | 不注册 Paper、ReadOnly、Live，不替换 V1～V5 |

本清单在运行 V6 回测前冻结。V6 只检验“EMA 趋势多是否需要突破后的市场接受
确认”，不得同时修改其他 16 个信号家族、初始止损、目标档位、成交成本、K
线来源、候选排序或退出规则。

## 2. 四层认知框架

### 2.1 已知的已知

- V5 压力成本共有 `6,662` 笔交易，净结果为 `-968.01R`；
- 精确单一家族 `ema_trend_long` 有 `1,070` 笔，压力成本净结果
  `-272.21R`，平均 `-0.2544R`，是样本不少于 100 笔的最大累计亏损家族；
- ATOM、LTC、FLOW 的代表性亏损均发生在单根放量大阳线后立即追入，随后未
  能持续站在最近结构高点外；
- RSR 盈利对照在突破后出现多根完成 K 线继续站在结构外。

### 2.2 已知的未知

- 两根收盘接受是否能跨币种稳定过滤假突破；
- 延迟确认会不会把有效趋势的盈亏比压缩得过多；
- 使用原始突破棒 ATR 和目标档位，是否比使用确认棒的波动尺度更稳定。

### 2.3 未知的已知

- V5 `ema_trend_long` 只要求放量、EMA 严格多头排列、价格位于 EMA12 上方、
  中等大阳线和 RSI 小于 70，并没有要求突破任何结构；
- 因此它实际混合了“趋势中继突破”和“局部高位单棒冲刺”两种不同形态；
- 直接扩大止损只会放大纯入场错误，不能证明市场已经接受突破价。

### 2.4 未知的未知

- 20 根结构高点可能在不同波动状态下过近或过远；
- 多个高相关币种可能由同一市场事件同时触发，原始交易数会高估独立样本；
- 当前固定 1 单位聚合不能替代统一资金、容量和相关簇风险回放。

## 4. V6 单一规则

### 4.1 原始来源棒

原始来源棒 `s` 必须先满足 V5 全部 `ema_trend_long` 条件：

```text
volume_event
EMA12 > EMA144 > EMA696
close > EMA12
close > open
实体 / 振幅 >= 60%
1% < 实体 / open < 3%
RSI14 < 70
```

并且：

```text
close[s] > highest(high[s-20 ... s-1])
take_profit_atr[s] 可用
```

来源棒收盘时冻结：

- 最近 20 根已完成 K 线最高价 `breakout_line`；
- 来源棒收盘价；
- 来源棒 ATR14；
- 来源棒 `filtered_volume_ratio`；
- 来源棒对应的 `2.7 / 3.6 / 4.5 ATR` 目标档位；
- 来源棒时间和索引。

来源棒本身不再立即生成订单。

### 4.2 接受确认

只检查来源棒之后的第 `1～3` 根已完成 K 线。确认棒 `t` 必须同时满足：

```text
close[t-1] > frozen_breakout_line
close[t]   > frozen_breakout_line
close[t]   >= frozen_source_close
EMA12[t] > EMA144[t] > EMA696[t]
close[t] > EMA12[t]
```

这表示价格至少连续两根完成棒站在突破线外，并重新达到来源棒收盘价。确认棒
不要求再次放量，也不重新计算来源结构、ATR、量比或目标档位。

任一等待棒收盘 `<= frozen_breakout_line` 时，当前 setup 立即失效；第 3 根
仍未满足确认时过期。等待中的 setup 不允许回退到更早结构，也不允许用后续
K 线移动突破线。setup 有效期间不重复启动同一家族的新 setup。

确认棒 `t` 收盘生成 `ema_trend_long`，最早 `t+1` 开盘成交。初始止损仍为
来源棒冻结 ATR 的 `1.5 ATR`，目标仍为来源棒冻结量比对应的原 V5 ATR 档位。
其余退出、同棒路径和冲突规则全部继承 V5。

## 5. V5 / V6 对照和预注册门禁

V5-Control 与 V6-Candidate 必须使用同一 sealed snapshot 和相同报告代码。

### 5.1 最差家族改善门禁

只统计最终 `families == [ema_trend_long]`：

- V6 压力成本交易数不少于 `100`；
- 压力成本净 R 至少比 V5 改善 `10%` 的绝对亏损，即改善不少于
  `27.22R`；
- 压力成本平均 R 必须高于 `-0.2544R`；
- 压力成本 R 口径 PF 不得低于 V5 的 `0.690`；
- 必须分别列出真实亏损、成本后才转亏和退出原因，不能只看总和。

### 5.2 全策略否决门禁

即使目标家族改善，只要出现任一情况，V6 仍判为失败：

- 全策略压力成本净 R 或平均 R 比 V5 更差；
- 全策略压力成本 PF 下降；
- 顺序权益最大回撤扩大；
- 零成本净 R 比 V5 更差；
- 交易路径在零成本与压力成本之间发生漂移；
- 结果主要由头部 5 笔或头部 5 个币贡献，移除后改善结论反转。

### 5.3 晋级边界

V6 只有同时满足项目职业级联合门槛，才有资格另行讨论 promote：

- 净每笔期望 `>= 0.6R`；
- 净 PF `>= 2.2`；
- 最大回撤 `<= 15%`；
- Recovery `>= 4`；
- Sharpe `>= 1.5`。

当前实验只允许得到“改善但不晋级”或“假设证伪”两种 Research 结论。未通过
门禁时，主 Pine 恢复为 V5，V6 快照、实现和失败证据保留，不触发任何生产
切换或交易所 mutation。

### 7.4 TradingView 失败形态

ATOM `2026-07-11 08:15`、LTC `2026-07-17 11:15` 等保留亏损具有共同
形态：

1. 来源棒是靠近或冲出布林上轨的巨大放量阳线，量比常超过 `6x`，更像末端
   加速而不是健康突破；
2. 接受棒继续位于来源收盘价上方时，价格已经进一步远离突破线，V6 实际在
   追第二段扩张，不是真正等待“回踩—收回”；
3. 20 根局部高点之外仍可能紧邻 48/96 根供应区，规则没有检查更大结构的
   上方空间；
4. `EMA12 > EMA144 > EMA696` 只证明顺序，不证明 EMA144/EMA696 已形成
   稳定正斜率；反弹初期的慢均线仍可能接近平坦；
5. 多个失败样本入场后最大有利波动接近 `0R` 并立即回落，主因是入场位置
   错误，不是 `1.5 ATR` 止损过小。

FLOW 代表样本被 V6 过滤，但 ATOM/LTC 这类极端量能末端扩张仍被保留，说明
当前确认条件筛掉了部分弱突破，却没有识别最危险的吹顶式延续。

### 7.5 结论与后续边界

本次状态固定为：

```text
research_only_rejected_target_quality_gate_failed
```

- V6 不晋级、不注册 Paper/ReadOnly/Live，也不触发任何交易 mutation；
- 主 Pine 已恢复并保持 V5 `a36f0e19`，V1～V5 均未被覆盖；
- V6 Pine、Rust 实现和失败报告仅作为可复现的否证证据保留；
- 当前 Rust 正式报告尚未逐笔序列化 setup 来源索引、冻结突破线和确认年龄。
  实现与 Pine 悬浮信息已有这些状态，但报告证据字段仍不完整，因此也不满足
  本清单第 6 节的全部审计要求。

下一轮不得直接把量比事后收窄为当前样本中较好的 `4x～6x`。如果继续研究，
必须新增独立版本并在未见窗口预注册：

1. 等待价格真实回踩冻结突破线后重新收回，而不是要求继续高于来源收盘；
2. 要求 EMA144、EMA696 正斜率，并验证排列成熟度；
3. 检查 48/96 根已完成 K 线的上方结构空间；
4. 将 `>=6x` 的极端量能作为独立的耗竭/二次突破假设，不与普通趋势延续
   共用同一入口。
