| 研究版本 | `tradingview_velocity_rsi_divergence_ema_age_v5` |

本清单在查看 V5 回测结果前冻结。V5 只研究“纯 RSI 背离面对严格 EMA
排列时，趋势连续年龄是否应改变目标与保护方式”，不得顺带修改锚点、RSI、
量能事件、K 线门禁、止损、箱体识别或其他信号家族。

## 2. 已知事实、研究假设与未决风险

### 2.1 已知事实

- V4 对逆势结构统一使用 1R 激活、1R 距离的移动保护；
- V4 在逆势多单上改善明显，但截断了一部分原本有长尾优势的逆势空单；
- 当前逐笔报告可以按 `families + exit_policy` 识别纯 RSI 严格逆势交易，
  但尚未携带信号时 EMA 严格排列连续年龄；
- 冻结 60 品种对照在压力成本后仍为负期望，因此任何 V5 结果都只能作为
  Research 证据。

### 2.2 预注册假设

严格 EMA 排列刚形成和已经持续很久，不应使用完全相同的逆势退出：

- 连续 `1～599` 根属于**新趋势**。逆势交易只尝试回到最近冻结横盘的近边，
  不追求穿越整个横盘区；
- 连续 `>=600` 根属于**成熟趋势**。若 RSI 背离仍满足全部既有门禁，则允许
  使用冻结横盘远边；完成棒收盘穿过冻结近边后先保护到成本净保本，并且只有
  该结构确认已经成立且最大有利运动达到 `2R` 时，才采用较宽的追踪；
- 没有形成严格 EMA 排列的中性或过渡状态，不能证明“逆势所面对的趋势”
  具备可审计年龄，因此纯 RSI 背离不允许单独开仓。

### 2.3 最大风险

- `600` 可能只是本样本偶然有效的分界；
- 成熟趋势可能代表衰竭，也可能代表最稳定的延续，方向效应可能不对称；
- 近边目标会提高命中率但缩小盈利，15 分钟成本可能吞掉优势；
- 同一市场事件会同时触发多个高相关币种，原始交易数不能等同独立样本数；
- ETH 不在冻结 60 品种成员内，必须单独同源验证，不能由 60 品种结果外推。

## 3. 冻结数据与成本合同


固定合同：

- 每个品种使用 60 天预热，正式评价窗口与成员顺序不得改变；
- 行情只读取已确认 OKX 15 分钟 K 线；
- 成交量字段固定为 `vol_ccy`，禁止改成 `volume * close`；
- tick size、下一根开盘成交、OHLC 路径、同棒冲突、期末持仓处理与 V4
  完全一致。

60 天包含约 5,760 根 15 分钟 K 线，明显超过 600 根阈值。年龄从完整预热
开始累计；即使严格排列在预热窗口之前已经形成，也不会影响 `>=600` 桶的
归类。

### 3.2 双成本口径

必须对同一执行路径同时报告：

1. 零成本；
2. 每边手续费 `5 bps` 加每边滑点 `3 bps`，合计固定 `8 bps/side`。

压力成本只允许改变净 PnL、净 R 和派生指标，不允许改变信号、入场、止损、
目标、移动保护或退出时点。V5 成熟趋势使用的成本净保本价也固定按
`8 bps/side` 计算，并在零成本与压力成本回放中使用同一保护价，避免成本
模式反向改变交易路径。

## 4. 信号集合与 EMA 年龄

### 4.1 纯 RSI 背离

“纯 RSI 背离”要求最终可执行家族只有一个：

```text
纯底背离多：families == [rsi_bullish_divergence]
纯顶背离空：families == [rsi_bearish_divergence]
```

同一信号棒若另有独立有效家族，不属于本次“纯 RSI”实验。V5 对 RSI 分支的
限制不得取消该独立家族，也不得改变其止损、目标或退出政策。

### 4.2 严格排列与连续年龄

在信号 K 线 `t` 收盘时：

```text
底背离逆势多：
    EMA12[t] < EMA144[t] < EMA696[t]

顶背离逆势空：
    EMA12[t] > EMA144[t] > EMA696[t]
```

连续年龄包含信号 K 线。从 `t` 向前逐根检查已完成 K 线，直到首次出现：

- 任一 EMA 缺失或非有限值；
- 任一严格不等式不成立；
- EMA 相等。

禁止使用容差把相等视为严格排列，也禁止在排列中断后跨段累计。审计报告至少
保存 `signal_counter_trend_ema_age_bars_capped_600`；值 `600` 表示
“至少 600 根”。

诊断分桶在查看结果前固定为：

| 桶 | 连续年龄 | 规则身份 |
| --- | ---: | --- |
| A1 | 1～32 | 新趋势 |
| A2 | 33～96 | 新趋势 |
| A3 | 97～300 | 新趋势 |
| A4 | 301～599 | 新趋势 |
| A5 | >=600 | 成熟趋势 |

策略行为只使用 `1～599` 与 `>=600` 两档。A1～A4 仅用于诊断，禁止根据
分桶结果再选择其中盈利区间作为开仓门禁。

### 4.3 中性、过渡与顺势状态

- 两种严格排列均不成立时，记为中性或过渡状态；
- 中性或过渡状态的纯 RSI 背离直接阻止开仓，不允许回退到 ATR 目标；
- 严格顺势的纯 RSI 背离不属于本次逆势年龄实验，沿用 V4，并在报告中单列；
- 若同棒存在其他独立有效家族，只移除被禁止的纯 RSI 分支，其他家族继续按
  自己的 V4 合同评估。

## 5. V5 目标与退出合同

### 5.1 共同边界

- 信号在 K 线 `t` 收盘确认，最早下一根开盘成交；
- 初始 `R0 = abs(actual_entry - frozen_initial_stop)`，入场后永久不回写；
- 横盘区必须在 `t` 收盘前已经确认并冻结，开仓后不得重识别或移动；
- 没有有效冻结横盘、目标方向错误或目标不能覆盖有效价格距离时，阻止该纯
  RSI 逆势开仓，不得回退到 ATR；
- V4 的背离锚点、量能事件、RSI 路径、方向性 K 线门禁和初始止损均不变。

### 5.2 新趋势：1～599 根

新趋势纯 RSI 严格逆势交易：

- 目标固定为最近有效横盘的**近边**；
- 逆势多单位于横盘下方时，近边为横盘下边界；
- 逆势空单位于横盘上方时，近边为横盘上边界；
- 沿用 V4 的完成棒保护：达到 `1R` 后，以 `1R` 距离单向移动；
- 沿用 V4 既有保本下限，不把成熟趋势的固定成本净保本价混入新趋势组。

### 5.3 成熟趋势：至少 600 根

成熟趋势纯 RSI 严格逆势交易：

- 目标固定为最近有效横盘的**远边**；
- 逆势多单位于横盘下方时，远边为横盘上边界；
- 逆势空单位于横盘上方时，远边为横盘下边界；
- 同一冻结横盘的**近边**同时作为结构确认线；
- 逆势多的完成棒收盘严格站上近边，或逆势空的完成棒收盘严格跌破近边时，
  下一根起先把保护移到固定 `8 bps/side` 的成本净保本价；
- `1R` 本身不触发任何保护动作；
- 只有完成棒结构确认已经成立，并且最大有利运动达到 `2R`，才激活 `2R`
  距离的单向宽追踪；两个条件可以在同一根完成棒同时满足；
- 只要完成棒收盘尚未穿越近边，即使影线或 MFE 已经达到 `2R`，仍保持原始
  止损，不得移到成本净保本，也不得开启宽追踪。

设单边固定成本率 `c = 0.0008`，实际入场价为 `E`，固定净保本价为：

```text
多单 net_be = ceil_to_tick(E * (1 + c) / (1 - c))
空单 net_be = floor_to_tick(E * (1 - c) / (1 + c))
```

该公式使：

```text
方向毛价差 - (entry_price + exit_price) * c >= 0
```

成熟分支使用有前置依赖的完成棒状态机：

```text
structure_confirmed =
    structure_confirmed[1]
    || (long  && close > frozen_near_edge)
    || (short && close < frozen_near_edge)

net_be_active =
    structure_confirmed

wide_trail_active =
    structure_confirmed
    && MFE >= 2R0

if !structure_confirmed:
    stop = original_stop

if MFE >= 1R0 && MFE < 2R0 && !structure_confirmed:
    stop = original_stop
```

结构确认后，下一根起保护不得差于 `net_be`。结构确认与 `MFE >= 2R0`
可以在同一根完成棒同时成立，并从下一根起直接使用宽追踪。只有
`wide_trail_active` 为真时，每根已完成 K 线才计算：

```text
多单候选保护 =
    max(previous_stop, net_be, highest_high_since_entry - 2R0)

空单候选保护 =
    min(previous_stop, net_be, lowest_low_since_entry + 2R0)
```

保护只允许朝盈利方向移动。结构确认和依赖它的宽追踪都在对应 K 线完成后
生效；若完成棒收盘已经越过新保护，则下一根开盘退出，禁止用该棒内部路径补造
更优成交。仅影线达到 2R、但完成棒收盘未穿越近边时，不产生任何保护更新。

### 5.4 同棒退出优先级

V5 不修改 V4 已冻结的 OHLC 同棒冲突规则。结构目标、原始止损或已经生效的
移动保护在同一根 K 线同时可达时，必须继续使用 V4 的确定性路径，不得为 V5
样本选择更有利的成交顺序。

## 7. 预注册评估输出

### 7.1 总体与方向

V4、V5 均须报告：

- 全策略交易数、净 R、平均净 R、胜率、净 PF；
- 最大回撤、Recovery Factor、Sharpe、盈利币覆盖；

- 目标、原始止损、净保本、移动保护及其他退出原因。

### 7.2 EMA 年龄桶

A1～A5 每桶分别报告：

- 原始信号数、实际成交数、阻断数；
- 顶背离空、底背离多各自的交易数、净 R、平均净 R、胜率和净 PF；
- 零成本与压力成本差异、平均成本 R；
- 结构近边/远边命中率、达到 1R/2R 的比例、激活后回吐；
- 按月正负贡献及有效市场事件数。

`600` 是查看结果前冻结的预注册阈值。无论 A4 或 A5 哪一段结果更好，都不得
在本轮把阈值改为 400、500、700、800 或任何其他值。若 600 被证伪，只能
保留失败结论；后续新阈值必须作为独立 V6 假设重新预注册。

### 7.3 BTC、ETH 与覆盖边界

- BTC 是冻结 60 品种成员，必须同时报告全策略和纯 RSI 年龄桶结果；
- ETH 不在本次冻结 60 成员中，必须另建同一 OKX、15分钟、正式窗口、60天
  预热、`vol_ccy`、tick size 和双成本口径的固定同源快照；
- ETH 结果只能作为独立单币诊断，不得写入 60/60 主样本聚合，也不得在看到
  结果后改变 V5 规则。

### 7.4 集中度与稳健性

必须报告：

- 按币种、月份、顶/底方向和 A1～A5 的收益贡献；
- 60 分钟同方向 single-linkage 事件簇及有效事件数；

## 8. 判定边界

本轮没有 Paper、ReadOnly 或 Live 晋级路径。即使 V5 在某个年龄桶、BTC、
ETH 或零成本口径显著盈利，也只能得出“该预注册假设值得继续消融”的结论。

以下任一情况均必须保留为失败或不充分证据：

- 压力成本后总体或纯 RSI 逆势仍为负期望；
- 收益主要依赖单一方向、少数币种、少数月份或单一事件簇；
- V5 只提高胜率但显著截断长尾盈利；
- ETH 与 60 品种方向冲突，或某年龄桶样本不足；
- 缺少逐笔 EMA 年龄、冻结目标、净保本、2R 激活或退出路径证据；
- 需要修改 600 阈值才能得到正结果。

V5 在本轮始终保持 `Research-only / no promote`。任何后续实现、回测或消融
不得覆盖 V4，也不得让 V5 成为默认策略入口。
